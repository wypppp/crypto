# 河北公开污染源目录审计

> 建立：2026-08-24
> 数据入口：`https://111.62.218.180:9920/psIndex/`
> 范围：当前唯一企业/点位观测源的目录、字段能力与可复现快照；可形成公开源审计，但不构成产品产能、设备拓扑、信息独占性或 `G2/G3` 通过

## 1. 已验证的平台身份与接口

首页标题和页脚将其标识为“河北省污染源自动监控信息公开系统”，版权所有方为河北省生态环境厅。前端在匿名模式下使用 `X-ACCESS: ANONYMOUS`，同源调用下列公开接口：

| 用途 | 方法与路径 | 本研究用途 |
| --- | --- | --- |
| 河北行政区划 | `GET /online_system/v5/regions/tree?id=130000000` | 企业区县连接 |
| 字典 | `GET /online_system/v5/dictionary` | 行业、企业类型、监测点类型翻译 |
| 企业目录 | `GET /online_base/v5/psInfo` | 启用企业公开母表 |
| 监测点目录 | `GET /online_base/v5/portInfo` | 启用监测点公开母表 |
| 企业可用点位类型 | `GET /online_base/v5/portInfo/findPortTypeAndMonitorTypeByPsId/{psId}` | 小规模点位核对 |
| 公开列定义 | `GET /online_statistics/v5/dataQuery/column` | 同点位字段/单位核对 |
| 公开监测表 | `POST /online_statistics/v5/dataQuery/list` | 仅在选定 `T-026` 点位后保存首版响应 |

公开网页默认只允许查询向前滚动一年，默认数据类型代码为 `2061`；前端源码还标注 `2011` 为实时数据、`2031` 为日数据。`2061` 的精确定义必须以接口列定义或平台字典继续核实，不能只凭代码猜测为小时数据。

## 2. 采集与证据纪律

[采集器](scripts/collect_ps_public.py)只枚举公开网页自身会请求的目录，使用服务端分页、每次请求至少间隔 1 秒，并在 `429/5xx` 时退避。每个原始响应保存：

```text
请求 URL / 查询时间 / HTTP 状态 / Content-Type
ETag / Last-Modified / 响应字节数 / SHA-256
```

运行产物放在 `data/runs/<run-id>/`，结构和复核命令见[data 说明](data/README.md)。Git 不跟踪大体量原始响应；需要归档时应连同 `manifest.json` 一起保存，不能只保留派生 CSV。

## 3. 可用于什么

该公开源可以：

- 形成有截止时点的公开企业与监测点目录；
- 按 `06` 第 5 节检索词发现可能相关的企业/点位；
- 为候选 `T-026` 点位提供公开 ID、公开字段和首版响应；
- 前向测量公开端的颗粒度、缺失、回填、质控和首次可见时点。

它不能单独完成：

- 原计划中的独立内部“企业—产品—生产线—设施—监测点”目录；2026-08-25 已确认该内部来源不存在；
- 产品规格、设计产能或有效产能分母；
- 一对一、共享排口或单设备多排口拓扑；
- 内部/公开同一点位比较或内部信息领先检验；
- 设备状态、产品产量或市场净平衡推断。

接口字段也有一个可复现限制：`portInfo` 请求 `parentCode/parentName` 或区划投影时，服务端当前返回 HTTP 400 和 SQL 别名错误。因此目录采集只请求已验证可用的点位、排放口及生产工序代码字段；区划通过企业表连接，父级设施关系保持未知，不能补猜。

完整性计数按“接口声明行数”和“唯一 ID 数”分别报告。当前接口会对少量点位返回内容完全相同的重复行；采集器保留原始响应，在派生表按 ID 去重，并把重复 ID 写入清单。若同一 ID 的内容冲突则直接失败，不静默选取。

所以派生表中的 `mapping_status` 固定为 `discovery_only_unverified`。即使点位名称包含“高炉”“玻璃熔窑”或“焦炉”，也只能进入人工交叉核验，不能把名称命中升级为 `F` 的核心设备映射。
