## 一条完整流程

已有 13 条种子可以用于暴露缺口，但不能代替完整枚举。当前并行补齐宇宙、经济证据、内部目录、工具存在性和数据时效；之后才逐层收敛：

```text
冻结约束与证据规则
        |
        v
Round 0 封闭 U-MKT / U-ECON / U-OBS / U-PROC
        |
        +-- 现有种子的 Round B/C、W1、B-ENV 可并行推进
        v
T-025a：经济—可观测条件短名单（仍不可交易）
        |
        +-- W2：账户、真实双边盘口、小账户成本与容量
        +-- B-IND / B-MKT：产业最快信息与市场代理基准
        v
T-025：冻结 0-5 个幸存方向；允许 0 个
        |
        v
P3 状态校准 -> P3-S 协议封存 + readiness run
        |
        v
P4 正式前向虚拟跟踪 -> P5 裁决
        |
        v
P6 另行实盘授权（不会自动发生）
```

## 现在并行做三件事

1. **内部数据目录 `T-022`**：按 `06` 导出匿名且稳定的“企业—产品—生产线—设施—监测点”元数据。第一批不要导出全年小时数值；企业真实名称可以不提供。
2. **公开与工具审计 `T-020b/T-021/T-023`**：完整枚举四张 universe，核对产品规格、河北角色、库存/替代和交易所官方 `W1`。这部分由研究端推进，所有外部模型 URL 在独立打开并归档前仍是 `L`。
3. **立即启动 30 天时钟 `T-026`**：选择能在内部与公开环保平台唯一匹配的少量点位，保存同测量窗口的首次可见版本、查询时间和哈希。这里可以提交小规模前向快照；它是“不导出全年数值”的唯一当前例外。

三件事完成前，不训练价格预测模型，不用历史收益挑行业，不向旧三轨模板填事件，也不因某个监测字段漂亮就把方向升为候选。
