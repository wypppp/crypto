## 现在做什么

1. **使用者当前无需准备文件。** 不再要求内部目录、内部点位交叉表或产能母表。
2. **执行 public-only 第一波。** 固定 A01/A04/A05/A07 四个机制、5 个公开点，连续 7 个自然日测量字段语义、数值可见性、缺失、修订和物理一致性；不看价格换点。
3. **七日后先裁决来源本身。** 只允许 `PUBX/PUB1` 初裁；没有多个独立点稳定通过时，不延长实验。即使未来达到 `PUB2`，也只能另提经济映射研究，不能直接进入交易建模。
4. **原 v2 保持阻断。** 旧工具审计可以完善公开事实，但不能解除缺失的产能和设备拓扑。

public-only v1 期间不训练价格预测模型，不用历史收益挑行业，不向旧三轨模板填事件，也不因公开监测字段漂亮就把方向升为交易候选。合格结果允许是所有机制均为 `PUBX`。

当前无需使用者补数据或做人工操作。研究端已把 122 条名称样本、5 点字段语义和 7 天历史当前视图固化。历史快速分支已完成单事件物理分离、三点同时对照、27 组邻近阈值稳健性及最小两阶段信号时效计算：技术 POC 暂时保留，合成物理确认约 5 小时 2 分，不构成交易证据。对同一批数据继续增加模型复杂度不会产生新的泛化证据；剩余增量项是按预注册窗口继续做前向轮询。事后完整的 168 小时不能替代这条前向时钟。

第一日固定窗口已冻结为 4 个完成槽、1 个 `missed`：4 个点的目标行首次观察上界为 `≤+62`，一个点截至 `+80` 无数值；完成槽内未见既有目标数值改写。这个结果仍不足以授予 `PUB1`。

为快速判断思路是否值得继续，已有七日历史当前视图另做了不污染前向实验的诊断：简单多字段规则识别出 A07 停运弱标签中段的 6/12 小时，弱标签外 660 个数值小时零警报；事件窗流速降至事前 6.5%，事件后恢复至 97.7%，三个同时间对照点保持稳定。结论是“技术代理概念初步可行，但泛化、实时性、经济映射和交易 Edge 均未证明”。
