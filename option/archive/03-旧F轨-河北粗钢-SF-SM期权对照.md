| win / loss / false-positive / right-info-wrong-price | 0 / 0 / 0 / 0 |

任一 activation Gate 长期不通过，本轨保持阻断；不得用期货替代。S 轨共享 episode 到 F candidate/admitted 的转化率只作机会频率报告，不能因低频本身淘汰。激活后至少 8 个独立 `matured admitted` 才作阶段裁决：

- resolved 子集的加权 SF/SM 需求方向错误率 `>30%`，或 matured admitted 的 `unverifiable` 率 `>30%`；
- `>=50%` matured admitted 在事后满足冻结的主产区供给市场混杂阈值；
- `>=50%` matured admitted 的执行处置为 `no-trade-no-quote`；
- `>=70%` matured admitted 未形成 `virtual-entry`（已定价、无报价或规则不交易合计）；
- 若两轨 matched virtual-entry 交集至少 4 个，同预算、同基准币和冻结持有规则下，SF/SM 累计净P&L不高于 S 轨；不足4个时本条只能记证据不足；
- 若 F 轨 virtual-entry 子集至少 4 个且累计 all-in 净P&L `<=0`。少于4个时本条证据不足；去掉最佳一笔后的结果只报告，不因右尾收益依赖单一赢家而机械淘汰。
