## 使用规则

- 当前工作不要从本目录开始，也不要执行归档文件中的“从今天开始”“当前执行顺序”等指令。
- 归档模板不得直接复制为正式事件日志。只有某方向通过现行普查全部硬门和 `W2` 后，才按当时协议重新生成模板。
- 需要追溯旧判断、旧字段或历史纠正时才进入本目录；发现与现行文档不一致时，以现行文档为准。
