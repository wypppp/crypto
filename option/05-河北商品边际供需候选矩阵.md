## 0. 先读结论

本轮没有选出可交易方向，也没有任何工具通过 `W2`。矩阵目前只记录第一批跨行业种子发现和初步处置；在 `U-MKT/U-ECON/U-OBS/U-PROC` 逐项母表冻结前，既不声称 Round A 完整，也不据此固定行业范围：

1. 第一批同时审计 13 个商品级机制，不只审计钢铁、玻璃、焦化和纯碱；
2. 新增重点包括氧化铝、PVC/烧碱、尿素、玉米淀粉和再生铅；
3. 钢材本品供给应与钢铁对铁矿石的需求映射同台比较；
4. 水泥、火电等即使设备状态容易识别，也因直接凸性工具或经济映射缺口留在淘汰/工具待发现区；
5. 工具初核已经区分“截止时点前已挂牌”和“注册/未来上市”，详见[官方期权工具注册表](08-官方期权工具注册表.md)；但完整 `U-MKT-v2` 尚未逐项枚举，官方发现只能记 `provisional-W0`。外部模型给出的工具总数 `55/64/75` 互相冲突，因此仍不采用任何总数。

2026-08-24 公开污染源目录快照发现 5,951 家启用企业和 17,408 个唯一启用监测点，首批检索词对 `A01-A13` 均有点位/工序文字命中，详见[公开污染源目录审计](07-河北公开污染源目录审计.md)。这些命中全部保持 `discovery_only_unverified`：它们不证明产品、核心设备、共享拓扑或产能覆盖。

2026-08-25 已确认不存在内部数据或内部样例。此前写为 `I0` 的点位/字段描述全部撤销该等级，只能按公开平台目录或试采事实处理。公开字段可以证明“平台返回过什么”，不能证明设备真实负荷、产量或比市场更早的信息位置。

2026-08-26：本文件"最大待核问题"栏中反复出现的"河北份额/全国产能权重/边际份额"，13 条种子原先一条未填。已另建[11-分母与工具可达性](11-分母与工具可达性.md)，把该栏拆为五列（产量份额、平台可达性、商品化率、库存缓冲、需求侧份额）并逐格核实。第 ① 列已完成，`A07` 因河北份额仅约 4% 降级为方法验证用例；第 ② 列（多省平台可达性）为未验证前提，其成立与否使最优品种由玻璃改为氧化铝。本矩阵不复制该表数值，以 11 为准。

## 3. 已扫描但当前不进入开发

这些方向仍保留记录，避免因点位字段漂亮而反复重开。

| 类别 | 方向 | 当前否决或阻断理由 |
| --- | --- | --- |
| 设备易观测、工具缺失 | 水泥熟料 | 窑头/窑尾很适合识别设备状态，但未发现符合冻结要求的直接成熟买方期权；映射燃料又增加配比与库存层 |

| 经济映射过小 | 河北炼厂状态 -> 全球原油 | 河北单一区域变化相对全球原油平衡通常需要极端规模；进口排期和库存隔断即时需求 |
| 状态不可观测 | 生猪、鸡蛋、饲料 | 污水/排口不能可靠识别存栏、出栏、产蛋或饲料配方；企业加工状态也不等于养殖供给 |
| 状态不可观测 | 田间玉米、小麦、花生、棉花、苹果、红枣 | 企业环保数据不覆盖种植、天气、单产和收获真值 |
| 产品错配 | 铜铝加工 -> 铜/铝需求 | 环保点位通常不直接给出金属净消耗，边角料回用、库存和订单结构影响大 |
| 产品错配 | 棉纺、纸加工 -> 棉花/纸浆需求 | 加工状态与采购之间有库存和产品结构；尤其再生纸与针叶浆合约可能错配 |
| 河北角色弱待证 | 锂电、工业硅、多晶硅上游 | 河北是否为标的边际供给区待证；下游状态传到全国上游商品链条过长 |
| 吞吐不等于库存 | 港口矿石/煤炭扬尘与输送点 | 最多是装卸活动代理，货种、存量、转运和作业调度难以唯一识别 |
| 无直接工具 | 碳黑、TDI、维生素/API、粘胶、钒制品、太阳能玻璃等细分品 | 河北个别细分份额可能有意义，且设备可能可观测；但未发现直接成熟买方期权。只留“工具待发现”旁表 |
| 公司映射稀释 | 细分工业品 -> 海外对标公司 | 上市公司常有多业务、公司事件和地区暴露稀释；只有另建并冻结 `U-T3`，且产品对 EBITDA/现金流的净敏感性、河北地域暴露、套保、垂直一体化抵消、公司混杂及 `W1/W2` 全部过门，才可复活 |
