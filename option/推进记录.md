## 3. 当前执行顺序

S 轨是唯一主工作流；M 轨只在等待数据积累或外部回复时并行；F 轨只核验 Gate，不做策略开发。依赖关系如下：

```text
所有轨：T-000 是进入最终封存和 P4 的共通前提

S：T-004 + T-005 + T-007 -> T-014 smoke run
   T-001 -> T-002 ----\
   T-003 ------------+-> T-015 最终封存 -> T-016 readiness -> P4
   T-004 ------------|
   T-005 -> T-006 ---|
   T-007 -> T-008 ---/

M：T-009 + T-010 -> T-017 最终封存 -> T-018 readiness -> P4

F：T-011 + T-012 -> T-013 -> T-019；完成前始终不激活
```

现在可同时启动且不会污染开发窗口的只有：

1. `T-000`：先冻结开发窗口、事件簇口径、五轴状态和统计分母；
2. `T-004/T-005`：只建立原始留存并各保存一份不可覆盖的样例快照，固定 `Tmeasure/Tavailable/Tseen`、时区、缺失和修订字段，不校准信号；
3. `T-007`：取得 SGX 铁矿石期权账户可达性、合约机制和到期处置的书面/官方证据。

`T-001` 在 `T-000` 完成后立即开始，以匿名企业ID建立企业、厂区、电表与工序映射。

上述三组任务没有产出前，不等待事件、不调期权参数、不把历史上“看起来有效”的案例计入样本。`T-006` 在 `T-005` 完成后立即开始计满30天；`T-008` 在 `T-007` 通过后立即开始计满10个交易日。P4 只有在对应轨的最终封存和 readiness run 均完成后才能启动。
