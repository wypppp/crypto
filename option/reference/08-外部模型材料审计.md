## 1. 总裁决

三份材料加强了普查方法，但没有把任何候选升级为通过状态：

| 材料 | 裁决 | 可吸收内容 | 不可吸收内容 |
| --- | --- | --- | --- |
| LLM1 | 拒绝其完成状态和最终候选；仅保留少量待核线索 | 应比较产业共同信息、关注计划外停复产、区分库存和替代 | 工具白名单、报价/IV/深度、W2 通过、`3+2` 冻结、物质性数字和候选排名 |
| LLM2 | 方法部分有条件吸收；事实和等级逐条重核 | 封闭宇宙、供需角色与可观测实体分离、状态不等于产量、地理定价与替代链、允许 `0` 个幸存者 | `55` 个工具总数、A/S 等级、历史 `Tseen` 重建、未鲜活核验的工具状态和提前冻结的六条候选 |
| LLM3 | 只作遗漏检查和发现线索 | 鸡蛋等未覆盖商品可进入 Round 0 的逐项处置队列 | `64` 个工具总数、无 URL 的产业数字、按“河北非主产区”直接淘汰需求/瓶颈角色、任何执行结论 |

截至本审计：

- 没有商品期权通过 `W2`；
- 没有候选通过 `G0-G6`；
- 当前矩阵只是种子队列，`Round 0` 尚未完成；
- 最终允许 `0-5` 个幸存者，不设最低数量；
- 外部材料中的 URL、数字和“已打开/已核实”声明均未自动升级为本项目的 `F` 级证据。

## 2. 审计边界和证据处理

本文件审计的是主张的一致性、物理因果、时间可行性和与冻结约束的相容性。原材料保留在 [1.md](../../1.md)，不改写其内容。

本次环境无法鲜活访问并封存外部网页，未取得原始响应、访问时间和快照哈希。因此，`1.md` 中的所有外部 URL 和数字至多保持 `L`；专业产业报告在以后独立打开、记录版本和封存后可成为 `M`；官方或法定一手页面只有在同样完成封存后才可能成为 `F`。另一个模型声称“页面已打开”，不等于本项目已取得证据。

外部材料内部的逻辑矛盾可以直接作为否决依据，因为不需要相信任一外部网页。例如，截止日之后才上市的产品不可能在截止日前拥有可测的盘口。

## 3. LLM1：完成状态和最终候选全部拒绝

### 3.1 时间和工具状态自相矛盾

1. 它把声称 `2026-09-02` 才上市的焦炭期权计入 `2026-05-31` 冻结宇宙，见 [1.md 第10行](../../1.md#L10) 与 [第106行](../../1.md#L106)。在当前日期 `2026-08-20`，该产品即使未来确会上市，也只能记为未来待核线索，不能是当前 `W1/W2`。
2. 它称焦炭期权“执行审计已完成”并给出权利金、价差和深度，同时又写“待上市后实测价差”，见 [第219-231行](../../1.md#L219)。这在时间上不可能成立。
3. 它把“获批/注册”“招募做市商”“境内特定品种/QFII 可参与”混同于已挂牌、用户账户可达和当前可执行，见 [第8-15行](../../1.md#L8)。三者分别只能支持待核发现、制度参与范围和潜在线索，不能越过 `W1/W2`。
4. 工具总数自相矛盾：LLM1 给出 `62+`、约 `75` 等口径，见 [第29行](../../1.md#L29)；LLM2 给出 `55`，见 [第289行](../../1.md#L289)；LLM3 给出 `64`，见 [第2587行](../../1.md#L2587)。这些数字不能平均或择一采用，只能由交易所逐产品母表解决。

### 3.2 所谓执行审计不可复核

LLM1 对 FG、RB/HC、J、JM、I 给出权利金、bid/ask tick、IV、持仓、可退出手数和收益倍数，见 [第223-231行](../../1.md#L223)，但没有目标合约月份、方向、行权价、到期日、报价时点、市场数据源、逐档数量或原始订单簿快照。因此：

- 不能证明任何档位在当时存在双边报价；
- 总持仓或总成交不能证明目标行权价可退出；
- “一手低于1万元”没有按冻结的单事件风险预算计算；
- “限产 +5%/+10% 得到 2.5-3x”没有标的路径、IV 情景、期限衰减和真实退出 bid；
- 不能据此建立 `T2`，更不能判定 `W2` 或右尾门通过。

其“执行审计已完成”“所有幸存者都满足”“最终冻结 3+2”及相应 CSV 交付声明整体无效，见 [第219行](../../1.md#L219)、[第231行](../../1.md#L231) 和 [第248-258行](../../1.md#L248)。仓库中也没有材料声称已经落成的 CSV。

### 3.3 经济和工艺映射错误

| 原主张 | 裁决 | 原因 |
| --- | --- | --- |
| 以河北板带材占比支持“RB/HC 合并候选” | 拒绝 | `RB` 是螺纹钢长材，不能由板带材占比支持；高炉/粗钢状态还需分别映射连铸、轧线和产品结构。原主张见 [第198-201行](../../1.md#L198) |
| 焦炭、焦煤、甲醇是联产品 | 拒绝 | 焦煤是投入，焦炭是主产品；焦炉煤气、煤焦油、粗苯等才是典型副产品，甲醇可能是焦炉煤气的下游。原主张见 [第53行](../../1.md#L53) |
| 纯碱到氯碱/PVC 是简单串行链 | 拒绝 | 纯碱与氯碱首先是不同工艺，集团循环经济或公用工程耦合不能代替物料平衡。错误链见 [第1696-1712行](../../1.md#L1696) |
| C4 项目证明丙烯角色 | 拒绝 | C4 项目不证明 C3/丙烯产能、投产状态或商品供应。线索见 [第452-480行](../../1.md#L452) |
| 炼油规模证明 PX 潜力可入候选 | 拒绝 | 炼油能力不证明存在 PX 装置、规格、实际产量或可外售量。原主张见 [第145行](../../1.md#L145) |
| 河北原矿吨数直接映射 DCE/SGX 进口矿 | 拒绝 | 原矿品位、选矿回收率、精粉规格和运输市场均不同；更合理的机制是河北铁水活动改变进口矿需求。原数字比较见 [第708-732行](../../1.md#L708) |

LLM1 的“占比 × 停产比例 × 库存折扣 × 替代折扣”没有统一实物单位、事件期限、可释放库存或可达替代量，见 [第49行](../../1.md#L49) 和 [第150-160行](../../1.md#L150)。它最多是主观情景算术，不能称为供需冲击下界，更不能把数量百分比写成价格影响。

## 4. LLM2：吸收方法，不接受提前裁决

### 4.1 已吸收的方法改进

以下内容与冻结约束相容，已并入协议 v0.2：

- 先定义并冻结 `U-MKT/U-ECON/U-OBS/U-PROC`，再逐项处置；
- 重点排污单位集合不等于河北经济实体全集；无监测点只表示不可观测；
- 把产品、交割规格、地理定价市场、库存、运输和替代链写入物质性审计；
- 明确 `O0 观测 -> O2 设备状态 -> O4 产品影响 -> O5 市场影响`，禁止跨级；
- 静态排污许可、环评、产能置换和法定披露主要用于企业—产线—设备—排口映射，不证明实时生产；
- 二手产业数据可作为 `M` 级市场共同信息和估计区间，不能成为生产真值或位置领先证明；
- 计划内玻璃冷修/点火已被产业机构系统跟踪，不应作为位置优势事件；相关材料见 [第1957行](../../1.md#L1957) 和 [第2095-2115行](../../1.md#L2095)；
- 最终结果允许为 `0`，不得因为目标数量而凑候选；
- 海外公司期权必须单列 Tier 3，并对 EBITDA/现金流暴露、地域、套保、垂直一体化和公司混杂单独过门。

### 4.2 仍须拒绝或降级的部分

1. “已经扫描全部55个工具”不能成立，因为缺逐产品成员表、截止时点和排除日志，且与另外两份材料的总数冲突，见 [第274-305行](../../1.md#L274)。
2. 页面 URL、搜索结果或动态行情页不能证明当前期权流动性、账户权限和万元风险预算适配；所有工具仍需分别过 `W1/W2`。
3. 在点位、设计产能、共享排口和状态映射未知时给候选 A/S 级或 Round 3 PASS，属于用未知项完成裁决。例如纯碱被写成 `Round 3 = PASS`，见 [第1686-1693行](../../1.md#L1686)，应退回阻断。
4. 候选不能只因河北产业存在而“强保留”。集团宣传、产业园项目和拟建项目只生成待核产品—设备线索，不证明有效在产产能或市场边际性。
5. 利用现在可查询、可能已修订的滚动一年历史数据回溯 `Tseen` 不可行。材料建议重建过去事件的 `T0 -> Tseen -> Tpub -> Tprice`，见 [第2507-2515行](../../1.md#L2507)；若没有当时首次可见版本和轮询日志，历史数据只能校准设备状态，不能证明历史位置领先。

## 5. LLM3：仅作遗漏检查

LLM3 没有为核心数字提供可直接审计的 URL，工具总数 `64` 也与另外两份材料冲突。其价值是提醒 Round 0 不能被既有工业候选绑架：

- 鸡蛋可作为 `U-MKT/U-ECON` 的逐项遗漏检查，见 [第2599-2601行](../../1.md#L2599)；但当前 CEMS/污水点位不能证明蛋鸡存栏、产蛋率或淘汰节奏，工具也未通过 `W1/W2`，因此不能进入状态开发。
- 不得仅因河北不是主产区就淘汰碳酸锂、多晶硅、贵金属或热带原料，见 [第2603-2608行](../../1.md#L2603)。必须先检查河北是否存在集中需求、加工瓶颈或联产品角色；检查后仍可因物质性、可观测性或工具不合格而淘汰。
- “河北原矿占比高”不能把铁矿石归为与进口矿合约同品供给；该行只能触发规格和地理市场核对，见 [第2595-2597行](../../1.md#L2595)。

## 6. Mysteel 与公开环保平台意味着什么

外部意见指出 Mysteel 等机构已经周度跟踪钢厂铁水、玉米淀粉、油厂、纯碱和其他商品的开工、产量或库存。若逐项独立核实，这既是有价值的聚合校准源，也是最重要的竞争基准之一，但不能推出两个极端结论：

1. 不能因为市场已有周度调查，就立即断言内部小时数据无价值。小时数据仍可能更早识别计划外单厂或区域状态变化。
2. 不能因为内部数据快于公开周报，就断言存在交易 Edge。边际定价者可能通过付费快讯、单厂调研、采购/贸易电话网络和盘面更早知道。

因此竞争对象必须拆成：

| 基准 | 要回答的问题 |
| --- | --- |
| `B-ENV` | 内部 `INT-CEMS` 是否比同点位公开环保镜像更早、更细、更少修订？ |
| `B-IND` | 内部冻结信号是否早于产业机构的等效付费快讯、单厂调研或聚合报告？ |
| `B-MKT` | 在 `Tsignal` 前，期货、现货或 IV 是否已经出现超出冻结噪声阈值的反应？ |

“公开平台约5天后才更新当天日均值”目前仍是 `L`。即使以后证明属实，也只支持内部数据相对公开环保镜像的时效优势，不证明领先真正的边际定价者。

位置领先应以前向保存的首版数据计算：

```text
lead = min(Tequiv, Tproxy) - Tsignal
```

正数只是必要条件；是否有交易价值还要看 `T2` 的真实期权 ask、退出 bid、费用、IV 和剩余价格残差。

## 7. 对当前候选和推进顺序的影响

本次材料不改变任何候选的通过状态。它只改变研究方法和否证顺序：

1. 钢铁—进口铁矿石需求、玻璃、纯碱、螺纹、热卷、焦煤等继续只是种子或待核行，不因外部排名获得优先权；焦炭/热卷的期权状态冲突保持 `L` 级待核工具线索，在 `U-MKT` 冻结和官方鲜活核验前尚未取得 `W0`。
2. 玻璃计划冷修/点火降为市场共同信息；只有计划外停窑、异常降负荷、延迟或提前复产才可能形成待测事件。
3. 纯碱污水总口、VOC 干燥口或共享公用工程不能直接推出纯碱产量；必须先找到核心工艺节点和一对一设备映射。
4. Mysteel 247 家钢厂周度铁水调查若核实，可用于聚合校准和 `B-IND`；不得把它当成边际定价者最早知道的时点。
5. 下一步先完成 `T-020b` 封闭宇宙、`T-021/T-022/T-023` 公开物质性/元数据/W1、`T-026` 同点位30天环保对照；只有条件短名单形成后，才对其执行 `T-027` 产业竞争基准和昂贵的 `T-024 W2`。

在这些工作完成前，正确状态仍是：`B0` 不交易，P4 未开始，没有 admitted 前向事件，也没有可以冻结为正式观察轨的商品方向。
