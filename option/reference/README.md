## 证据晋级

参考文件中的 URL、数字或“已打开”声明不会因被收录而自动成为项目事实。专业产业材料须独立打开并按协议封存后才可能成为 `M`；官方或法定一手页面须保存原始响应、发布时间、访问时间和快照哈希后才可能成为 `F`。
