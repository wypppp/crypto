# M 轨：特定稀土/磁材管制与许可执行 → MP 买方期权

> 状态：弱保留；前向虚拟盘准备期
> 事件编号：`M-YYYYMMDD-NN`
> 核心假说：中文原文的产品范围/许可语义在 MP 正股盘前定价后仍留有可通过常规时段期权表达的解释残差

## A. 硬边界

- 只纳入与 MP 已有产出、已宣布近期产出或磁材投入直接重合的稀土/永磁产品。
- 镓、锗、锑、泛化工事故、与 MP 无直接产品关系的公告不得纳入。
- MP 期权不能盘前成交。`T2` 只能是美股期权常规时段内首个合格双边报价。
- 同一政策影响多个产品或多个股票仍只算一个事件。

## E. 滚动汇总与淘汰判定

| 指标 | 当前值 |
| --- | --- |
| 全部候选政策/数据事件 | 0 |
| rejected 候选数 | 0 |
| admitted 事件（含所有执行/市场混杂状态） | 0 |
| matured admitted / open / resolved / unverifiable | 0 / 0 / 0 / 0 |
| `pending` / `no-trade-rule` | 0 / 0 |
| admitted 有市场混杂事件数 | 0 |
| `no-trade-already-priced` 数 | 0 |
| `no-trade-no-quote` 数 | 0 |
| `virtual-entry` 数 | 0 |
| 产品范围/方向正确数 | 0 |
| 真实 ask/bid 净盈利数 | 0 |
| 累计净P&L | 0 |
| 去掉最佳一笔后净P&L | 0 |
| 最佳单笔净收益倍数 | NA |
| win / loss / false-positive / right-info-wrong-price | 0 / 0 / 0 / 0 |

至少 8 个独立 `matured admitted` 后才作阶段裁决。位置和执行条款使用全部 matured admitted；产品/方向正确率使用 resolved 子集并另查不可验证率；P&L 只用 virtual-entry。触发任一条即淘汰：

- `>=70%` matured admitted 在期权开盘前已有 `Tequiv`，且正股盘前已完成主要反应；
- resolved 子集的产品范围/MP净方向错误率 `>30%`，或 matured admitted 的 `unverifiable` 率 `>30%`；
- `>=50%` matured admitted 的市场混杂状态不为 `none`；
- `>=50%` matured admitted 的执行处置为 `no-trade-no-quote`；
- `>=70%` matured admitted 未形成 `virtual-entry`（已定价、无报价或规则不交易合计）；
- 若 `市场混杂=none + resolved + virtual-entry` 子集至少 4 个，其中 `>=70%` 在冻结 `Tout` 的 all-in 净P&L `<=0`；不足4个时本条只能记证据不足；
- 若 virtual-entry 子集至少 4 个且累计 all-in 净P&L `<=0`。少于4个时本条证据不足；去掉最佳一笔后的结果只报告，不因右尾收益依赖单一赢家而机械淘汰。

事件不足 8 个时只能标记“证据不足”，不得与 S/F 轨合并凑数。
