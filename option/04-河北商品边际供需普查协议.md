## 1. 普查要回答的问题

本普查不寻找“河北产量最大的行业”，也不寻找“环保数据最容易拟合的行业”。它寻找：

> 河北一次未被边际定价者预期的设备状态变化，能否在指定期限内显著改变某个具体商品的边际供需平衡，并在首个可执行时点仍留下可由买方期权捕获的价格残差。

候选的最小单位固定为：

```text
具体商品和规格
× 河北的供给、需求、瓶颈或联产品角色
× 可观测核心工序
× 未预期状态变化及持续时间
× 明确的买方期权
```

“钢铁”“玻璃”“化工”不是候选。类似“河北多厂高炉意外降负荷持续至少48小时 -> 进口铁矿石边际需求下降 -> 指定铁矿石看跌期权”才是可检验候选。

最终幸存者没有最低数量要求。`0` 个是完全合格的普查结果；不得为凑满研究队列而放宽任何硬门。

## 2. 已确认的数据边界

### 2.0 2026-08-25 来源更正

使用者没有内部 `INT-CEMS/INT-AIR` 系统，也没有内部点位目录、企业用电或产品产能母表。企业和点位观测唯一可用来源是河北省污染源自动监控信息公开系统。以下 `2.1/2.2` 保留的是 2026-08-20 普查启动时的旧输入前提，用于审计为什么原路线被否证，不再代表当前可用能力，也不再产生任何 `I0` 证据。

公开平台已经提供的企业、点位、字段和前向响应可以形成独立的 `U-PUB-OBS` 来源审计；它们不能被改名为内部数据，不能证明数据独占性，也不能自行给出产品产能、核心设备拓扑或市场物质性分母。交易工具仍只用交易所和监管机构公开官方来源核验。

### 2.1 企业工序级环保数据 `INT-CEMS`

使用者可查询全河北可能产生污染的企业，数据按企业、生产设施或监测点逐小时提供；当日可见截至上一完整小时的数据，只能查询向前滚动一年。不同污染源和企业字段不完全相同，已确认可能包括：

- 生产设施工况；
- 正常、停运、故障、校准、超标、维护和数据有效性等标记；
- 废气量或污水量；
- 污染物实测/折算浓度及小时质量排放量；
- 氧含量、烟气流速、温度、湿度和压力；
- 能显示烧结机、高炉、焦炉、窑头、窑尾、锅炉、玻璃熔窑等工序的监测点名称。

这些字段获准进入研究。它们不是已经验证的产量真值，也不是自动成立的交易 Edge。系统中的“生产设施工况”若与其他环保字段同源、由企业人工填报或由平台规则生成，只能作为弱标签，不能作为独立验证。

### 2.2 环境站网络 `INT-AIR`

使用者可查询国控、省控及其他站点的逐小时数据，包括 PM10、PM2.5、SO2、NO2、O3、CO、AQI、TVOC、TSP 和原字段名 `O38`；站点有经纬度、站点类型、质控和可见时间。“其他站点”可能包括企业厂界、园区微站和乡镇站。

环境站主要用于区域共同冲击、气象混杂、疑似异常排放和企业排口状态的一致性校验，不默认承担单厂产量估计。`O38` 在字段定义核实前不得自行改名。

### 2.3 目前没有的数据

- 没有已确认的企业用电数据；
- 没有连续、独立的小时产量或负荷真值；
- 没有历史逐小时“当时首次可见版本”的完整档案；
- 没有任何已经通过产品存在、账户可达和真实深度三道门的商品期权白名单。

滚动一年数据只能用于设备状态开发和稀疏公开事件校准，不能重建历史信息领先。位置领先只能由现在开始保存的不可覆盖快照前向验证。

## 3. 封闭宇宙与扫描范围

### 3.1 Round 0：宇宙定义与冻结

`v1@2026-08-20T13:00:00+08:00` 保留为未完成的历史 vintage，不回写 2026-08-24 才取得的目录成员。经 2026-08-24 用户裁决，现行版本新建 `v2@2026-08-24T17:05:00+08:00`；以下 Round 0 均指 `v2`。“全维扫描”只表示对下列预先定义的封闭宇宙完整枚举，不表示扫描世界上所有可想象的商品、企业或金融工具。

| Universe ID | 成员定义 | 完整性证据 |
| --- | --- | --- |
| `U-MKT-v2` | 截止时点前，上期所、上期能源、大商所、郑商所、广期所、SGX、CME、ICE、LME 官方产品目录内与商品价格直接相关的标准化期权；期货仅作代理价格；本 vintage 不含公司期权和事件合约 | 交易所逐项成员表、正式挂牌日、当前合约、规则 URL、访问时间与快照哈希 |
| `U-ECON-v2` | 河北所有可能生产、消费、阻断或联产 `U-MKT-v2` 对应商品的经济实体与产品 | 统计、产能置换、环评、排污许可、法定披露和行业名录的去重成员表 |
| `U-OBS-v2` | `INT-CEMS/INT-AIR` 实际可查的企业、厂区、设施、监测点和环境站 | 稳定匿名 ID 目录、首次可见时间、历史长度与字段版本 |
| `U-PROC-v2` | 上述商品的核心工序、核心设备及其治理设备/排口拓扑 | 产品—生产线—核心设备—排口映射表，未知关系不得猜测 |

`U-ECON` 与 `U-OBS` 必须分开：没有监测点只能说该产能当前不可观测，不能说产业不存在。Round A 只有在四张成员表有版本、截止时点、来源和排除理由后才可称“完整”。当前矩阵是第一批工作队列，不是已证明完整的宇宙。

按 2026-08-25 更正，`U-OBS-v2` 没有可访问的内部来源；`U-ECON-v2` 缺少完整产品/产能来源；`U-PROC-v2` 缺少可证实的产品—设备—排口拓扑。因此原定义的 Round 0 v2 保持 `source_scope_blocked`，公开平台目录不得替补这三张表。若未来要把公开平台本身定义为信号源，必须另建目标和门槛不同的研究 vintage，而不是回写 v2。

### 3.2 市场端反向扫描

发现宇宙覆盖：

- 郑州、大连、上海、上海国际能源和广州期货交易所的商品期权候选品种；
- SGX 中与中国实体供需直接相关的商品期权；
- CME、ICE 等境外市场中与河北供需可能存在直接映射、且个人账户可能可达的商品期权；
- 当商品工具不合格时，可提出业务暴露足够纯且期权链可执行的海外上市公司线索；它不属于当前 `U-MKT-v2`，不得据此声称本轮市场宇宙完整；
- 只有在结算条件与实体事件精确对应时，才可提出规则清晰的事件合约线索；它同样不属于当前 `U-MKT-v2`。

期货只用于发现标的和记录 `Tproxy`，不能替代冻结约束所要求的买方凸性表达。

海外上市公司期权为 Tier 3 后备，不与直接商品期权并列。仅当直接商品工具失败，且公司扫描前已冻结的纯度规则同时覆盖产品对 EBITDA/现金流的净敏感性、河北事件的地域暴露、套保、垂直一体化抵消和公司事件混杂，才允许新建带独立截止时点、交易场所、成员和排除规则的 `U-T3` vintage。收入占比高不自动等于利润敏感性高；`U-T3` 未冻结前，Tier 3 线索一律保持阻断，之后仍须单独过 `W1/W2`。事件合约若被启用，也必须先建立独立的 `U-EVT` vintage；它们不追加入 `U-MKT-v2` 或旧前向分母。

### 3.3 河北角色正向扫描

每个商品分别检查四种角色：

| 角色 | 含义 | 典型因果链 |
| --- | --- | --- |
| 直接供给 | 河北生产与合约经济对象相同或高度可替代的商品 | 核心设备状态 -> 本品供应 -> 本品价格 |
| 集中需求 | 河北是某原料的重要边际消费者 | 下游核心设备 -> 原料消耗 -> 原料价格 |
| 加工瓶颈 | 河北掌握短期难替代的中间环节 | 瓶颈状态 -> 全球/全国上下游可用量 |
| 联产品/副产品 | 一个可观测主工序同时改变另一商品供应 | 主设备状态 -> 联产品收率/供应 -> 标的价格 |

不得以行业总产值或企业数量代替对应产品的可映射产能、消费能力或边际份额。“区域同步冲击”是事件聚类方法，不是第五种经济角色。

### 3.4 明确纳入但允许快速淘汰的领域

黑色及钢材、建材、有色冶炼、能源与炼化、煤化工、氯碱、基础化工、化肥、橡胶、农产品加工、油脂压榨、造纸、畜牧加工，以及河北可能控制的细分工业品都进入发现宇宙。没有直接成熟凸性工具、环保数据不覆盖核心过程或河北变化无法影响合约经济对象的方向，保留淘汰记录而不进入开发。

## 4. 证据标签

矩阵中的每个判断必须标注证据等级：

| 标签 | 含义 |
| --- | --- |
| `I0` | 使用者明确确认的内部数据事实；允许使用，但不是独立外部验证 |
| `F` | 研究者已打开并保存的官方、法定披露或可追溯一手来源；含 URL、原始发布时间、访问时间和快照哈希 |
| `M` | 可定位版本的专业产业数据/二手市场共同信息；可用于库存、开工、产量和定价者已知信息的保守区间，不能证明内部信息领先 |
| `L` | 外部模型、搜索摘要或他人提供的 URL/数字线索；本研究尚未独立打开和封存，不得通过任何硬门 |
| `H` | 待验证假说；不能在评分中按已知事实计分 |
| `U` | 尚未调查或当前无法核实 |
| `X` | 已有证据反驳或命中硬淘汰条件 |

“业界常识”“河北是制造业大省”以及模型记忆一律不升级为 `F`。公开事实优先使用国家统计局、河北省统计局、工信部门、生态环境环评/排污许可、交易所和企业法定披露等来源。

Mysteel、隆众、卓创、SMM、汾渭等专业产业数据可以 `M` 身份进入 G1 保守下界，但必须记录发布商、产品/版本、样本范围、口径、原始发布时间、URL、访问时间和快照哈希。只能使用区间和敏感性计算；若合理区间的两端会改变 Gate 结论，该门保持 `U`，不得为了让 Round B 收敛而选有利数字。

每一个矩阵结论另存 `Universe_ID / Claim_ID / Evidence_ID / source_class / market_visibility / estimate_range / last_verified_at / disqualifying_condition`。“另一个模型说已打开页面”不等于本研究已核实。

## 5. 工具状态单独分层

工具端不使用“有期货，所以有可用期权”的推断：

| 状态 | 通过条件 |
| --- | --- |
| `W0 发现` | 在当前已冻结并激活的 universe vintage 内发现一个可能相关的期权工具；只允许进入工具核验队列。公司期权或事件合约只有在独立 `U-T3/U-EVT` 冻结后才可能取得 `W0` |
| `W1 存在` | 同日官方产品页、现行规则、当前合约列表、到期和行权机制均已保存 |
| `W2 可执行` | 账户可达；目标 DTE/行权价有实时双边报价和退出深度；一手成本适配 `1万元AUM × 单事件风险比例`；完成 USD100k/USD300k 总权利金容量审计 |

截至本版本，没有任何工具通过 `W2`。现有 SGX 铁矿石官方 URL 只使其进入待鲜活核验队列；SF/SM 期权仍按未核实处理。

“获批/注册/宣布将上市”不等于截止时点前已挂牌；QFII/境外交易者可参与名单也不等于使用者账户可达。两者均不能越过 `W1/W2`。

## 6. 七道硬门

硬门不能用总评分补偿。任一道被证伪，候选即淘汰；未知则保持阻断。

### G0：凸性工具门

- 至少有一个 `W0` 表达，才能进入长名单；
- 达到 `W1` 且通过 `G1a` 后，只允许做价格盲的状态可行性开发和小样本数值抽取；不得建立正式事件分母、调交易参数或称为候选校准；
- 达到 `W2` 且其余经济/可观测硬门通过后，才可进入 P3 状态校准和正式协议准备；
- 只有 P3-S 封存与 readiness run 完成后，才可建立 P4 正式前向交易日志。

### G1：边际物质性门

此门分两次执行，避免 Round B 与 Round C 循环依赖：

- `G1a 市场级可行性`：用 `U-ECON` 的同规格有效产能/消费能力，问合理意外冲击在扣除缓冲后是否仍可能有物质性。连市场级上界都很小时立即淘汰。
- `G1b 可观测净冲击`：G2/G3 完成后，只用可唯一映射且状态可识别的核心产能重算。最终通过 G1 以 `G1b` 为准。

对一个合理而非灾难幻想的意外事件，`G1b` 估计：

```text
意外净平衡变化下界
= Σ(唯一映射设备设计产能 × 保守状态变化 × 持续时间 × 产品/投入产出系数)
 - 合约期限内可立即释放的库存
 - 可快速替代的跨省/进口产能
```

保守下界不足以改变指定合约期限内的边际平衡，淘汰。静态产量或消费占比本身不能通过此门。

所有数字必须换算到同一商品实物单位和指定合约时间窗口。库存只扣事件窗口内相对基准可增量释放的数量，替代也必须是同规格、同期限内可到达的数量。禁止用“河北占比 × 停产比例 × (1-库存缓冲率) × (1-替代率)”这类无统一物理口径的百分比相乘替代实物平衡表。

不设跨品种通用的 `0.5%` 或 `3天` 门槛。判定必须相对于该品种事件前预期平衡、预测误差、库存/流量和候选期权 DTE，不得把数量冲击百分比直接写成价格影响百分比。

### G2：核心工序可观测门

- 监测点必须能绑定指定产品的核心生产或消费设备；
- 必须记录一对一、多设备共享排口或单设备多排口的拓扑；
- 按可唯一映射的设计产能计算覆盖率，不按企业数计；
- 公共锅炉、共享火炬、污水总出口和治理设备只能作为辅助证据，除非另有事实证明其为不可绕过的主线瓶颈。

覆盖率分母来自 `U-ECON` 中同规格、同地域、同 as-of 的有效在产产能，计划、已拆除和长期闲置分开报告；分子只计入产品、核心设备和排口关系已确认的产能。必须同时报告“唯一映射、共享排口、已知不可观测、产能未知”四类份额。

产能缺失不得从分母删除，也不得退化成按企业数计算。使用排污许可副本、环评、产能置换和法定披露外挂匹配；仍无法匹配时 G2 保持 `U` 或只报保守下界。共享排口对应产能不得重复计数。

### G3：设备状态识别门

必须区分生产变化与维护、校准、故障、风机/风门、烟道切换、治理效率、燃料变化和数据回填。状态输出先限制为：

```text
正常 / 显著降负荷 / 停运 / 启动或复产 / 维护校准 / 无效 / 未知
```

工况字段可作弱标签。公开确认的停复产、环评验收、产能置换、事故和企业公告可作异源校准锚点；校准集只验证实体状态，不验证信息领先。

证据链必须分层保存，不允许跨级：

```text
O0 原始观测值和质控
 -> O1 传感器/监测点是否有效
 -> O2 具体设备状态
 -> O3 核心工序状态
 -> O4 指定产品的产量或消耗影响
 -> O5 指定地理定价市场的净平衡影响
```

例如，通过 O2 不代表通过 O4；预测模型也不能替代中间层的物理和经济证据。

### G4：经济因果门

必须能冻结产品规格、自用/外售、库存、合同、采购/交付时滞、联产品收率和替代来源的保守规则。中间未知层过多，或监测对象与合约经济对象明显错配，淘汰。

### G5：位置与定价残差门

边际对手必须具体到产业采购、贸易商、套保盘、产业调研和跨市场套利盘。每个事件保存：

```text
Tmeasure, Tavailable, Tseen, Tsignal, T0,
Tequiv, Tpub, Tproxy, T2, Tout
```

上述是字段集合，不预设时间顺序。`Tsignal` 是事件前已冻结的状态规则首次满足的时点；若要求连续三个小时，就不得把第一个小时的 `Tseen` 当成信号时间。模型、阈值、方向映射和合约选择算法必须在事件前按版本冻结；事件级 `T0` 只冻结本次解释、事件簇和算法输出。

`Tequiv` 是边际定价者可得的首个“等效且可行动”信息时点，可来自带时间戳的付费快讯、单厂调研或其他可审计渠道；事件前必须冻结“等效”所需的产品、方向、规模和持续时间。不可观测时记 `unknown`，不得用较慢的公开周报代替。

领先公开新闻不够；若产业盘已同步知道，或在 `T2` 前期货/IV 已完成主要反应，则只有情报价值，没有交易价值。

每个候选必须建立三层共同信息基准：

| 基准 | 必须记录 |
| --- | --- |
| `B-ENV` 公开环保镜像 | 全国/河北/市级平台的具体 URL、同点位字段、聚合颗粒度、首次可见时间、更新频率、修订和质控 |
| `B-IND` 产业情报 | Mysteel/隆众/卓创/SMM/汾渭等对应产品、样本数、覆盖区域、调查频率、发布时刻、付费等级和事件快讯机制 |
| `B-MKT` 市场代理 | 现货、期货、隐含波动率的原始数据商、场所、合约、时区、bar 粒度、交易所时间戳、缺失/修订和快照哈希 |

Mysteel 247 家钢厂周度铁水调查等信号若经核实，会是强竞争基准；但公开周报不自动代表边际定价者的最快信息。还必须记录付费快讯、单厂调研、采购/贸易电话网络和盘面本身。只对比“我们的小时数据 vs 公开周报”会系统性高估 Edge。

外部材料所称“公开环保平台约5天更新一次、只有日均值”已被本次平台接口和小时模板试采否定为不可直接采用的概括。三轮试采只夹定了少量公开点位的可见区间；因为不存在独立内部端，它不能证明任何内部领先，也没有继续累计双端 30 天时钟的含义。

领先时长统一按 `min(Tequiv, Tproxy) - Tsignal` 记录，正数才表示本系统先看到；必须同时保留价格混杂和无法确定等效信息时点的情形。滚动一年历史修订数据可以校准 O0-O4，但不能重建当时 `Tseen/Tsignal`，因此不能用历史回溯证明位置领先。

### G6：执行与右尾门

入场按真实 ask、退出按真实 bid，计入费用、汇率、滑点、未成交和 IV 变化。买方期权本身不自动证明右尾有利；每次必须用预注册的标的变化 × IV 变化情景网格验证收益倍数，并在自动行权或转成期货头寸前强制退出。

买方期权的小账户入场成本是权利金、费用和不可退换汇成本，不得把标的期货保证金误加到正常买入期权的建仓成本。但若可能自动行权或转为期货，必须通过强制退出与 DNE/券商 cutoff 规则消除保证金尾部风险。

## 7. 过硬门后的排序方法

只有不存在 `X` 且关键字段不再是 `U` 的方向才评分。六项各 `0-3` 分：

| 代码 | 维度 |
| --- | --- |
| `M` | 意外净平衡变化的物质性 |
| `O` | 核心工序可观测性及产能覆盖 |
| `C` | 状态到商品平衡的因果清晰度 |
| `I` | 相对边际定价者的信息残差 |
| `E` | 期权小账户可执行性和容量 |
| `R` | 事件低频尾部性与买方期权非对称性 |

排序先看最低单项，再看六项乘积；不使用加权平均。任何未知写 `?`，不得用主观中间分补齐。这样，“经济影响巨大但产业盘已先知道”和“状态识别完美但不影响商品价格”都会被最低项挡住。

## 8. 五轮普查流程

### Round 0：Universe Freeze

先填充并冻结 `U-MKT/U-ECON/U-OBS/U-PROC`。只建成员表、来源和排除日志，不评分、不看收益。直接工具清单与河北经济实体清单独立构建，然后求交集，避免一开始就围绕已知行业或已知工具找理由。

### Round A：工具和河北角色发现

对已冻结宇宙逐品种记录河北的直接供给、需求、瓶颈和联产品假说。产出长名单和明确无关项，不训练模型、不看收益。

### Round B：公开边际物质性审计

对长名单核实具体产品规格、地理定价基准、交割品级/地点、设计/有效产能、消费量、库存、进出口、运输时滞、跨区及进口替代和历史合理冲击。先执行 `G1a`；市场级上界都很小的方向淘汰。

### Round C：企业-设备-监测点覆盖审计

元数据目录可与 Round B 并行建立；只对通过 `G1a` 的方向做详细点位样例和数值抽取。建立：

```text
企业 -> 厂区 -> 产品 -> 生产线 -> 核心设备
     -> 治理设备 -> 排口/监测点 -> 设计产能 -> 共享关系
```

此轮只判断可观测性和覆盖，不用价格筛选点位；完成 G2/G3 后执行 `G1b`。

### Round D：工具、竞争者与前向可证伪性审计

完成 `W1/W2`，明确边际定价者和其信息渠道，建立 `B-ENV/B-IND/B-MKT`，设计 `Tsignal/Tequiv/Tpub/Tproxy/T2` 前向实验。Round B/C 可在工具网络核验阻断时继续，但只能形成“经济—可观测条件短名单”，不得叫最终候选。最终只允许 `0-5` 个通过全部经济/可观测硬门和 `W2` 的方向进入 P3 状态校准；每个方向只有在 P3-S/readiness 后才另建 P4 正式日志和分母。

## 9. 建模纪律

普查阶段禁止：

- 用历史价格选择行业、点位、污染物或阈值；
- 在所有监测字段上搜索与收益最相关的组合；
- 把同一浓度、流量和机械计算出的质量排放量当三份独立证据；
- 把系统工况字段同时当训练标签和独立验证结果；
- 用滚动一年修订后数据声称历史可交易领先；
- 因现有 S/F 日志已经投入工作而提高其评分。

首版状态识别只使用物理一致性、设备自身分位基线、持续性阈值、变点检测、多点位一致性和跨厂同步性。需要机器学习时，必须按企业和时间双重留出，并报告未知/不可验证率，而不只报告分类准确率。

## 10. 停止与冻结规则

- 本轮由后来被否证的数据前提触发；任何既有种子方向均不享有优先通过权，且当前统一受来源范围阻断；
- Round 0-D 完成后冻结候选集合，最多 `0-5` 个进入 P3 正式状态校准；`0` 个时不得强行补位；
- 未来只有新增数据类型、正式新增可执行凸性工具，或某项关键 `F` 证据被推翻，才重开扫描；
- 新增企业或同类监测点只更新覆盖率，不自动重开行业扫描；
- 普查不改变 `B0` 不交易，也不自动改变供给侧维护模式；是否提高长期研究优先级须在幸存者形成后另行裁决。
