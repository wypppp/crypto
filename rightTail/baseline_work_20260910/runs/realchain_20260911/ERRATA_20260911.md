# 勘误 · 真链对照首轮

本目录所有原有文件保留原字节。完整勘误见 `../realchain2_20260911/ERRATA_20260911.md`，与本目录相关的有三条：

1. **退出码**（E1）：`parallel` 与 `resume_serial` 的未捕获异常在 `runs.jsonl` 里实际记为 `exit=1`，
   不是「不在 0/1/2/3 之内」。问题在于它与「判定不通过」撞码、且没有 abort / footer。
2. **491473 的分类**（E6）：`serial.json` 里记的 `state_validation_failed` 来自两次 TLS EOF（出场身份调用、恢复复读），
   按规格 v1.17 应为 `data_missing` / `validation_status=unavailable`。原记录不追改。
3. **不要执行本目录的 `run_compare.sh`**（E5）：它会清空本目录 `runs.jsonl`、覆盖原始日志，
   且子运行全失败时仍退出 0。替代入口是 `../../realchain_tools/run_compare.py`。
