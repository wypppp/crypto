### 7 目标可达性硬门
必须填三个量，缺一条本项作废：
- **A** = 扣全成本后、未加杠杆的年化算术收益：____（**分母是什么？**____）
- **s** = 同一分母口径下的年化波动：____
- **f_放行** = ____ ← **乐观上界，不是你打算下的仓位**
  `f_跳空 = 0.25 / ℓ`，ℓ = **单位敞口在该跳空事件中的损失率**（单场所永续、场所归零 ℓ=1/L → f≤0.25L｜双腿同场所 ℓ=2/L → f≤0.125L｜做多现货、标的归零 ℓ=1 → f≤0.25）
`f_放行 = min(f_跳空, u/Σ(1/Lᵢ))`，两项同为**资本占比**单位。u≥0.25 时跳空帽恒绑定，u 不承重
  **ℓ 必须写出来并说明那个跳空事件是什么**（哪个场所／对手方／标的归零）
- **C_abs** = 该策略以**元**计的最大可部署资本：____（不是比率，是元）
  > **禁止**在此处填自设仓位上限。第 7 条是上界检验，下注的 Kelly 分数属阶段 4、尚未指定。

判定（`f_半Kelly = A/(2s^2)`）：
> **`g(f)=fA-(fs)^2/2` 是二阶近似，只许杀，不许放。**
> 通过必须用精确式：`g = L*E[ln(1+f*R)]`，L=年事件数，R=逐事件净收益分布。
> 25% 跳空帽保证每个候选都有一个离散 -25% 尾 => **二阶式对每个候选都高估 0.05-0.08/年**。
> 二阶式算出 <门槛 -> 直接 STOP（真实值只会更低）；算出 >=门槛 -> **必须给出收益分布并精确重算**。
> **精确 g = ____**（写出逐事件收益分布与年事件数 L）
- `A/s ≥ S_需要(k)`？ □
- `g(min(f_半Kelly, f_max)) ≥ 1.2036/k`？ □
- **即使乐观上界仍不能达标 → STOP**；否则最多 PROBE

**k 必须写明并说明理由，不得默认为 3。** README §0 的措辞是「**允许** 2–3 条」——允许，不是要求。
