## 第 0 题 · 先回答这个，答不出就别写卡

**目标不是"有正 edge"，是 1 万元在 3 年内变成 111 万元。**

**引理 2**：`g ≤ fA` ⟹ `f ≥ 1.2036/A`，代入容量硬门

> 复核：pump.fun T+5m 可执行容量中位 $79.73 ≈ 570 元 ⟹ 必要 A ≥ **2,344%**。不是"容量小一点"，是差三个数量级。

**`A < 4.8144·ℓ` 或 `C_abs < 133.6万/A` → 立即 STOP，不填其余任何字段。**
批次 02 的 11 张 STOP 里有 6 张只用这两条就判死了，其中 3 张只需要 ℓ 一个数。

先给三个量，给不出或够不着就**不要写这张卡**：

- **A** = 扣全成本、未加杠杆的年化算术收益（**写明分母**：单腿名义？gross？占用资本？差 2 倍以上）
- **s** = 同一分母口径下的年化波动
- **f_放行** = **乐观上界，不是你打算下的仓位。禁止填自设仓位帽。**
  `f_跳空 = 0.25 / ℓ`，ℓ = **单位敞口在该跳空事件中的损失率**（单场所永续、场所归零 ℓ=1/L → f≤0.25L｜双腿同场所 ℓ=2/L → f≤0.125L｜做多现货、标的归零 ℓ=1 → f≤0.25）
  `f_放行 = min(f_跳空, u/Σ(1/Lᵢ))`，两项同为**资本占比**单位。u≥0.25 时跳空帽恒绑定，u 不承重
  **ℓ 必须写出来并说明那个跳空事件是什么**
- **C_abs** = 该策略以**元**计的最大可部署资本（**不是比率，是元**）

**引理 3（带止盈止损的候选，0 分钟 0 数据先算这个）**：
`p₀ = S/(G+S)` 盈亏平衡胜率｜`R̄(p) = p·G − (1−p)·S`｜`λ_min = 1.2036/ln(1+f·R̄)`
`λ_min` 远超该形态可能的事件率，且已有**同一入场条件下**的 p 上界 → STOP。
> `p₀` 只给所需胜率，不会脱离入场条件自动构成死因。禁止用无条件价格路径的命中率裁决带条件入场的候选；Arm M 的 58.2% 误判即源于此。

**引理 4（ℓ 的正确取法）**：`ℓ = max(1/L, x_跳空)`
无对冲方向性持仓遇 −x 跳空时损失 = f·x，`f ≤ 0.25/x`，**与 L 无关**。只写 `ℓ=1/L` 只覆盖场所归零，
对持有期 ≥ 小时档的方向性敞口**是错的**。BTC 参考：−40%(2020-03)｜−30%(2021-05)｜−15%(2022-06)｜−6.84%(2025-10)。

判定三条，缺一即 STOP：
1. `A/s ≥ S_需要(k)`（k>1 时 `S_需要 = 1.792·√((1+(k−1)ρ)/k)`，**ρ 必须写数值**：ρ=0.3、k=3 时每条需 **1.309** 而不是 1.034）
2. `g(min(f_半Kelly, f_放行)) >= 1.2036/k`，`f_半Kelly=A/(2s^2)`
   **`g(f)=fA-(fs)^2/2` 是二阶近似，只许杀，不许放。**
   通过必须用精确式：`g = L*E[ln(1+f*R)]`，L=年事件数，R=逐事件净收益分布。
   25% 跳空帽保证每个候选都有一个离散 -25% 尾 => **二阶式对每个候选都高估 0.05-0.08/年**。
   二阶式算出 <门槛 -> 直接 STOP（真实值只会更低）；算出 >=门槛 -> **必须给出收益分布并精确重算**。
   > 反例（2026-08-30 实测）：228 次 +2.0473% / 12 次 -25%，A=166.80%、s=91.32%、f=1、C_abs=200万、存续 10 年。
   > `A/s=1.8264 > 1.792` 过；二阶 `g=1.2510 > 1.2036` 过；容量过。
   > **但精确 `g = 228ln(1.020473) + 12ln(0.75) = 1.1686`，三年终值 99.9 万，差 11 万。**
3. **`C_abs ≥ min(f_半Kelly, f_放行) × 111万`** ← **容量硬门**

**引理 5（三道门的等价重述，0 数据，用来先划可行域）**
把三条判定解开，可行域只有三个不等式（k=1，`S=1.792`）：

```
mu >= 1.792 * sigma          (Sharpe 门)
sigma >= 3.583 * l           (跳空帽给波动率一个**下限**)
C_abs >= 99.4万 / sigma  元   (容量门，**与 sigma 成反比**)
```

| ℓ | 形态 | σ 下限 | μ 下限 | C_abs @σ下限 |
|---:|---|---:|---:|---:|
| 0.025 | 单场所永续 L=40 | 9.0% | 16.0% | 1,110 万 |
| 0.10 | 单场所永续 L=10 | 35.8% | 64.2% | 278 万 |
| 0.20 | 双腿同场所 L=10／20% 跳空 | 71.7% | 128.4% | 139 万 |
| 1.00 | 现货可归零／全额担保 | 358.3% | 641.9% | 27.8 万 |

**两个反直觉但正确的结论：**
1. **跳空帽给波动率一个下限**——σ 太小 → 半 Kelly 要的 f 太大 → 撞跳空帽。**低波动策略不是更安全，是够不着。**
2. **C_abs 与 σ 成反比**——低波动策略需要的**绝对容量反而更大**。

σ 低于下限时不是不可行，而是 f 被 f_放行 卡住、**需要更高的 Sharpe**（σ=20%、ℓ=0.1 时需 S=2.66）。
> ⚠ **不要把可行域压成一个点。** 「年化 100–180%、容量 ≥$175k」只在 σ=0.8 时成立，
> 而 σ 本身由 ℓ 决定下限。**必须用你自己的 ℓ 查上表，不得套用某一档的数字。**
> ℓ=1 时 σ 下限 358%，σ=0.8 根本过不了它自己的跳空约束。

> **第 3 条是新的，因为上一版没有它就被两家审计各构造出一个反例穿过去了。**
> f 是比率、C_abs 是绝对额。一个 A=520%、s=145%、f=0.25、容量 2,500 元的候选能过第 1、2 条，
> 但 `dW/dt → A×C_abs = 13,000 元/年`，**线性不是指数**，三年终值 4.9 万。
> 维持 f=0.25 到 111 万需要 27.75 万可部署资本 —— 是它如实填写的 111 倍。
> **注意：P6 第 4 条「为什么大资金不来做」奖励小容量（容量小是最强的结构性理由）。

> **A 或 s 拿不到就明说「需要跑脚本，X 小时」，不要编。** 这是可接受答案——**但仍然要交这张卡**。
> 上一版这里与「给不出就不要写这张卡」直接矛盾。**以本句为准：任何候选都要留下卡与判决，
> 够不着就判 STOP 并写明死因。**协议 `D_搜索账本` 要求记录全部尝试、永不删除；
