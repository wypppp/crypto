## 1. 候选流程（顺序不可调换，小时上限硬性）

**第 0 步 · 读一手规格（含在案头 4h 内，不可跳过）**
读所交易标的的官方规格，写下：**这个价格由什么决定？什么时段由什么源决定？**
> 此步若早存在，HIP-3 第 1 天即死。见 `C_死亡触发事实.md`。

**第 1 步 · 查场所成本表**（`A`）→ 得 **δ** 与 **周转上限**。**表中数据必须在使用当日重验**——v1 的 Polymarket 行在写下当天即已失效。

**第 2 步 · 候选卡（案头上限 4h）**
1. 具体交易：何时观察／下单／交易什么／何时退出
2. 收益来源：信息／风险承担／流动性补偿／市场分割／制度摩擦
3. 为什么大资金不来做（结构性理由）
4. 独立于我们回测的证据
5. 历史数据可得性（**用于可行性判断，不作为放行闸门**）
6. 成本、容量、杠杆、尾部风险区间
7. **目标可达性硬门（v3.0 重写）**：给出**逐事件净收益分布 R**（不是 μ/σ）、事件率 **λ**、**C_abs（元）**、**存续期**。
   路径模拟：起始 1 万 → 触及 5 万注入 10 万 → 3 年，报 **P(W₃≥111万)**、**P(归零)**、中位终值。
   **每步 `f = min(f_目标, C_abs/W)`——容量进路径，不再是独立闸门。**
   **R 的定义（P10 反例强制）**：R 必须是**按真实持仓时间、从账户权益流水算出的全成本净收益**。
   `R = 价格收益 − 每笔交易成本 − ∫(持仓期内融资/借券/funding)`。**只扣"每事件 bp"是错的**——
   反例：价格 +5.2%/+5.4%、交易费 0.2%、融资 1%/日×7 日 ⟹ 模拟器看到 +5.0%/+5.2% 得 **P=100%**，真实三年终值 **501 元**。
   ⟹ **必须有每笔的进出场时间戳**，否则本项不可填。
   **归零阈值必须显式写出**（最小可交易资本／追保线／最小手数），**不是 0**。
   > `f=0.70 归零 65.2%` 复核 = `1−(92/93)^97 = 64.96%`——**由 n=1 的那条 −147.8% 单独决定**；
   > `f<1/1.478=0.677` 时 IID 自助下数学上不可能归零，故 `f=0.55 归零 0.01%` 来自一个未写出的 100 元地板。
   **必报**：P(达标) 与 P(归零) 各带自助置信区间｜**无注资对照组**｜块自助（IID 会低估左尾）｜R 是毛还是净。
   > 注资使口径不可比：f 越高越早撞 5 万门槛、越多领到 10 万外生资本，**f 排序里含"领钱速度"而非收益能力**。
   > 同理 `f=0.55 > f=0.40` 是**阈值型泛函的性质**（远目标下最优下注高于对数最优），不是策略证据。
   > **已废止**（全部由「g≥1.2036 + 半 Kelly」导出，判据一换即失效）：k｜Sharpe 门 1.792｜半 Kelly f｜25% 跳空帽｜引理 1／2／5。
   > **仍有效**：引理 3（`p₀=S/(G+S)`，带止盈止损的 0 数据预筛）｜存续期｜延迟可行性（并列必要条件，排第 3 位，先算收益与容量）。
   > 二阶式 `fA−(fs)²/2` 与精确式 `λ·E[ln(1+fR)]` 降级为**诊断量**，不再是闸门。
8. **最便宜最快的证伪方法，及其小时/金额成本**
9. **时序可执行性**：`信息ₜ → 信号ₜ → 决策ₜ → 执行ₜ₊Δ`。任一步不成立 → STOP

**每条结论写成**：`结论 → 依赖前提 → 证据 → 可证伪条件`
**任一前提被撤销 → 依赖结论自动 UNRESOLVED。禁止改一句话继续。**

**第 3 步 · 三档判决**：`STOP` / `PROBE`（限时限额事实核查）/ `LIVE-KILL`（进入 ≤1,000 元实盘证伪）
**批次级检查**：本批是否共享某个已证伪前提？是 → 批量淘汰。

## 2. 阶段职责（收益不得混算）

| 阶段 | 只回答 | 预算 | 禁止 |
|---|---|---|---|
| 案头 | 有没有明显理由不值得继续 | 4h | 建管道 |
| 工程/历史 | 可行性量级、成本、容量 | **≤20h** | **当作放行闸门** |
| **≤1,000 元实盘证伪** | **只判执行事实**（见下） | ≤1,000 元 | **按盈亏判定** |
| 扩容 | 收益是否随资金衰减 | — | — |

### 2.1 LIVE-KILL 的判定规则（必须事前冻结）

**只按执行事实判定，绝不按盈亏判定。** 1,000 元样本对 Sharpe≈1 的策略几乎无统计信息量；按盈亏判会随机杀掉好候选、提拔坏候选。

**逐条勾选，任一不过即 STOP：**
1. 账户可开、可入金、该市场对本人可交易
2. 计划规模能成交（对照候选卡的容量估计）
3. 实付费率 ≤ 候选卡预估的 1.5 倍
4. 实际滑点 ≤ 候选卡预估的 2 倍
5. 无异常拒单／延迟／API 行为
6. **仓位能按计划退出**（进得去出不来 = STOP）
7. 信号在真钱下确实出现过（不是"赚了钱"，是"信号按定义触发过"）

> **本阶段的盈亏明确不构成 edge 的证据，不得计入任何统计样本，不得用于候选排序。**

## 3. 释放 10 万的条件

① 账户达 5 万 **且** ② 该 sleeve 已通过 ≤1,000 元实盘证伪段且未被证伪 **且** ③ 已完成执行校准。
**①单独成立不释放**：零 edge 策略触及 5× 的概率为 **11.1%（亏50%止）～19.8%（亏99%止）**（`H`）。

## 4. 必须每次可见的三个基线

- **零 edge 完成 100 万的基线概率 = 0.81%（亏50%止）～2.70%（打光本金）**。研究计划要跑赢的不是 0%，是约 1–3%。
- **成功本身仍不构成 edge 的证据**：达标是单一样本，无法与那 0.81–2.70% 的分支区分。**但该分支比 v2 原文小 4–12 倍，故这条自我否定弱于原表述，不消失。**
- **统计验证在此量级不可得**：`T_验证/T = 2.9433/lnM`，**与时钟长度无关**（放长时钟同时降低所需 Sharpe，两效应精确抵消）。现口径 M=37 ⟹ **0.815**；调低目标反而更差（M=18.5 ⟹ 1.009）。`T_验证<T` 需 **M>19×**。故不以统计显著性放行。
