# 附录 E · 统计协议

## 1. 留出集的作用域（v1 裁决）

**留出期属于全研究计划，不属于单个候选。**

- 保留 **最近 6 个月** 为**计划级最终留出期**，任何候选在进入历史验证前不得触碰。
- 每个候选的开发与走步只允许使用留出期之前的数据。
- **同一留出期最多解封 2 次**（首次 + 一次复核）。解封记录写入 `D_搜索账本.md`。
- 第 2 次解封后，任何新候选必须等待新的、真正未见的数据积累，或改用前向只读积累。

## 2. 留出失败后的处置（事前冻结）

> **原候选记 STOP。任何修改后的信号视为新假说 ID，不得复用同一留出集证明自己。**

这一条防的是：看失败 → 改参数 → 再看同一留出集。

## 3. 多重检验

- **账本全局记录**（`D`），**修正按事前定义的假说族分层**，不对历史全部方向机械做全局 Bonferroni（会造成大量 Type II）。
- 假说族在进入历史验证**之前**定义并冻结，不得看到 p 值后再划分。
- 族内用 **BH 控制 FDR**；跨族不做机械修正，改为在最终证据评级中记入定性警示。

## 4. 进入历史验证前的一次性冻结清单

假说 / 交易方向 / 时点 / 标的池与排除规则 / 真实可用信息集 / 成本·funding·滑点·容量模型 / 参数搜索空间 / **最小经济效应量 δ** / 主指标 / 失败条件 / **已尝试的方向·信号·参数计数**

## 5. 检验设计

发现集开发 → **滚动走步** → 留出集（按 §1 规则）→ 对重叠样本、制度变化、资产相关性、多重试验调整 → **收益集中度检查**（是否集中于单一资产、单一时期或极少数尾部事件）。

## 6. 判据

- 主判据：**扣全成本后 `μ > δ`**，不是 `μ > 0`。
- 状态空间必须完备：`STOP` / `CONTINUE` / `INCONCLUSIVE` / `MODIFY`。
  **检查：均值 ≤0 且 CI 跨 0 落在哪个状态？** v3–v6 曾出现无状态可落的漏洞。
- 顺序检验：**只设一个最终确认点**，或事前分配 alpha spending。禁止"40 窗口看一次、80 窗口用同一 95% CI 再看一次"。

## 7. 功效必须先于设计

`n` 由 δ、σ、聚类结构、缺失比例、同时检验数与目标功效共同决定。**先做不使用确认性结果的功效分析，再决定 N**，不得先固定周数。

**已知的结构性事实（`frontier.py` 可独立复算）**：
- 全 Kelly 下达标所需年化 Sharpe = `sqrt(2·lnM/T)`；本项目 = **1.55**
- 验证一个 Sharpe=S 的策略需 `7.849/S²` 年 = **3.26 年**，**超过 3 年期限（比值 1.09）**
- 两式均在"固定年化 Sharpe"口径下与事件率无关；该口径是代数结果，不是独立事实
- **推论：目标与"先统计验证后部署"在 3 年窗口内不完全相容。** 这个冲突不靠调地板掩盖，写在此处每次可见
