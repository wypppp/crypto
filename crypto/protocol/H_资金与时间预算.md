# 附录 H · 资金路径与时间预算

## 1. 资金路径与真实所需年化（2026-08-30 裁决）

```
阶段1: 1 万 ──5×──> 5 万        ln = 1.609
                 ↓ 释放 10 万
阶段2: 15 万 ──7.40×──> 111 万   ln = 2.001
合计对数增长 3.611 / 3 年 = 1.2036 /年
```

> **所需年化 = 233%**（税前口径；若按 20% 税则约 256%），不是 116%。
> 116% 只在"11 万于 2026-08-30 全额投入"的假设下成立，**那不是使用者的路径**。
> 分段注资使要求**变高**：本金晚到，且前 1.34 年只有 1 万在工作。

阶段1 预计耗时 **1.34 年（16 个月）**，阶段2 剩 1.66 年。

## 2. 与可验证性的冲突（不掩盖，每次可见）

| | |
|---|---|
| **半 Kelly 所需组合 Sharpe** | `sqrt(1.2036/0.375)` = **1.79**（全 Kelly 为 1.55，但 edge 是估计值，理性用半 Kelly） |
| 验证该 Sharpe（单次检验） | `7.849/1.79²` = **2.45 年** |
| **含 17 条前史 Bonferroni** | **4.58 年** |
| **所有候选场所的存在时长** | HL≈3 年、HIP-3 数月、pump≈2.6 年、Polymarket<2 年 —— **全部短于所需样本** |
| 期限 | 3.00 年 |
| **结论** | **统计验证在此量级不可得，前向后向皆不可得。故 v2 不以统计显著性放行。** |

（对比：11 万一次性投入时比值为 1.70。目标更激进反而使比值改善，因为所需 Sharpe 更高、更易与零区分。**但高 Sharpe 策略也更稀有。**）

## 3. ★ 释放条件「1 万赚到 5 万」的缺陷

**零 edge = 财富为鞅**（非对数零漂移——后者算术期望为 +σ²/2，是正 edge）。停时期望：`1 = P·b + (1-P)·a` ⟹ **`P = (1-a)/(b-a)`**：

| 止损点 | 零 edge 下触发 5× 的概率 |
|---|---:|
| 亏 50% 停 | **11.1%** |
| 亏 70% 停 | 14.9% |
| 亏 90% 停 | **18.4%** |
| 亏 99% 停 | **19.8%** |

> **一个完全没有 edge 的策略，有 11–20% 的概率把 1 万做到 5 万。**
> **同样地：零 edge 完成 11万→111万 的基线概率 = 5.2%–9.8%。研究计划要跑赢的不是 0%，是约 10%。**
> **推论：若三年后真的达标，也无法与那 10% 的分支区分——成功本身不构成 edge 的证据。**
> 单用它当扳机 = **用一次抛硬币决定是否投入 10 万**。
> 故 `README.md` §3 将释放条件改为三条同时满足。

## 6. v2 新增：研究预算以小时计价

三个月 × 40 小时 ≈ **500 小时**。即使按 50 元/小时计价，已花掉约 **25,000 元研究成本，去保护一个 10,000 元的风险预算**。

> v1 的成本会计**只记钱、不记小时**——所以它把工程定价为免费、把下单定价为昂贵，于是一直买工程。
> **"三次死亡的触发事实都在工程之后才被发现"不是执行失误，是这套定价的必然产物。**

v2 改为：案头 4h → 工程 ≤20h → **≤1,000 元实盘证伪**；到首笔交易总预算 **≤200h**。
时钟从首笔实盘起算，故 200h 上限是**唯一逼你开始的约束**。
