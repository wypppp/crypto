# T+5m 首触发止盈/止损执行实验

> 状态：冻结后执行；历史探索性物理可行性检验，不授权实盘。  
> 重要限制：止损方向由既有样本的最高价曲线启发，因此本样本不能成为最终确认样本；即使通过，也必须在 2026-07-25 之后毕业、结局完全成熟的新样本上复验。

## 1. 固定执行时点与仓位

- 特征/决策截止：T+5m；
- 假设计算和广播耗时：15秒；
- 模拟成交时点：T+5m15s，以该时点前最后一个 canonical 池状态报价；
- 主策略仓位：每币500美元；只有执行时点 `0.05 × 报价储备美元值 >= $500` 才入场；
- 诊断仓位：每币250美元，对应容量门槛250美元；
- 路径观察：入场后24小时。

## 2. 成交公式

PumpSwap按恒定乘积池处理。设入场状态基础币储备为 `X`、报价储备为 `Y`，美元仓位换算为报价币 `B`。

- 实际事件费率：最后/当前事件的 `lp_fee_basis_points + protocol_fee_basis_points + coin_creator_fee_basis_points`；
- 额外执行损耗：入场和退出各100 bps，用于未建模的优先费、MEV、报价变化和舍入；
- 入场进入曲线的报价额：`q = B / (1 + total_fee_rate + 0.01)`；
- 买到基础币：`tokens = X × q / (Y + q)`；
- 在未来状态 `(Xt,Yt)` 整仓卖出的曲线报价：`Yt × tokens / (Xt + tokens)`；
- 退出净报价再乘 `1 - total_fee_rate - 0.01`，并按事件小时报价币美元价换算；
- 策略收益倍数 = 退出净美元 / 初始美元仓位。

这是包含双边池冲击和费用的历史报价模拟，但不把我们的入场永久写入后续历史池状态，仍是近似反事实。

## 3. 冻结主策略

- 仓位/门槛：$500 / 容量至少$500；
- 止盈：整仓可退出价值达到2.0x；
- 止损：整仓可退出价值降到0.5x或以下；
- 超时：入场后4小时；
- 先发生者优先；同一事件同时满足时按止损处理；
- 止盈收益封顶2.0x，不享受跳空超过目标的额外收益；
- 止损按首个触发状态的实际整仓退出价值结算，保留向下跳空；
- 4小时内均未触发时，按4小时前最后一个交易状态结算；没有后续交易则按入场状态立即往返价值结算。

## 4. 冻结诊断网格

- 仓位/容量：`$250/$250`、`$500/$500`；
- TP：1.5x、2x、3x、5x；
- SL：0.7x、0.6x、0.5x、0.4x；
- 超时：1h、4h、24h。

共96个组合。网格只用于判断是否存在值得新样本复验的候选，不能覆盖主策略裁决，也不能把网格最佳值当确认性收益。

## 5. 裁决

主策略需同时满足：

1. 至少100个可执行入场；
2. 平均净ROI严格大于0；
3. 按UTC日期block bootstrap 10,000次的单侧95% ROI下界严格大于0；
4. 三个时间段（05-01–05-31、06-01–06-30、07-01–07-24）至少两个平均ROI为正；
5. 每周可部署名义本金至少10,000美元。

任一失败则主策略“不通过”。诊断网格只有在某一组合同时满足平均ROI>0、bootstrap下界>0、三段至少两段为正时，才可登记为“待新样本验证”；否则止损方向整体关闭。

## 6. 不得事后修改

- 不得在结果返回后改变15秒延迟、100 bps双边损耗、仓位、容量门槛或主TP/SL/超时；
- 不得删除无交易、跳空止损或极端亏损样本；
- 不得用现货最高价替代整仓退出价值；
- 不得把96格中最高收益直接称作策略证据；
- 若事件实际费率缺失，使用100 bps链上费率替代，并保留额外100 bps执行损耗。
