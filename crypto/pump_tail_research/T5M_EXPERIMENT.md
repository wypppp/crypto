# T+5m 延迟选币前向回测协议

> 状态：冻结后执行的历史前向检验；不授权实盘。  
> 冻结时间：在 `09_t5m_features.sql` 全量结果返回前。  
> 与 `crypto/roadmap/毕业代币筛选前向实验.md` 分开记账：本实验只使用毕业后五分钟内的 PumpSwap 行为，不检验迁移前左尾筛选。

## 1. 单一问题

能否只用毕业时至 T+5m 已经可见的 canonical PumpSwap 链上状态，把随后仍可从 T+5m 现货价上涨 10x 的 precision，从无条件基线 6.7369% 提高到显著高于毛盈亏平衡线 10%，同时保留可执行容量？

不同时搜索入场延迟、标签倍数或持有窗口。本轮只允许：

- 入场：T+5m；
- 标签：`remaining_max_5m >= 10`；
- 结局窗口：`[T+5m, T+30d)`；
- 入场容量：T+5m 最后 canonical 池状态的 `0.05 × 报价储备美元值`。

## 2. 冻结特征

只使用 T+5m 截止时可见的数据。禁止使用代币名称、symbol、社交数据、未来交易数、未来最高价、p7d、p30d 或任何全样本事后聚合。

### 静态特征

- 报价币是否 WSOL；
- 毕业初始报价储备美元值；
- coin creator 在当前毕业之前的 canonical 毕业次数；
- 毕业 UTC 小时与星期的正余弦编码。

### 五分钟价格与池状态

- 30秒、1分钟、3分钟、5分钟最后价格 / 毕业价；
- 五分钟内最高、最低价格倍数及最高点秒数；
- T+5m 报价储备美元值、5%容量、相对初始储备变化；
- T+5m 状态陈旧秒数；
- 五分钟内加池/撤池次数及报价币流入流出。

### 五分钟真实付费活动

- 买/卖笔数、报价成交额、净买额和买入占比；
- 0–1m、1–3m、3–5m 三段的交易数和成交额；
- 独立交易钱包、独立买家、独立卖家；
- 官方 Mayhem agent 之外的笔数、钱包数与成交额；
- coin creator 自己的买/卖笔数与成交额；
- 单钱包最大成交额占比和成交额 HHI。

所有成交额从报价腿按小时价格重建，不使用 `amount_usd`。

## 3. 时间前向切分

固定三个扩展窗口，不随机打乱：

| Fold | Train | Validation | Test |
|---|---|---|---|
| 1 | 2026-05-01–05-31 | 2026-06-01–06-14 | 2026-06-15–06-28 |
| 2 | 2026-05-01–06-14 | 2026-06-15–06-28 | 2026-06-29–07-12 |
| 3 | 2026-05-01–06-28 | 2026-06-29–07-12 | 2026-07-13–07-24 |

日期边界均按 UTC，结束日的次日为 exclusive。每个 fold 只用当期 train 拟合；validation 只确定分数阈值；test 只结算一次。

## 4. 冻结模型与阈值

主模型：`HistGradientBoostingClassifier`，参数固定为：

- `learning_rate=0.05`
- `max_iter=200`
- `max_leaf_nodes=15`
- `max_depth=3`
- `min_samples_leaf=100`
- `l2_regularization=1.0`
- `random_state=20260824`

训练时正例权重设为 `N_negative / N_positive`。数值缺失仅用当期 train 中位数填充，并增加缺失指示器。

诊断模型：L2 Logistic Regression，标准化后拟合，正负类 balanced。它不参与主裁决。

每个 fold 的主阈值固定为 validation 分数的第90百分位，即 validation 最高10%。该数值阈值原样应用到下一段 test，test 实际选择率允许因漂移改变。诊断选择率固定为最高 1%、2%、5%、10%、20%，不用于改主阈值或挑模型。

## 5. 主指标和通过条件

合并三个 test 的首次样本外预测，主裁决必须同时满足：

1. 主模型选中至少100个代币且至少10个正例；
2. 逐币 precision 的单侧95% Wilson 下界严格高于10%；
3. 按每币 T+5m 5%容量加权的 precision，经按日期 block bootstrap 得到的单侧95%下界严格高于10%；
4. 三个 fold 至少两个的点估计 precision 高于10%；
5. 被选集合的 T+5m 容量中位数不低于100美元。

任何一条不满足即“不通过”。AUPRC、ROC AUC、诊断选择率、特征重要性只用于解释，不能推翻主裁决。

## 6. 防后视和解释限制

- SQL 全量结果返回后不得增加、删除或变换特征来改善本轮结果；任何新特征属于新实验。
- 不根据 test 选择模型、阈值、止盈倍数或延迟点。
- 标签是最高现货价上界，尚未扣入场冲击、退出冲击、费用、夹子和止盈失败；即使通过，也只允许进入更严格的成交仿真，不等于可交易。
