## 0. 元规则

### 0.1 什么被冻结、什么可以立即中断

**A. 冻结（执行期间不修改）**

- 当前阶段的目标与出口标准
- 已预注册的实验规则、数据截止日、未触碰的测试集
- 总时间预算、小时上限与"不实盘"边界

**B. 允许立即中断并修正（走附录7变更日志，写清触发原因）**

- 法律、平台资格、职业身份合规、账户/钱包安全问题
- 数据泄漏、公式或代码错误、合约规格理解错误
- 数据源失效，导致实验已不可解释
- 路线图内部逻辑矛盾

**C. 只进 Parking Lot（附录6），阶段5前不展开**

- 新框架、新维度、别人的方法论意见、"是不是还缺点什么"
- **"我发现了一个更好的框架"不是中断理由。** 这是唯一需要严防的一类。

### 0.2 其余规则

1. **只问具体问题**：答案能直接填进当前模块的笔记才算合格问题。
2. **出口问题脱稿验收**：答得上就前进，答不上只补对应缺口。
3. **产出物大于阅读量**：没有笔记 = 没学。
4. **小时上限强制前进**：每阶段有小时上限（见日程表）。**打满上限就进入下一阶段，缺口记 Parking Lot。时间变多不等于范围变大。**
5. **想法变化是预期内的**：记进笔记，到阶段2/4-A/5 的决策点兑现。
6. **零策略始终在牌桌上**：任何阶段都可以得出"暂不进入""只做被动配置"。

### 0.3 四种收入模型 —— 先分清你在测哪一种


| 模型                         | 核心产物                       | 收入来源                     | 本路线的处理                         |
| ------------------------------ | -------------------------------- | ------------------------------ | -------------------------------------- |
| **A. 自有资本交易者**        | 可重复的信号、执行与风险记录   | 扣成本后的交易P&L            | **本路线：交易研究轨**               |
| **B. 自有资本研究者/投资者** | 投资备忘录、组合配置、监控决策 | 持仓重估、收益分配、风险溢价 | **本路线：投资研究轨**               |
| C. 卖研究/数据/内容/工具     | 报告、订阅、咨询、产品         | 订阅费、咨询费、产品收入     | **路由到创业线，本路线不做**（见下） |

**关于 B**："靠发现机会赚钱"这个说法漏了后半段。自有资本研究者**仍然必须决定**：买什么、什么价格买、买多少、相对什么基准、什么情况下退出。它不是"研究"，是"研究 + 组合决策"。因此 A 和 B 共享 Mandate、基准、风险和退出纪律，只有**收益机制、数据、工作节奏和验证方式**不同。

**关于 C**：这是一条独立的创业/职业路线，需要回答客户是谁、为什么付费、交付频率、公开档案、披露责任——**不要混进自有资金路线**。但也不要当它不存在：结合你的背景（喜欢做攻略、英语可用、AI放大器、海外可露脸、愿公开真实数字），"英文加密研究内容/工具"与你的百万级目标的关系，很可能比 A 和 B 都更直接。**处理方式：记入 Parking Lot 并注明"归创业线"，本路线不展开。**

### 0.4 两条轨道并不对称（这是最容易搞错的地方）


|                 | 交易研究轨（机制1–7）                                 | 投资研究轨（机制8）                                           |
| ----------------- | -------------------------------------------------------- | --------------------------------------------------------------- |
| 论点验证周期    | 天到周，**7周内可被证伪**                              | 数月到数年，**7周内不可能被证伪**                             |
| 本轮能测什么    | 流程可行性**+ 初步统计证据**                           | **只能测流程与意愿**，测不出"我判断得准不准"                  |
| 与你约束的匹配  | 受 22:00–06:00 盲区、10分钟延迟、无自动化限制**较大** | 受这些限制**很小**                                            |
| 与1万本金的匹配 | 差（1万元做交易，收益绝对值无意义）                    | 同样差，但**研究能力与资本规模无关，可迁移到更大资金和C模型** |

**结论：阶段5比较两轨时，禁止用"哪个跑出了更好的数字"来比。** 交易轨会有数字，投资轨不会有——这不代表投资轨更差。合法的比较维度只有三条：**能不能做出来、愿不愿长期重复、硬门槛是否通过。**

## 阶段1-A：加密市场结构 —— 与A股的差异（12h）

主线是**我从A股带来的哪些默认假设在这里失效**，而不是"加密是什么"（行业层基础知识两份报告已覆盖）。

### 核心差异清单


| 你在A股的默认假设                     | 加密市场的现实（注意限定词）                                                                                                                                                                                                                                                      |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 每天4小时交易，有休市                 | 7×24全年无休；周末与凌晨照样出大行情，且流动性更薄。**对你意味着：每天有8小时结构性盲区**                                                                                                                                                                                        |
| 有涨跌停、有熔断                      | 无涨跌停，但**并非"无任何限制"**：交易所仍有价格保护带、风险限额、维护停机、暂停提现、ADL（自动减仓）                                                                                                                                                                             |
| T+1                                   | T+0。**做空是另一件事**：需借币或用衍生品，受借币可得性、保证金、借贷成本与资金费率约束                                                                                                                                                                                           |
| 券商托管+第三方存管，券商倒闭股票还在 | CEX 是**交易所托管**（你不控制私钥，持有的是对平台的账户权益/合同债权）。平台倒闭**可能造成重大损失和长期冻结**，但结果取决于资产隔离、法律权属、是否被再质押、清偿顺位——不是简单"归零"。**研究题**：FTX 债权人最终按什么口径、拿回了多少？这个细节会改变你对"交易所倒闭"的理解 |
| 人民币计价                            | USDT/USDC 计价。**稳定币不是无风险现金**：谁发行、储备是什么、脱锚过几次                                                                                                                                                                                                          |
| 融资融券是少数人的工具                | 杠杆原生。永续成交量常年数倍于现货，**市场结构由衍生品主导**（清算连环与资金费率会反过来影响现货）                                                                                                                                                                                |
| 内幕/资金动向不透明                   | **链上账本**公开（余额、转账、DEX成交、部分协议持仓）。但 CEX 内部账本、订单流、真实实体身份**并不公开**；Coinglass 的持仓量/清算来自交易所API而非链上。链上更透明 ≠ 参与者动机与平台负债更透明                                                                                  |
| 有证监会单一监管                      | 全球监管拼图。平台注册地、你的居民身份、职业身份、出入金路径是**互相独立**的风险变量                                                                                                                                                                                              |
| 流动性整体均匀                        | 极端分层：BTC/ETH 深度极好；小市值币挂1万元单就能砸出可见滑点                                                                                                                                                                                                                     |

### ⚠️ 写机制8时必须先回答的问题（v1.2 新增，这是投资轨的生死题）

外部意见把"基本面重估"当成可落地的既定路线，**但它跳过了一个前置问题：在加密市场，"判断对了基本面"靠什么机制转化成价格？**

股票里这条链是硬的：现金流 → 分红/回购/被收购 → 财报日强制披露 → 估值收敛。**加密里这条链大多是软的**：

- 多数代币对协议收入**没有可执行的索取权**（分配靠治理决定，随时可改）
- 没有财报日、没有强制披露、没有收购要约——**没有任何强制收敛机制**
- 因此"我对了"到"价格涨"之间，往往还夹着一层**叙事与资金流**

**推论（必须写进机制8卡片，作为核心风险）**：加密的"价值投资"有可能只是一种**穿着价值外衣、周期更长的叙事/资金流交易**。这不是否定这条路，而是说：**机制8的第一个检验对象不是估值，而是"这个代币对任何东西有没有真实的、不可随意更改的索取权"**。答案是"没有"的资产，你对它的基本面判断再准，也缺少变现路径。

由此得到贯穿投资轨的一句约束：

> **好协议 ≠ 好代币 ≠ 当前价格是好投资。**

### 加速规则（防止均匀用力）

先用 §阶段2 五道硬门槛快速过一遍。**明显过不了的机制不写完整卡，只写3行"为什么被排除"。** 按你的约束预判（以自己的结论为准）：机制3（凌晨集中）、5（速度）、6中的做市部分大概率过不了硬门槛4。

## 阶段1-D：双轨审计实验（18h，动手 —— 全路线最重要的技能模块）

知道"前视偏差"的定义，和能在代码里发现它，是两件事。你会大量用AI生成notebook和研究草稿，**审计能力是这条路线的关键依赖**。两轨各做一个。

### 轨1：回测审计（10h，交易轨）

用BTC日线数据，AI可辅助写代码，但每步你要能解释：

1. **复现买入持有基准**：算累计收益与最大回撤，**手工复算其中3行**与代码对上。
2. **加成本**：给一个简单规则加手续费+滑点，看收益被侵蚀多少。
3. **故意造一次前视偏差再自己抓出来**：例如用当日收盘产生信号又按同一根K线收盘成交，或 `shift()` 方向写反。看"业绩"虚高多少——这个数字会让你终身受益。
4. **第二数据源抽查**：同一天收盘价换个数据源对一遍（时区/日线边界是否对齐）。
5. **存档原始数据**：CSV存档 + 记录下载日期，后续实验都基于这一份。

**必须能识别的错误**：同根K线产生信号又成交 / 时区与日线边界不一致 / `shift()` 方向反或索引错位 / 缺失值被ffill带入未来信息 / 资金费率与价格时间戳未对齐 / 退市币从资产池消失（幸存者偏差）/ 基准与策略收益日期错位 / AI代码默默使用未来数据。

**参数探索的正确姿势**（不是禁止探索，而是登记探索）：

```
训练段探索参数 → 验证段选择方法 → 测试段一次性使用（用完即废）
→ 检查参数邻域（相邻参数是否也还行，还是孤峰）
→ 分市场状态检查（牛/熊/震荡分段）
→ 登记：一共试过多少条规则、多少组参数
```

> **诚实提示**：BTC 只有十几年日线，独立趋势波段可能只有几十段。三段切分后每段都很薄。**这套流程在本路线中的作用是"练纪律"，不是"得出统计上可信的结论"。** 别因为跑完了切分就以为结论变可靠了。

### 轨2：来源审计（8h，投资轨）

选**一个公开、流动性足够、资料充分**的代币，复核以下每一项，并注明每个数字的一手来源与 as-of 日期：

1. 流通量、总量、FDV —— 两个数据平台的口径为什么不同？
2. 未来12个月解锁与排放计划 —— 来源是项目文档还是第三方推测？
3. 协议费用 vs 协议收入 vs **代币持有人实际拿到的价值** —— 这三个数常常差一个数量级
4. **代币的索取权到底是什么**：读官方文档/治理提案原文。是可执行权利，还是治理可随时更改的分配政策？
5. 持仓集中度：前10地址占比，其中哪些是交易所/金库/团队？

**最重要的输出**：把 **事实 / 推断 / 假设** 三类分开标注。AI 生成的研究草稿最典型的问题就是把三者混在同一段流畅的文字里。

### 出口问题

1. 说出三种你**亲手制造过**的骗自己方式（回测侧）。
2. 你审计的那个代币，持有人对协议收入有可执行索取权吗？证据是哪句原文？
3. 为什么"现金"这个词必须说明是 CNY、USD、短期国债还是 USDT？

- 标注所有"待核实"项

## 阶段4-A：等成本工作样本 + 中途 go/no-go（15h）

只深试一个候选却给所有候选排名，等于试驾三辆车中的一辆然后评冠亚军。

### 做法

**3个样本，每个5小时，用计时器，AI预算相同**（这一点很重要：如果一个样本你用了大量AI而另一个全靠手工，你比较的是AI擅长什么，不是你适合什么）。

- **必含1个规则类样本**（交易轨）
- **必含1个基本面备忘录样本**（投资轨）：选两个同类、高流动性、资料充分的协议，写一份**相对比较备忘录**。必须回答"**为什么A在当前价格下优于B、优于BTC**"，而不是介绍两个项目。
- 第3个自选

每个样本只回答：**这活我做得出来吗、做起来什么感觉？** 不追求结论。"我连数据都没拉通"是极有价值的结果。

### 每个样本结束后必填

```
实际耗时（vs 预估）：
卡在哪一步：
数据实际拿到了吗、口径对得上吗：
真做起来需要多快反应（对照22:00-06:00盲区）：
这个流程重复100次，我愿意吗：
对模糊与长期无结论的耐受：
哪些步骤我完全依赖AI且自己无法审计？（隐藏风险，必须列出）
新鲜感消失后我还想做吗：
规则化 vs 主观判断，哪种对我更自然：
```

### 🚦 中途 go/no-go（v1.2 新增）

看完三份记录，四选一：

- **GO**：选1个进入4-B深实验
- **换候选**：回阶段2 换一个，再做一次样本（+5h）
- **STOP-暂缓**：三个样本都指向"做不出来/不想做" → **直接跳到阶段5判定"全部证据不足"，不要再投30小时**
- **STOP-退出**：明确不适合主动交易与主动投资 → 转被动配置，本路线结束

> 这个关卡的存在是为了对冲沉没成本。到这里你已投入约95小时；再投30小时，"放弃"就会变得更难说出口。

## 阶段4-B：深实验（30h，刻意摊在4周）

对**一个**候选做纸面深验证。**协议随机制走，不要让候选适应统一模板。**


| 机制                | 最小实验协议                                                                                      |
| --------------------- | --------------------------------------------------------------------------------------------------- |
| 0 被动持有          | 不同起点/持有期的收益与回撤分布；定投 vs 一次性                                                   |
| 1 趋势跟踪          | BTC/ETH日线预注册规则回测，含成本、分段样本外、参数邻域检查                                       |
| 2 横截面选择        | **点时可得资产池**（含已退市币，否则幸存者偏差）+ 排名规则 + 换手成本                             |
| 3 均值回归          | 极端偏离的事件研究：定义阈值 → 统计其后N日分布，含成本。**额外记录：有多少事件发生在你的盲区内** |
| 4 Carry             | 对齐现货/永续/资金费率/基差多源数据；把收益拆成 carry、基差变动、腿风险、抵押品与交易所风险       |
| 5 相对价值/套利     | 先做可行性证明：价差扣除费用、延迟、提币时间后是否仍存在？"不可行"也是结论                        |
| 6 波动率/流动性提供 | LP 收益 vs 持有底层代币（量化无常损失）；不实操                                                   |
| 7 事件驱动          | 定量事件研究：**事先**定义事件清单（如解锁日）与窗口，统计前后分布，含成本                        |
| **8 基本面重估**    | **见下方专用协议**                                                                                |
| 9 协议补贴捕获      | 纸面测算：历史空投的实际人均收益 vs 投入的时间、gas、资金占用与被判定女巫的概率；**不做链上交互** |

### 机制8 专用协议（投资轨深实验）

1. 选**一个实时公开市场对象**，冻结 `as-of` 日期与当日价格
2. 完成尽调 → **价值捕获链检验（第一步，不是最后一步）** → 熊/基/牛三情景估值 + 概率 → 最强反方 → 模拟配置权重
3. 结论只能是 **拒绝 / 观察 / 值得继续跟踪**，**不能是"值得买"**
4. 用附录3模板产出投资备忘录

### 影子组合（8/21启动，与4-B并行，每周约1h）

不投真钱。写下预先定义的**里程碑**，然后只跟踪：

- **只有事实变化才允许更新论点**（价格变化不算事实变化——这条是整个练习的核心纪律）
- 每次更新记录：改了什么、因为哪条新事实、我原来的失效条件是否被触发
- 期末做**收益归因**：市场Beta / 基本面 / 催化剂 / 叙事 / 运气

> **8–12周不能验证一个数年期的投资论点。** 它只能验证你的监控与更新流程——以及一件同样重要的事：**你会不会悄悄改论点来避免承认自己错了。**

### 本轮**能**回答 / **不能**回答

**能**：我能完成这种研究流程吗？数据能获得、能审计、口径稳定吗？规则或判断能被明确表达吗？成本和风险是否已使方向不可行？我愿意长期重复吗？

**不能**：❌ 策略有效吗 ❌ 能赚钱吗 ❌ 该投多少钱

> **日历时间 ≠ 有效样本。** 后续"验证多久算够"应由有效事件数、持有期、市场状态覆盖度和结果不确定性决定，不是"跑满3个月"。

### 产出

一页实验备忘录（附录4）。结论三选一：**淘汰 / 证据不足 / 值得继续**。**"回测赚钱"不许写成"策略有效"。**

## 决策日志（8/21起，每周约1h）

### 触发方式

**记录所有满足预设条件的机会，包括 `No trade`。** 预设条件先写死（例如"资金费率进入历史前5%极端区间"或"我的候选机制发出信号"）。一周没触发就记0条——**记0条是合格的**。

### 每条字段

```
时间戳 / 信息截止时间（as-of）
标的、价格源、可操作工具
预测对象、方向、期限、我给的概率
假想仓位 + 入场与退出规则
基准预测（如"就是随机"或"跟随BTC"）
支持证据 / 我能找到的最强反证
失效条件（出现什么算我错）
结果 + 统一评分方法
```

### 历史重放的警告

把资料冻结到历史某天再判断，对你**污染严重**——你刚写完一份加密史报告，已经知道后续。若要做，必须**预先定义抽样规则**（随机抽日期，而非挑著名事件），且优先选报告未覆盖的细节。**前向日志的价值远大于历史重放。**

## 阶段5：复盘 → 下一轮研究优先级（8h）

### 合法结论（四选一，后两个不是失败）

1. **继续深化**当前候选，进入下一轮8–12周研究
2. **切换**到另一候选（附理由）
3. **全部证据不足** → 只做被动配置或暂缓，重新评估是否继续投入时间
4. **明确退出**主动交易与主动投资研究

> 产出叫 **"未来8–12周研究优先方向"**，不叫"选定主方向"。你只深试了一个候选。

### 两轨比较的禁令（重申 §0.4）
