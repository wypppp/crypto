# 链上一级发行：全队列执行实验

> **状态（2026-09-22）**：已关闭。§5 的待办已被同目录 08-28 的[终局裁决](NO_NEW_QUERY_TERMINAL_DECISION_2026-08-28.md)取代。现况见 [总入口](../../RT/00_总入口.md) §2.2。

版本：2026-08-25

## 1. 要回答的问题

不是“一级发行有没有过 10x”，而是：对一个从约 1 万元人民币风险本金起步、接受锁仓但不依赖毫秒速度的人，系统性参与一级发行能否提供足够大的**实际获配额 × 可实现回报 × 事件频率**，使本金出现跃迁。

核心恒等式：

```text
年度净利润 = Σ[实际获配金额 × 已解锁份额 × (可执行卖价 / 销售价 - 1)]
             - 参与成本 - 资金占用成本 - 失败/退款损失
```

ATH、最大申购额、项目销售总额都不能代替“实际获配金额”。

## 2. 母体审计

CoinList 2025 年报声称当年有 21 个项目、18 个超额认购。但不能直接把该名单当作用户可参与事件的全集：

- 年报名单包含 `Mocaverse`，而 CoinList 官方 `Moca` 发行页显示销售发生在 2024-04-24 至 2024-05-02；
- CoinList 官方主站 sitemap 和发行页包含 2025-07-11 至 2025-07-12 的 `PUMP` 销售，但年报名单没有 PUMP；
- `Redacted` 是 2025 年 MocaList 联合品牌销售，只出现在旧站/联合品牌页面，不在当前主站 sitemap；
- 2026 年博客只容易检索到 Zama 和 USD.AI，但主站 sitemap 还包含 Flying Tulip。

因此，本实验把“在 CoinList 或其联合品牌界面上、用户可提交资金获得 token/权利的独立事件”作为母体，不采用平台年报的宣传分类。当前重建结果为：

- 2025：21 个可确认事件（年报中的 20 个真实 2025 事件，去掉日期不符的 Mocaverse，再加入 Redacted 与 PUMP）；
- 2026-01-01 至 2026-08-25：3 个可确认事件（Zama、Flying Tulip、USD.AI）；
- `Moca/Mocaverse` 保留为审计异常行，不纳入 2025–2026 主样本。

这只是 CoinList 队列。Legion、Echo 及专项 launchpad 必须各自建队列，不能混合后只报告总平均。

## 3. 冻结口径

### 3.1 事件纳入

满足以下全部条件：

1. 官方页面能确认销售窗口、价格或拍卖规则；
2. 普通参与者或一个预先定义的身份组能够实际提交资金；
3. 取得的是 token、可赎回包装权利或有法律文本的未来 token 权利；
4. 销售开始时间在研究窗口内。

节点许可证、纯积分活动、无购买行为的空投不进入主队列，另行分层。

### 3.2 可执行卖价

- TGE 已解锁部分：首个具备至少 5 万美元可见深度的市场，以 T+1h、T+24h、T+7d、T+30d、T+90d 的成交量加权中间价计算；
- 线性解锁部分：按每批实际可转让时间单独定价，不用 TGE 价格套到未来解锁份额；
- 无足够深度、未 TGE、暂停交易或无法转让：该时点记为不可实现，不以项目方估值代替；
- 拍卖项目以实际清算价为成本；若只有地板价而无清算价，收益保持缺失；
- Flying Tulip、USD.AI 等带退款/Put 权利的事件，分别计算“保留保护权”和“放弃保护权后卖出”两条路径。

### 3.3 获配容量

按以下证据优先级记录：

1. 可公开验证的链上分配；
2. 平台公开的分配统计；
3. 多个参与者提供的去标识化成交回执；
4. 平台规则推导的上下界。

最大申购额不能作为获配额。若只能得到上下界，则最终输出区间，不填单点估计。

## 4. 预注册输出

每个平台分别输出：

- 事件数、TGE/未 TGE/失败/退款数；
- 已解锁收益的 P10/P25/P50/P75/P90/max；
- `>=2x / >=5x / >=10x` 的事件占比和资本加权占比；
- 中位、P10、P90 实际获配额；
- 每年可部署金额、最大同时占用本金、回款时间；
- 随机全参加、只参加当时可见规则筛选、贡献换额度三种策略的净收益；
- 最终换算为 `P(1万元 -> 5万元)`、所需事件数和时间。

右尾项目名单只能作为解释，不作为主结果。

## 5. 当前状态

`data/coinlist_event_universe.csv` 已固定 CoinList 事件级母体与官方条款。下一步依次补：

1. 实际清算价/TGE/可转让日期；
2. 历史成交价格与深度；
3. 获配分布或严格上下界；
4. 同样口径的 Legion 队列。

在第 3 项之前，不得把“销售回报高”写成“对个人可形成高收益策略”。
