## 0. 先给结论

1. **不存在一个名为“加密”“期权”或“预测市场”的大类，天然适合三年百倍。**市场是场所，期权和杠杆是支付工具，真正需要选择的是“优势来源 × 支付结构 × 执行场所 × 持有期”。
2. **你的目标只能由四类账户路径实现**：高度集中的百倍标的、低价二元索赔权、连续多级高风险复利，或奖金/锦标赛式幂律支付。套利、Carry、普通趋势和做市可以赚钱，但正常收益量级不能单独完成目标。
3. **“三年触及百万的中心概率至少 1%”不是 Alpha 门槛。**若三次 1 万元尝试相互独立，或每次在此前失败后的条件命中率相同，则单次百倍票只需约 0.334% 的条件命中率，整体就达到 1%。纯负期望赌博也可能机械过线；若三次暴露于同一风险状态，这个计算会高估概率。
4. **“机构少、散户多”只是一条线索，不是优势。**热门新币、永续合约、0DTE、体育盘口和主流预测市场已有专业做市、机器人、内部人及高水平研究者。机构真正不愿覆盖的通常是小容量、条款复杂、数据脏、操作麻烦和责任风险高的角落。
5. **与你的知识和工作方式最匹配的研究区不是泛新兴市场，而是慢速、公开、复杂事件的概率判断，再用有限损失的凸性工具表达。**这只说明值得优先检验，不说明你已经优于正在定价这些事件的专业交易者；所有候选的真实 Edge 证据目前都是未知。
6. 本轮保留五个尽调候选：
   - 公开政策与地缘事件概率 + 跨场所凸性执行；
   - 上市公司二元催化剂 + 期权/权证；
   - 公开链上危机预警 + 有限损失下行工具；
   - 高波动流动市场的中频趋势/动量 + 预先冻结的激进风险阶梯；
   - 点时完整资产池中的早期加密资产极端右尾排序。
7. **当前没有任何候选已经证明整体成功概率达到 1%。**旧草稿中“5%–15%”一类主观数字没有完整分母、真实报价和账户模拟支持，本报告不继承。
8. 保留三个强制对照：`不交易`、`无研究优势的低摩擦大胆下注`，以及`随机右尾资产/随机长赔率票`。其中大胆下注必须和五个研究候选接受同等的场所、费用、限额、支付和概率审计；如果它最终胜出，不能因为没有研究含量而排除。

## 1. 冻结口径

### 1.1 资金与时间

| 项目 | 冻结口径 |
| --- | --- |
| 首笔实盘 | 10,000 元 |
| 追加方式 | 只有活跃账户亏光才补下一笔 10,000 元 |
| 外部投入上限 | 30,000 元，共最多三次 |
| 主动借款 | 不允许 |
| 被动穿仓负债上限 | 50,000 元；概率模型必须单列，不能把它当可用本金 |
| 现有 A 股 50,000 元 | 完全排除 |
| 研究建设预算 | 另有 10,000 元 |
| 准备期 | 1–3 个月，最长 6 个月，不计入三年实盘期 |
| 实盘期限 | 首笔真实资金入场后 3 年 |
| 维护时间 | 长期平均约 6 小时/天 |
| 执行 | 24 小时自动化；异常可立即人工响应 |

### 1.2 成功、失败与财富

账户状态必须按以下净口径计算：

\[
W_t=L_t+A_t-D_t-C_t
\]

- `L_t`：已经提取、不会再承担风险的锁定利润；
- `A_t`：按真实可平仓深度计算的活跃账户清算价值；
- `D_t`：负余额、追缴和其他交易负债；
- `C_t`：尚未扣除的交易、税务、融资、Gas、提现和结算成本。

判定口径：

- 主要成功：任一时点 `W_t >= 1,000,000` 元；
- 有意义的中间结果：`W_t >= 500,000` 元；
- UI 浮盈、极薄盘口中的标记价格、不可提现余额和未扣负债不能算成功；
- 锁定利润计入目标，但具体锁定公式尚未冻结，所有候选概率暂时都只能标为未知。

### 1.3 信息边界

| 信息类型 | 是否可进入模型或交易 |
| --- | --- |
| 公开政府文件、法院记录、公司公告、链上数据 | 可以 |
| 合法购买的数据、公开但冷门的小语种原始资料 | 可以 |
| 合法自建调查、非保密访谈、实地观察 | 可以，逐项确认使用权 |
| 非公开但非重大、合法取得且不受保密义务约束的信息 | 可以，先完成来源分类 |
| 因职务或特定关系获得、受保密义务约束的重大非公开信息 | 全景中如实列为客观机制，但不可执行 |
| 购买泄密、诱导内部人员、操纵价格或结算源 | 不可执行 |

这不是把所有“未公开”一刀切。决定因素是来源、取得方式、保密义务、重要性和潜在价格影响，而不是事后是否真的赚钱。

### 1.4 证据等级

| 等级 | 含义 |
| --- | --- |
| `F` 事实/规则 | 可由固定文献、监管文件或官方产品文档核验 |
| `I` 推断 | 从机制和约束推出，但尚未经过完整样本验证 |
| `H` 假说 | 值得用数据证伪，当前不能写成优势 |
| `D` 动态待核 | 费率、地区、权限、成交深度、产品存续等必须在尽调日重抓 |

本轮环境未能重新抓取 2026-08-14 的外部网页快照，因此不背书现有仓库里未经一手页面复核的动态成交量、估值、用户盈亏比例和当日费率。本文只使用稳定机制、可推导数学和官方入口；所有动态字段留给下一轮来源审计。

本报告中的实际用法如下：

- 第 2 节公式和由公式直接得到的数值为 `F`；
- “支付工具不等于优势”“小仓百倍不等于账户百倍”等结构判断为 `I`；
- 五个候选、研究顺序、评分和“谁可能付钱”全部是 `H`，不是事实；
- 当前费用、地区、权限、深度、历史数据覆盖和产品存续全部是 `D`。

下一轮候选事实账本必须逐条携带 `F/I/H/D`，而不是只在文档开头定义标签。

## 2. 目标数学：先把“百倍”还原成账户路径

### 2.1 所需复利速度

单次 1 万元做到 100 万元是 100 倍：

\[
100^{1/3}-1=364.16\%\text{/年}
\]

| 口径 | 所需速度 |
| --- | ---: |
| 3 年 100 倍 | 年复合约 364.16% |
| 36 个月 100 倍 | 月复合约 13.65% |
| 156 周 100 倍 | 周复合约 3.00% |
| 若 3 万元第一天全部可用，做到 100 万 | 年复合约 221.83% |

最后一行仍明显低估真实难度，因为你的后两万元只能在前一账户归零后加入，不能从第一天共同复利。

### 2.2 1% 门槛为什么会被纯赌博通过

若每次 1 万元只买一张“命中则净财富到 100 万，否则归零”的票，并假设三次尝试相互独立，三次机会至少命中一次的概率为：

\[
P_{all}=1-(1-p)^3
\]

令 `P_all=1%`，得到：

\[
p=1-0.99^{1/3}\approx0.33445\%
\]

因此，在独立假设下，一张毛支付 100 倍、真实命中率只有约 0.334% 的票，即使单次期望回收只有本金的约三分之一，仍可勉强通过你的整体 1% 门槛。等价地，若每次是在此前失败后才启动，则 `p` 必须解释为每个阶段的**条件命中率**，而不是三张相关票各自的边际概率。

若只知道三次尝试各自的边际命中率而不知道依赖结构，不能使用上式：完全正相关时，三次 0.334% 的票合起来仍只有 0.334%；负相关时则可能高于独立结果。后续模拟必须显式建模共同市场 regime、共用模型错误和平台共同失效。

另一个表示是连续翻倍。`2^7=128`，一次尝试需要七级连续成功。在每级成功率都是相同条件概率、失败即结束该笔尝试，且三笔尝试相互独立的简化模型下，整体达到 1% 只要求每一级净翻倍的条件成功率约为 44.3%；若每级是无摩擦的公平 50/50，三次中至少一次七连胜的概率约为 2.33%。

结论不是“应该去赌场”，而是：

> `P(触及百万) >= 1%` 衡量的是支付右尾，不自动衡量 Alpha、期望收益或研究价值。

### 2.3 公平博弈上界

对一个非负、公平或负期望的财富过程，Ville 最大不等式给出：

\[
P\left(\sup_t W_t\ge H\right)\le\frac{W_0}{H}
\]

单次 1 万元、目标 100 万元时，**限定损失为本金且财富不低于零**的无优势公平博弈，触及概率上界约为 1%；若把最多三笔外部本金视为预先承诺的 3 万元总风险资本，对应的宽松上界约为 3%。费用、庄家优势、税、滑点和时间限制会压低可达概率。三次尝试的依赖关系相对独立公式既可能提高也可能降低联合命中率，但这个 3% 宽松上界本身不要求三次独立。

你另行允许极端穿仓形成最多 5 万元被动负债。对于财富下界为 `-D` 的理想公平过程，可以把财富整体上移 `D`，得到：

\[
P(\text{先触及 }H\text{ 而非 }-D)\le\frac{W_0+D}{H+D}
\]

若极其宽松地把全部 3 万元外部本金从第一天视为已承诺、`D=5 万`、`H=100 万`，理论上界约为：

\[
\frac{3+5}{100+5}\approx7.62\%
\]

这不是可执行概率：你不主动借款，券商/平台通常也不会把“可能穿仓”当作可主动部署的信用额度；真实负余额只会在跳空、流动性消失或清算失败时被动产生。它说明的是，任何允许财富跌破零的策略都不能拿 3% 上界作比较，必须单独报告债务概率和债务调整后的净财富。本文的 B1 限定风险基准仍使用非负财富口径。

这给出两个重要判断：

1. 如果限定损失为本金的候选路线宣称 5%–15% 的百万概率，必须明确指出新增期望来自何处，例如外部补贴、可验证定价优势或结构性权利；若概率来自负余额尾险，则必须把债务作为支付结构而不是 Alpha 披露；
2. 如果候选只有约 1%–3% 的百万概率，它可能只是用更复杂的形式复制公平或负期望赌博。

### 2.4 小仓凸性不能让账户百倍

若账户比例 `f` 投入一个最终变为 `M` 倍的标的，其余资金不变：

\[
W_1=(1-f)+fM
\]

要让整个账户变为 100 倍：

\[
M=1+\frac{99}{f}
\]

| 投入比例 | 单一标的所需倍数 |
| ---: | ---: |
| 1% | 9,901 倍 |
| 5% | 1,981 倍 |
| 10% | 991 倍 |
| 25% | 397 倍 |
| 50% | 199 倍 |
| 100% | 100 倍 |

所以“95% 稳定引擎 + 5% 百倍彩票”命中后，账户只约为 5.95 倍，不是 100 倍。锁定利润还会降低后续可复利本金，因此未来概率模拟必须使用你的真实锁定规则，不能套用全额复投曲线。

### 2.5 产品能出现百倍，不等于你能买到百倍

每个候选都要同时通过四道账户级检查：

1. **支付**：按真实成本，赢家是否能把净财富推到目标；
2. **深度**：1 万元是否能在当时 ask 档成交，目标时是否能结算或退出；
3. **概率**：在完整/可重建总体或显式模型下，可审计的真实命中率中心估计是多少，而不是报价显示多少；
4. **路径**：失败、追加、锁定、相关性和三年截止如何共同影响终值。

## 3. 全景图的三层结构

### 3.1 第一层：谁在付钱

| 收益来源 | 付钱方或承担的风险 | 持久性 |
| --- | --- | --- |
| Beta / 经济增长 | 企业现金流、采用增长、长期风险承担 | 较持久，通常不够高 |
| 风险溢价 | 套保者、借款者、保险需求者为转移风险付费 | 可重复，但有尾部亏损 |
| 行为偏差 | 彩票偏好、锚定、反应不足、被迫追涨杀跌 | 需具体到可验证偏差 |
| 公开信息/模型优势 | 判断较差或处理较慢的边际交易者 | 会被竞争侵蚀 |
| 规则与结算理解 | 看不懂权利、截止日、状态和裁决的人 | 小容量但可能持久 |
| 强制流 | 因保证金、赎回、法规、合同必须交易的主体 | 事件型，必须证明“真的必须” |
| 流动性与执行 | 急于成交者支付价差和冲击 | 竞争强、常负偏 |
| 结构性补贴 | 协议金库、VC、交易所或营销预算 | 窗口型，规则可追溯改变 |
| 信用/平台风险 | 无法或不愿承担倒闭、冻结、黑客风险者 | 未必被充分补偿 |
| 速度/订单流 | 反应更慢或订单暴露的交易者 | HFT/MEV 基础设施主导 |
| 内幕、操纵、控制结算 | 不知情交易者或被影响的市场 | 客观存在，但不可执行 |

### 3.2 第二层：支付形状

| 支付结构 | 例子 | 百倍能力 | 核心问题 |
| --- | --- | --- | --- |
| 线性现货 | 股票、现货币、商品 ETF | 只有标的本身百倍才行 | 需极端集中 |
| 杠杆线性 | 期货、永续、FX/CFD | 可连续复利，也可迅速归零 | 杠杆不创造优势 |
| 有限损失凸性 | 看涨/看跌期权、价差、权证 | 单仓可 10–100 倍以上 | 彩票溢价、Theta、幅度与期限 |
| 二元索赔权 | 事件合约、数字期权 | 1 分买入、1 元结算即 100 倍毛支付 | 深度、真实概率、结算状态 |
| 幂律标的 | 微盘股、新币、早期私募、NFT | 少数赢家可数十至千倍 | 完整死亡分母和退出容量 |
| 锦标赛/奖金 | 扑克 MTT、交易竞赛、奖池博彩 | 小入场费对应大头奖 | 参赛者总体和主办方风险 |
| 收敛/固定权利 | 套利、赎回、要约、complete-set | 通常收益有限 | 能保命，不能单独百倍 |
| 卖保险/Carry | 卖波动、基差、资金费率、借贷 | 多次小赚、偶发重损 | 与所需正凸性相反 |

### 3.3 第三层：执行场所

同一个判断可以在多个场所表达：股票、期权、期货、加密永续、加密期权、事件合约、博彩交易所或锦标赛。比较单位必须是完整四元组：

> `优势来源 × 支付结构 × 执行场所 × 持有期`

“做预测市场”“做期权”“做加密”都不够具体，不能直接进入候选评估。

## 4. 对“新兴市场更适合散户”的校正

你的原始判断有一半成立：

- 新规则、小语种、碎片化数据和低容量确实会阻止一部分机构进入；
- 个人没有规模约束，可以研究只容纳几万元的小机会；
- 复杂条款、社区信息和跨市场映射适合代码与 LLM 辅助；
- 24 小时市场和公开链上数据给个人提供了过去没有的基础设施。

另一半需要反转：

- **机构不进入可能是因为机会不值得做，而不是因为留下免费钱。**容量、法律责任、无法对冲和平台风险会把表面收益吃掉；
- **散户多常使右尾更贵。**远虚值看涨、仙股、权证、热门 Meme 和高赔率串关都可能因彩票偏好而长期高估；
- **“博傻”需要你能在更晚的参与者到来前退出。**项目方、早期筹码和做市商通常比公开市场散户更早、更便宜；
- **可见的定价偏差不等于可成交 Alpha。**盘口太薄、短借不到、合约会暂停、赔率定义不同，都可能让错误价格无法兑现；
- **新市场的数据最差。**没有退市样本、规则版本、历史订单簿和失败账户，就无法估计你要求的 1% 中心概率。

更准确的筛选原则是：

> 寻找“时钟足够慢、规则足够硬、公开信息足够复杂、容量刚好适合小资金、又存在有限损失高凸性工具”的市场，而不是寻找“最新、最热、散户最多”的市场。

## 5. 全球市场家族全景

状态标签：

- `候选`：进入第 8 节下一轮尽调名单；
- `候选子类`：属于某张完整候选卡，但不单独算第六个候选；
- `组件`：可以成为候选的信号、执行工具或资金停泊方式，但不是独立方向；
- `工具`：只提供支付、执行或研究基础设施，本身不提供 Edge；
- `观察`：存在右尾，需要更强前提，本轮不优先；
- `基准`：必须比较，但不声称有 Alpha；
- `淘汰`：与当前目标、资本、速度或边界明显不匹配。

预测市场价格不是天然的真实概率。费用、价差、风险偏好、资本约束、取消状态和结算争议都会造成偏离；普通期权的价格也不能直接与事件合约价格作一比一概率比较，因为期权是连续支付并含风险中性分布和波动率溢价。

基于已经公开、客观事实按协议规则提出或争议 oracle 结果，是一种合法机制候选；控制、污染或干预结算所依赖的事实源则属于第 5.7 节的禁止行为。二者不能混为一谈。

### 5.7 客观存在但不可执行的机制

下列机制会真实影响市场，也可能创造异常高收益，因此全景图不能假装它们不存在：

- 重大非公开信息；
- 控制或影响事件结算源；
- 抢跑客户订单、私有订单流；
- 操纵低流动性价格、刷量、拉盘出货；
- 虚假身份、多账户和规避 KYC；
- 侵入系统、窃取密钥或利用非授权漏洞。

它们只作为“为什么公开交易者可能是劣势对手盘”的风险因素，不进入候选、模型特征或路线图。

| Polymarket 类混合 CLOB | 条件代币；链下撮合、链上交换 | 钱包、稳定币、链与运营接口共同参与 | 市场规则与 optimistic-oracle 流程 | 文档化 API；当前状态为 `D` | 当前接口不证明旧 L2、队列和规则版本可得 | 合约语义、争议、稳定币/桥、私钥、接口停机、提现 |

| Betfair/Smarkets 类博彩交易所 | 对手盘订单簿，通常按净赢利抽佣 | 中央化账户余额 | 平台按赛事官方结果结算 | API 能力因场所而异，均为 `D` | 成交史与历史逐档深度须分别核实 | 佣金、限额、赛事取消、账户限制、结果更正 |
| 固定赔率、赌场、奖池与彩票 | 庄家报价、固定游戏规则或参与者共享奖池 | 中央化账户、票据或运营方负债 | 规则、随机过程、官方赛果或开奖 | 自动化和条款因场所而异，均为 `D` | 历史赔率不等于可获得限额；游戏规则、抽水和兑奖记录须留档 | 庄家优势、赔率相关、限额/封号、奖池分割、兑奖与对手方 |
| AMM/conditional-token 市场 | 曲线报价、complete-set 或多结果代币 | 智能合约与链上抵押 | oracle/仲裁协议 | 合约可组合，前端和索引器状态为 `D` | 链上交易可重建，但离链意图、前端与当时可见报价未必可还原 | 价格冲击、LP 逆向选择、漏列状态、Gas、合约升级 |
| OCC/Cboe/CME 等上市期权 | 连续标的支付；订单簿或经纪商路由 | 券商保证金与清算体系 | 按合约条款、标的与官方结算值 | 经纪商 API、权限与产品可用性为 `D` | 当前产品页不提供候选所需历史 NBBO、队列和完整期权链 | 最小合约粒度、价差、停牌、公司行动、行权与结算 |
| 上市股票、权证与期货 | 现金证券/权利或线性合约；交易所撮合与经纪商路由 | 券商托管、保证金与清算体系 | 公司行动、合约规则与交易所结算 | 经纪商 API、卖空和权限为 `D` | 需含退市证券、旧合约、历史 bid/ask、保证金与公司行动 | 跳空、停牌、追缴、借券、交割、权证赎回与最小粒度 |
| 中心化加密现货、launch 与 pre-market | 订单簿、平台分配、上线前索赔或交割 | 平台托管及平台定义的资产/索赔权 | 链上转账或平台交割规则 | API、分配资格和权限为 `D` | 当前存活币与成交史不包含全部失败发行、退市和不可交割机会 | 托管、上/下币、白名单、映射、交割、虚假量、冻结与提现 |
| 中心化加密期权/永续 | 期权连续支付或永续资金费/清算 | 平台托管、平台抵押品与风险引擎 | 指数、标记价和平台规则 | 通常有 API；当前限速与权限为 `D` | K 线/成交通常较易，旧 L2、指数成分和规则版本未必完整 | 托管、ADL、指数/oracle、清算、单腿、冻结与提现 |
| DEX 现货、launchpad 与 LBP | AMM/订单簿、拍卖曲线或初始分配合约 | 钱包、池、合约与桥 | 链上状态、代币合约和平台规则 | 合约可自动化，普通账户实际延迟为 `D` | 链上状态可重建，但失败部署、前端列表和不可成交项目易遗漏 | MEV、滑点、蜜罐、交易税、管理员权限、Rug、Gas 与桥 |
| 链上永续/期权 | 智能合约仓位、池或订单簿 | 钱包、合约金库、桥和抵押品 | 链上/链下 oracle 组合 | 合约与 API 可自动化，实际稳定性为 `D` | 链上状态可重放，但 oracle 延迟、前端路由和离链订单可能缺失 | oracle、管理员权限、合约漏洞、MEV、流动性池和桥 |

场所不是候选之外的附注，而是候选定义的一部分。下一轮不得写“做预测市场”或“买期权”，必须写成“具体信号 × 具体索赔权 × 具体场所 × 具体时点”，并逐项验证净支付和可清算深度。

## 6. 强制对照组

### B0：不交易

- 百万触及概率：0；
- 保留本金概率：接近 100%，扣除研究支出和现金机会成本；
- 意义：任何路线都要明确它用多少本金保存概率换来多少百万概率和 50 万概率。

### B1：无优势的公平/负期望大胆下注

定义：使用最大损失明确、结算可靠、摩擦尽可能低的二元或近二元支付，通过大胆下注而非细小下注，机械提高在归零前触及目标的概率。例子可以是受监管的限定风险期权价差、赔率透明的二元合约或低庄家优势游戏；具体场所须另行核验。

它不是建议，也不是 Alpha。它的作用是回答：

> 如果不做任何聪明研究，只优化“触及目标”的支付路径，能得到怎样的概率与中间结果？

必须计算：

- 可执行 bid/ask、佣金和税费后的每级真实赔率；
- 合约最小粒度导致的超额风险；
- 三次尝试共享三年期限后的总体概率；
- 达到 10 万、50 万后执行锁定层造成的概率变化；
- 平台限额、结算、账户和提现风险。

`B1` 不是第六个研究候选，但必须接受与五个候选同等级的尽调：为每一种可用路径指定具体场所和合约，审计费率、tick、最小下注、限额、真实深度、结算、充值提现和历史赔率，再用同一个财富模拟器输出 `P100`、`P50`、归零和负债概率。它不能因为“没有研究含量”被提前排除；若它在用户的目标函数下胜出，结论就应诚实地保留它。

B1 也不能用报价替代真实概率。每条路径都须完成“物理状态概率或已知游戏概率 → 点时可执行支付 → 财富路径”的三层估计；场所、合约筛选、下注阶梯、再平衡和退出规则必须在外层时间留出或 walk-forward 之前冻结。若先查看全样本，再从期权价差、事件合约和游戏中挑历史 `P100` 最高者，得到的不是诚实基准。

### B2：随机右尾资产/随机长赔率票

从当时与候选相同的**合格总体**中随机抽取，使用相同入场时间、机会频率、资金占用、成本、集中度和退出规则。例如候选 2 应从同一预注册事件集合内随机排序，候选 5 应从同一时点完整新资产池内随机选择；不能用一个更宽、更差的总体人为削弱 B2。这是检验 LLM/研究模型是否真的增加选中率的基线。

如果模型只比“事后成功案例”好、却不优于 B2，它没有选择优势。

## 7. 统一筛选框架

### 7.1 五道硬门槛

任一具体候选先过门槛，再谈打分：

1. **账户支付门槛**：在真实可成交深度下，存在把净财富推到 100 万的完整路径，而不是只有某张小仓票上涨 100 倍；
2. **概率可估门槛**：能在 6 个月内取得足以形成可审计中心估计的证据；完整或可重建的分母优先，无法完整恢复时允许明确假设的模型估计和宽区间，但必须降置信度；
3. **执行门槛**：1 万元、现有自动化、响应时段和 1 万元建设预算可以真实执行；
4. **风险边界门槛**：包含平台、跳空、穿仓、结算和负债后，最坏状态不超出冻结边界；
5. **优势解释门槛**：对研究候选，能提出谁在付钱、为什么错误可能未被抹平，以及哪项任务可能优于边际参与者，并用样本外证据检验；对按定义无 Edge 的 B1，此门槛不适用，但其无优势基准概率仍须同口径审计。

“历史上出现过百倍赢家”“回测盈利”“散户很多”“AI 可以抓新闻”都不能单独通过任何一道门槛。

### 7.2 九轴评分，不做加权总分

| 轴 | 1 分 | 5 分 |
| --- | --- | --- |
| 目标支付能力 | 正常路径远低于目标 | 单次或少数状态可把账户推到目标 |
| 概率可估性 | 无完整分母、极度非平稳 | 长历史、规则稳定、可校准 |
| 工作流/知识匹配 | 需要全新能力且难以获取 | 现有知识、代码和日常流程直接匹配 |
| 相对边际交易者的 Edge 证据 | 样本外反证或净成本后为负 | 多期点时样本外、净成本后反复成立 |
| 数据可得性 | 幸存者数据或付费超预算 | 点时、含失败、可自动保存 |
| 执行与自动化 | 依赖手工/低延迟/大额资格 | API 稳定、限定风险、粒度合适 |
| 机会频率/独立性 | 三年可能没有一次 | 大量非高度相关机会 |
| 容量与阶段迁移 | 只容纳极小资金且无法退出 | 1 万至 50 万均有承载方式 |
| 尾部可控性 | 平台与价格风险高度相关 | 最大损失和结算路径清楚 |

不加权求总分，因为“高分低收益套利”不能靠其他轴的高分越过账户支付门槛。评分只决定先研究什么，不代表预期收益。

`工作流/知识匹配`只表示研究成本和执行适配，不表示能战胜正在报价的专业参与者。本轮五个候选的 `Edge 证据`全部为`未知`，不得用前一轴的高分替代。

### 7.3 概率模型的统一输出

每个候选最终都必须用相同账户模拟报告：

- `P(三年内净财富 >= 100 万)`；
- `P(三年内净财富 >= 50 万)`；
- `P(三笔外部本金全部损失)`；
- `P(形成负债)`及负债分布；
- 三年末锁定财富、活跃财富和净财富的中位数；
- 中心估计与合理不确定区间；
- 去掉最大 1–3 个赢家后的结果；
- 相对于 B0、B1、B2 的增量。

路径模拟必须编码：亏光才补下一万元、总共三次、机会相关性、真实三年截止、锁定层、部分成交、费用、平台失效和负余额。不能把三次机会默认成独立，也不能把外部追加本金写成投资收益。

任何依赖低成本、小概率状态完成百万路径的候选或 B1 路径，都必须做**目标尾部专项验证**；其他候选则须定义对其 `P100` 贡献最大的等价目标分层。总体 Brier/log score 可能只因大量 20%–80% 常见事件而改善，却没有提高能够承担百万路径的低成本尾部。报告必须另外给出：

- 在“净成本/净支付足以进入目标路径”的预注册分层中的校准、区分度和实际净回报；
- 按同一政策、公司、赛事或共同冲击聚类后的有效样本量，而不是把相关合约当独立样本；
- 决策时真实 ask、逐档深度、排队/部分成交与退出 bid；
- 按资金占用和全成本加权的实现支付，以及该分层对账户 `P100` 的实际贡献。

只改善总体评分、分类准确率或中间价回测，不能通过启动门槛。

### 7.4 分母标准与各市场最低数据集

完整或可重建分母是首选证据，不是所有新市场都必须满足的隐藏频率学下限。用户已接受“中心估计高于 1%，但合理区间很宽且下界低于 1%”的结果；因此，确实无法得到完整总体时，可以提交显式模型假设、外部基准率、敏感性分析和降级置信度后的中心估计。不能做的是拿报价本身循环证明真实概率，或隐去缺失样本方向。

例外是缺失机制会摧毁中心估计的方向。早期加密若没有接近完整的死亡资产、不可交易项目和普通账户入场分母，幸存者偏差足以让估计失去意义，候选 5 仍须坚持近完整重建。其他候选是否必须达到同等完整度，应由缺失机制和敏感性分析决定，而不是一刀切。

| 市场 | 最低分母要求 |
| --- | --- |
| 期权 | 触发时全部合格合约、完整链、真实 bid/ask、到期归零、停牌和公司行动 |
| 股票/权证 | 当时可买的全部证券，包含退市、破产、并股、增发和不可借券状态 |
| 加密资产 | 当时全资产池，包含 Rug、蜜罐、迁移、退市、无流动性和池状态 |
| 链上危机 | 所有触发预警但没有崩溃的主体，以及预警时真正可用的交易工具 |
| 预测市场 | 所有满足预注册规则的市场，包含取消、争议、延期、无成交和规则版本 |
| 趋势/动量 | 全部入选品种、连续合约处理、真实保证金、成本和制度切换 |
| 体育/彩票/竞赛 | 所有下注或参赛机会、抽水、重入、参赛人数、奖池和未兑现奖金 |

### 7.5 当前最先验的可执行数据缺口

本轮找到的官方产品页、当前 API 和一般历史端点，**尚未证明**在 1 万元研究预算内能取得以下档案：历史 L2 订单簿与排队状态、预测合约规则的全部版本、上市期权逐时 NBBO/完整链、当时仓位和限额、退市资产及不可成交机会。候选 1 和 2 的数据可得性因此只能先评为 `1–2`，不能因当前有 API 就给高分。

连续收集未来六个月可以验证系统稳定性和常见事件执行，却不可能仅靠前向样本校准 0.5%–1% 的目标尾部。下一轮第一项任务是逐场所回答：多年可执行档案是否存在、字段是否足够、许可是否允许研究、总成本是否不超过 1 万元；若答案是否定，就应降低概率置信度、改用能审计的窄问题，或直接淘汰相关候选。

## 8. 五个下一轮尽调候选

以下排序是**研究优先级**，不是资金配置，也不是已通过 1% 门槛的收益排名。

五张卡中的“谁可能付钱”都是待证伪机制假说 `H`。本轮对五个候选相对边际交易者的 Edge 证据一律记为`未知`；“为什么匹配你”只表示知识和工作流适配，不能升级为交易优势。

### 候选 1：公开政策与地缘事件概率 + 跨场所凸性执行

#### 完整定义

使用公开政府文件、法院/监管记录、政策流程、可靠新闻与合法自建数据，估计一个离散事件及其时间/幅度分布；把同一状态映射到预测市场、股票/ETF 期权、商品期权或加密期权，选择限定损失且净支付最优的场所。

它不是“泛政治下注”，而是：

> `窄领域公开信息概率假说 × 严格状态映射 × 有限损失凸性`

#### 谁可能付钱

- 把“征求意见、审议、批准、公布、生效”混为一谈的交易者；
- 只读英文二手报道、没有定位中文原始源能力的交易者；
- 因娱乐、立场或彩票偏好高估/低估某一状态的参与者；
- 对规则、时区、官方结算源或事件幅度理解不完整的人。

#### 为什么匹配你

- 公开政策和军工语境是已确认的知识/工作流匹配，但相对专业定价者的 Edge 未知；
- LLM 适合抓取、版本 diff、实体消歧和状态映射；
- 24 小时自动监控与人工告警响应可覆盖全球场所；
- 1 万元适合小容量长尾，但必须验证目标赔率深度。

#### 百万路径

- 全成本不高于约 1% 的二元索赔权，一次命中可在毛支付结构上接近 100 倍；
- 10–50 倍的事件期权需要高度集中或多级连续命中；
- 如果只投入 1%–5% 彩票仓，这条路径不能使账户百倍。

#### 最强反证

- 翻译已高度自动化，真正信息领先窗口可能在你可成交前消失；
- 军事/战争长尾中，公开信息参与者可能持续面对真正内部人；
- 低价合约通常没有足够深度容纳 1 万元并净结算 100 万；
- 预测市场状态与期权连续支付并不相同，错误映射会制造假套利；
- 对 1% 事件，短期虚拟盘无法用盈亏验证概率优势；
- 当前来源尚未证明历史 L2、队列和完整规则版本能在研究预算内取得。

#### 下一轮一票否决问题

能否先在 1 万元研究预算内取得可用历史档案，再找到足够数量、规则客观、点时全成本达到目标赔率、1 万元深度可成交的事件，并在**目标成本尾部分层**中证明公开源模型在时间留出样本上比市场和朴素基准更校准、净支付更高？

若答案是否定的，淘汰，不因个人政策知识保留。

### 候选 2：上市公司计划性二元催化剂 + 期权/权证

#### 完整定义

研究发生时间相对可计划、公开资料复杂、支付状态离散的公司事件，再用限定风险工具表达。优先子域：

- 生物科技临床试验、FDA 咨询委员会与审批；
- 并购、反垄断、法院裁决和重组；
- 国防采购、预算拨款、关键矿物、出口管制和关税的二阶公司影响；
- SPAC warrants/rights、赎回、交换要约和公司权证。

#### 谁可能付钱

- 无法正确解释试验终点、统计方案、监管流程或法律条款的人；
- 把合同总上限当成已实现收入、把政策表态当成已执行规则的人；
- 不愿为小容量复杂文件投入研究成本的机构。

#### 为什么匹配你

- 化学背景可降低生物医药入门成本，但不预设已有行业优势；
- 政策、军工公开语境适合采购和监管事件；
- EDGAR、ClinicalTrials、FDA、国防合同及支出数据可结构化；
- LLM 可做文档字段抽取，确定性代码负责日期、金额和支付。

#### 百万路径

深虚值期权或低价权证在二元事件中可能产生数十倍；通常仍需要高度集中、多个阶段命中或极少数更高倍状态。普通并购套利和要约折价不能单独完成目标。

#### 最强反证

- 生物科技与并购期权已有专业事件团队，隐含波动率可能充分计价；
- 公司控制披露时间，历史数据存在严重选择性和时间戳问题；
- 权证成功案例集中于特殊制度期，完整总体可能长期负收益；
- 1 万元可以买期权，但最小合约粒度可能迫使风险超过计划；
- 中国政策相关标的可能先在亚洲交易时段完成价格发现；
- 当前来源尚未证明多年逐时 NBBO、完整期权链、停牌与公司行动能在研究预算内取得。

#### 下一轮一票否决问题

按子域分别完成三个互不偷换的检验：

1. 用事件实际结果检验只使用决策时点公开资料的事件概率，包括样本外 Brier/log score、校准和目标概率尾部分层；比较同一预注册事件总体内的朴素基准率、简单公开规则、可识别时的市场基准，以及同机会频率和资金占用的随机排序；
2. 单独估计“事件发生/不发生及其他状态”条件下的股票终值与期权/权证支付分布，并使用当时可执行 ask、退出 bid、逐档深度和全成本；
3. 把前两层联合输入统一财富模拟，检验是否提高三年 `P100`、`P50`，以及相对 B1/B2 的增量。

普通期权面只约束风险中性终值分布，不能唯一识别 FDA、并购、采购或诉讼的事件概率；因此不得把模型事件概率直接与一个未定义的“期权隐含事件概率”比较。

完整三层必须共用一个外层时间留出或 walk-forward。事件定义、特征、概率模型、合约选择、条件支付参数、退出规则和风险阶梯都只能用训练期确定，再在未见事件上联合评估；财富模拟还必须传播事件概率和条件支付参数的不确定性，不能把第二层全样本拟合值当作已知真值。

不能把四个子域混在一起凑样本；至少一个窄域独立通过才保留。

### 候选 3：公开链上危机预警 + 有限损失下行工具

#### 完整定义

监控稳定币、桥、LST/LRT、借贷协议、交易所关联代币和储备型资产的公开状态，寻找资不抵债、抵押循环、挤兑或强制处置风险；只有在独立可提现场所存在 put、put spread、数字事件合约或损失严格隔离的工具时才交易。

候选特征包括：

- 储备与负债口径差；
- 赎回速度、排队与折价；
- 抵押品循环、健康度和关联方集中；
- 地址异常流动，但不把“转入交易所”直接等同于卖出；
- 借币费、期权偏斜、永续基差和跨场所价格脱节。

#### 谁可能付钱

- 对高收益和稳定叙事过度信任的持有人；
- 无法持续整合链上、合约权限、储备和衍生品数据的人；
- 因撤资成本、锁仓或利益关系反应较慢的资本。

#### 百万路径

- 普通无杠杆做空从当前价格跌到零，利润最多约等于空头名义本金，不能百倍；
- 真正右尾必须来自事前便宜的 put、数字合约、极低价后有硬赎回权的复锚，或多个阶段复利；
- 因而“找到下一个 FTX/UST”不等于账户自然获得百倍。

#### 最强反证

- 危机极少，制度持续变化，完整假阳性分母难建；
- 第一个公开警报出现时，put、借币和可靠平台可能已经不可用；
- 危机资产与盈利所在交易所可能是同一对手方，账面盈利无法提现；
- 假钱包标签和内部调拨会产生大量错误信号；
- 提前做空可能被挤仓和资金费率耗死。

#### 下一轮一票否决问题

一个事前冻结的公开危机评分，能否在包含全部假阳性的主体面板上预测未来 30/90/180 日相对崩跌，并且首次信号时确有独立、足够深、限定损失的工具可买？

若只有著名崩溃案例，没有假阳性和当时工具快照，直接淘汰。

### 候选 4：高波动流动市场的中频趋势/动量 + 激进风险阶梯

#### 完整定义

在加密现货/永续、微型商品或指数期货等流动市场，用日内非高频至日线的预注册趋势、突破或横截面动量规则寻找小统计优势；用严格限定负债、预先冻结的风险阶梯把一个中等优势转化为高归零、高触达概率路径。

#### 为什么保留成熟市场候选

- 相较罕见事件，数据、API、订单深度和自动执行更可能被审计，但具体历史覆盖仍为 `D`；
- 机会频率通常更高，1–3 个月足以搭建系统并做前向影子执行；多年回放仍取决于档案质量；
- 容量可以从 1 万迁移到更高资金阶段；
- 它最容易与 B1 大胆下注基准作同口径比较。

#### 谁可能付钱

只有趋势风险溢价、行为延续、套保需求或强制去杠杆能提供收益；“我能承受归零”和“我用了 AI”都不是收益来源。

#### 百万路径

依赖多次连续复利而非单张百倍票。激进杠杆缩短到达时间，也提高波动拖累、清算和归零概率。期望值正负本身不能推出 `P100` 是否高于某条 B1；只有在统一支付、摩擦和路径模拟中实证超过预先冻结的 B1 才算胜出。

#### 最强反证

- 公开趋势因子已被大量研究，个人优势可能只存在于回测；
- 过高杠杆会让算术正期望变成负几何增长；
- 参数选择、连续合约、资金费率和交易成本极易产生幻觉；
- 三次尝试暴露于同一市场 regime，不独立；
- 逐仓清算也未必保证极端状态无追缴。

#### 下一轮一票否决问题

在严格 walk-forward、含退市品种、真实成本和多种不利 regime 下，是否仍存在稳定的样本外优势，并使冻结风险阶梯的 `P100` 明显高于同摩擦 B1，而不是仅提高回测 CAGR？

### 候选 5：点时完整资产池中的早期加密极端右尾排序

#### 完整定义

选择单一链、单一发行场所或清晰资产生命周期，重建每个历史时点普通账户真正可买的全部新资产，包括死亡、Rug、蜜罐、迁移和无流动性项目；用链上、筹码、解锁、价值捕获、开发者持续性、资本流和社区数据做事前排序。

不是寻找“唯一下一只百倍币”，而是检验：

> 冻结的 top-k 模型能否相对随机选择，提高进入未来收益分布最右端的概率，并在真实退出约束后提高账户目标概率？

#### 谁可能付钱

- 对早期项目质量、代币权利、筹码和解锁理解更差的后来买家；
- 追逐叙事但不验证链上采用和价值捕获的资金；
- 协议补贴或新生态扩张也可能提供外部流入。

#### 百万路径

- 全仓单一标的需要约 100 倍；
- 10 个等权标的中，其余归零时，唯一赢家约需 1,000 倍才使账户约百倍；
- 分散能降低单项目归零，却会稀释百倍赢家对账户的作用；
- 到达较大资金阶段后，必须切换市场，因为微盘退出容量无法同比扩张。

#### 最强反证

- 历史数据库系统性删除失败资产，标签和特征可被项目方操纵；
- 最早价格往往只有机器人、内部人或白名单能成交；
- 普通账户延迟数分钟后的入场价可能已使赔率消失；
- 显示的池估值不等于可退出净值；
- 公开排序模型会被资金流迅速侵蚀。

#### 下一轮一票否决问题

能否为一个边界清楚的发行总体恢复点时池状态、全部失败项目、普通账户入场延迟、交易税、Gas、MEV、滑点和按深度退出，并证明 top-k 在时间留出样本上优于随机、等权和简单流动性基准？

无法恢复死亡分母时，立即淘汰，不使用 CoinGecko 当前存活列表回测历史。

## 11. 对 AI、算力和自动化优势的诚实定位

### 适合交给系统

- 多语种公开源抓取、时间戳和内容哈希；
- 规则版本 diff、实体消歧和字段抽取；
- SEC/FDA/法院/政府/治理文件分类；
- 链上余额、赎回、健康度和权限监控；
- 期权链、事件盘口和逐档深度存档；
- 点时资产池重建、账户蒙特卡洛和异常告警；
- 反证搜索、回测代码审计和数据质量报告。

### 不能因有 AI 而省略

- 完整失败分母；
- 对事件真实概率的人工责任；
- 规则和索赔权的最终确认；
- 重大非公开信息的来源隔离；
- 对真实报价、容量和提现路径的核验；
- 对“这个优势为什么还没被竞争抹平”的回答。

6 卡 4090 对毫秒竞争没有优势。它的价值主要在批量处理长文档、重建历史数据和运行大量账户模拟；交易速度瓶颈仍是数据源、网络、订单簿和执行系统。在线 2 卡 3080 足以承担实时抽取、推理和告警，不应为了使用离线算力而扭曲方向。

## 12. 本阶段明确没有做什么

- 没有选择最终交易方向；
- 没有给任何候选分配资金；
- 没有设计锁定利润公式；
- 没有注册账户、下单或做链上交互；
- 没有声称任何候选达到 1% 启动门槛；
- 没有用著名赢家反推胜率；
- 没有把旧文档中的动态数字当作今日已核事实；
- 没有写候选的实操路线图。

下一阶段应对 `B1` 和五个研究候选做**同口径的场所、数据与概率可估性审计**，随后再从五个候选中选择值得进入正式历史实验的方向。`B1` 不计入五候选数量，但不能因无研究 Edge 而被跳过；在任何路径通过中心概率 1% 门槛前，`不做`仍是有效结论。

## 14. 本轮交付结论

全景层面的选择已经可以收敛为一句话：

> **优先检验慢速复杂事件中是否存在可证明的公开信息概率 Edge，并把期权、事件合约和加密衍生品视为竞争性执行场所；同时让 B1 大胆下注基准和流动市场趋势路径接受同口径比较。早期加密右尾和链上危机保留，但在恢复必要失败分母前不享受“新兴市场”加分。**

五个候选目前都只是“值得审计数据能否支持概率估计”，其 Edge 证据和 `P100>=1%` 证据全部未知。下一轮的第一项工作不应是搭交易机器人，而应是为 `B1 + 候选 1–5` 建立统一的场所与数据审计表，首先确认多年可执行档案能否在 1 万元预算内取得；允许模型化中心估计和宽区间，但不能掩盖缺失方向。候选 5 若无法恢复近完整死亡分母，应直接淘汰。
