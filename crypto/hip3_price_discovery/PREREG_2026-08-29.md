## 2. 假说（已按评审意见弱化）

**不再主张**"闭市无人对冲 → 无速度竞争"。该论证已撤回（CME 股指近 24h、黄金 24/7、WTI 近全天、个股有隔夜 ATS）。

**改为市场分割假说**：HIP-3（USDC 抵押、无 KYC、离岸、永续）与 CME／隔夜 ATS 之间跨界套利资本有限，因此在美国现金市场闭市期间，HIP-3 价格对下一次现金开盘的信息吸收可能不完全。

两个独立估计量：

- **E1 预测量（解释性副目标）**：HIP-3 盘口价相对 `oraclePx` 与 `上次现金收盘价` 两个 naive benchmark，对下次现金开盘价的预测**增益**。
- **E2 交易量（主目标）**：事前冻结的规则，入场与退出**全部按 HIP-3 当时可执行 bid/ask**，扣全成本后的组合净 PnL。

**E2 是判定成败的唯一标准。E1 强不蕴含 E2 强——预测越准，可捕获残差越小。**

## 4. 统计设计

- **统计单位：一个闭市窗口 = 一个观测**（窗口内等权组合的扣费净收益）。**明确记录：75 个资产×窗口不是 75 个独立观测；股票与股指不是两个独立簇。**
- **Block bootstrap 按窗口聚类**。分层结果（美股 beta / 贵金属 / 能源）仅作稳健性展示。
- **阶段一（14 天，≈10–12 窗口）＝ feasibility + 硬失败早停。** 可关闭的版本：成本过高、深度不足、数据拿不到、deployer 费吞噬 edge、明显持续负收益。**不得声称完成统计证否。**
- **阶段二（≥40 窗口，≈8–10 周）＝ 第一次 confirmatory 读数。**

### 四种状态（新增 INCONCLUSIVE）

| 状态 | 条件 |
|---|---|
| **STOP** | 均值 ≤0 **且** block-bootstrap 95% 上界 ≤0 |
| **CONTINUE** | 均值 >0 **且** 窗口聚类 95% 下界 >0 **且** Top-1 窗口贡献 <40% |
| **INCONCLUSIVE** | 均值 >0 但 CI 跨 0 → **按原规则继续积累至 80 窗口，不改规则、不判失败** |
| **MODIFY** | **仅限**数据口径错误、真值源缺失、字段语义错误这类硬错误 |

**已删除**：`正窗口比例 >50%`（人为约束，40% 胜率 + 3:1 盈亏比仍是正 EV）。

## 5. 探索性分析（不参与判定）

- **风险溢价 vs 错误定价**：窗口收益对实际跳空幅度与隐含波动率回归。**记为 mechanism analysis。收益 load 在 IV 上不能因果证明是风险溢价**——错价本身也可能在高波动环境放大。
- **E1 预测增益**：盘口相对 oracle 增加了多少信息。
- **容量曲线**：$1k/$5k/$25k/$50k 各规模的执行成本。

## 6. 风险与中断规则

- **deployer regime change**：oracle 方法、funding multiplier、费率、halt/resume 任一变化 → 标记 **structural break**，前后数据分别报告，不混算。T0 记录全部参数基线并持续监控。
- **主 dex 下架**：若 `xyz` 在实验期内下架 → 实验记为 **"中断"**，既不记证否也不记证实。（依据：`flx`/`vntl`/`km`/`cash` 四个 dex 已在数月内全部归零，部署者退出率高。）
- **访问性**：Hyperliquid 地域限制与实际可达性为**硬前置**，排在一切数据工作之前。未解决前不启动采集。

## 7. 禁止项

1. 事后挑资产、事后挑持仓时长、事后选臂；
2. 用最优参数格通过；
3. 报未扣 funding 或未扣 deployer 费的数字；
4. 把回溯当前向证据（回溯只允许在本文件冻结后运行，且期间不重叠，明标 in-sample）；
5. **用股票官方开盘价冒充平仓价**；
6. 用 OI 或全时段成交额论证闭市时段深度；
7. 把 `资产×窗口` 行数当独立样本量。
