## 1. 硬规则 v2

v1 的规则把「重大前提失效」和「普通新点子」一起延后，会稳定地生产已知有污染的数据。已拆成两条通道。

### 立即中止并复核（不等当前动作跑完）

- 发现前视偏差、样本污染、标签泄漏
- 发现接口语义错误或字段含义与假设不符
- 发现承重前提被撤销（依赖它的结论必须一起退回）

**这类问题本身就足以暂停，不需要另一条路线先给出更高的收益数。**

### 进 Parking Lot（不改变当前动作）

新母体、新维度、新点子。写下日期、来源、一句话，继续手上的动作。

允许因此改方向，需要的是**可检查的论证**：说清它会改变哪个决定、关键依赖是什么、追加成本多少。
**不要求折算成一个数**——v1 的「必须是一个数」会奖励伪精确，已删除。也不使用综合打分。

> 旧稿记载多次方向重置，但次数与动机未经本次原始记录核验，不作为对用户的诊断。普通新发现先登记其会改变的决定，重大前提失效则立即处理。

## 3. 框架说明（完备承诺已删除）

v1.1 声称「从终值分解可证明维度完备，补全一次就够」。**这个承诺已删除。**

保留的是问题分解关系：账户终值取决于资金、仓位、机会到达、每笔结果及其时间与依赖结构；每笔结果继续分为母体、筛选、入场、退出与成本。信息及时可得、交易在该规模下可执行、现金确实回收，三项都需要证据。测量方法与过程本身也可能出错。

**两条限定，缺一不可：**

1. 一个未完整定义自变量的 `W=f(...)` 不能仅凭命名保证充分性。要构成会计关系，必须明确现金流、持仓、费用与估值规则的账户递推。**即使单次结果的边际分布相同，不同的相关性、时序与资金占用也会产生不同的终值分布**——路径信息必须纳入定义。
2. **能把事后发现的因素归入某一层，不等于事前会生成它。** 这个分解是归档系统，不是发现程序。「付钱方」完美地落进层 1，可就是没人把它生成出来。

因此本账本不宣称穷尽未知。它的验收标准是：**一个足以改变选择的问题，能找到对应证据、依赖、未解部分和后续动作。**

勾选比例不是可信度。**不要把「37/54 空白」当成完善程度的度量。**

## 4. 关于「零 edge 触及 5×」的概率

旧材料中的“零 edge 高波动策略三年触及 5× 的概率 30–74%”缺少原始模型与计算依据。能构造出近似复现的模型，但不能因此认定旧数字已经得到支持；以下分别列明两个可复算的条件命题。

### 能复现，但复现不等于原计算是这么做的

若明确假设账户对数服从**零漂移、恒定波动率的布朗运动**：

```
W_t = W₀ · exp(σ·B_t)
P( max_{t≤3} W_t ≥ 5W₀ ) = 2·[ 1 − Φ( ln5 / (σ√3) ) ]
```

| 年化波动 σ | P(三年内触及 5×) |
|---:|---:|
| 90% | 30.2% |
| 125% | 45.7% |
| 200% | 64.2% |
| **275%** | **73.5%** |

30–74% 对应 σ ≈ 89%–275%。

**但**：仅有「期望对数收益为零」不足以推出这张表，还需要上述具体过程假设。**而且，现在构造一个能产生类似数字的模型，不等于证明原来的 30–74% 就是按这个模型算出的。** 原计算的出处与假设仍未提供。

### 这个模型不等于条件期望财富不增长

对 `W_t = W₀·exp(σB_t)`，账户期望值本身是增长的：

```
E[W_t] = W₀ · exp(σ²t/2)
```

| σ | 一年期望收益 | 三年期望收益 |
|---:|---:|---:|
| 90% | +49.9% | +237% |
| 125% | +118.4% | +942% |
| 200% | +638.9% | +40,243% |

**零对数漂移隐含 σ²/2 的正算术漂移。** 它可以没有择时能力，但不能充当「账户条件期望不增长」的模型。

“无优势”必须指定基准：没有选币/择时增量，并不排除市场风险溢价或被动资产的正漂移，不能宣称所有无优势模型都只能是超鞅。

另一个明确条件命题是：若账户财富 W 非负、无外部注资、以固定计价单位衡量，且为超鞅，则 `P(sup_t W_t >= 5W0) <= 1/5`。这是模型下的极大值不等式，不是本项目已经测得的真实概率；追加资金或改变计价基准后不能原样使用。[伯克利概率论讲义](https://www.stat.berkeley.edu/~pitman/s205f02/lecture19.pdf)

### 可用与不可用

**可用**：以上两条都只是模型下的换算，说明「触及 5 万」这一事件的概率对过程假设极度敏感。

**不可用**：不能把 30–74% 无条件替换成「真实概率 ≤20%」；不能由任一数字推出「触及五万对识别优势的信息量更高」或「注资更合理」。**注资政策与优势检验是两个决定。**

参考：[反射原理](https://almostsuremath.com/2023/04/18/the-maximum-of-brownian-motion-and-the-reflection-principle/)、[几何布朗运动讲义](https://www.columbia.edu/~ks20/FE-Notes/4700-07-Notes-GBM.pdf)

### 5.2 层 2 · 选择

筛选至少要同时看 `p_s`（命中率）、`m_s`（赢家条件平均回收倍数）、`n_s`（剩余机会数），还要看未命中回收、成本、时序和资金占用；三个数不构成完整策略模型。

**盈利条件不是简单的 `p_s·m_s > 1`。** 一般式为：

```
单笔期望净收益率 = p · E[M | tail] + (1−p) · E[M | other] − 1
```

上式假定条件均值存在、M 为同口径全投入回收倍数；美元/人民币利润还取决于每笔投入及其与 M 的关联。`p_s·m_s > 1` 仅在**未命中全损**（m_other = 0）且成本口径匹配时成为期望盈利条件。
反例：5% 回收 10 倍、其余回收 0.8 倍 → 平均回收 1.26 倍，原式会漏掉后一项。

> **文献缺口的准确表述**：不是「无人测量收益」，而是**缺少适用于本项目的可执行收益与账户证据**。MELT 有简化收益实验（迁移价买入、一小时内随机时点卖出，MLP Top-100 亏 26.64%）——它既不能证明你的交易可盈利，也不能证明所有退出方式都不可盈利。

### 5.3 层 3 · 交易

**历史回放能做很多事，但有明确边界。** Geth 支持在指定区块状态下调用合约与临时状态覆盖，足以支撑大量历史验证问题。**但**：分别在历史时点模拟一次买与一次卖，不会自动保存第一次买入对你的钱包、持有期与池子状态的影响；其他人的实际交易也未必在你加入后保持原样。**这个限制来自反事实，不是「加密必须先实盘」。**

历史回放、前向只读、实盘各自回答不同问题，不可互换：

| 方法 | 能回答 | 不能回答 |
|---|---|---|
| 历史回放 | 在给定历史条件下，这条规则会得到什么 | 你的介入如何改变后续路径 |
| 前向只读 | 当时信息是否真的可见、按你的规则会发生什么 | 真实成交与被打包的结果 |
| 实盘 | 真实执行影响 | 本轮不安排 |

模拟对象必须写成**策略 + 仓位政策 + 注资政策**，不能只归因于策略。

| 8 | 负权益 / 强平 / 单点故障 | 已定义禁区 | 可能造成未受限负权益且无隔离装置的结构直接排除。 |

**账户口径（三个量，不可混用；这是项目管理口径，不是税务计算意见）**：

```
V_t = 账户现金 + 按明示估值规则计量的剩余资产 − 账户负债
累计经济损益 = V_t + 累计对外提款 X_t − 累计外部投入 C_t
已实现交易损益 = Σ(已处置数量的净卖出收入 − 对应购入成本基础)
                 − 尚未计入成本基础/卖出收入的交易费用与失败费用
```

C_t 含期初本金和实际发生的追加；注资/提款是外部现金流，不是已实现交易盈亏。购入成本基础须按固定配对规则分摊买入费用；部分平仓只分摊已售数量。剩余资产的估值规则及可清算性单列，不能把未实现收益并入已实现目标。

复算例：注资 10,000、买入支出 1,000、卖出收入 1,200、另 9,000 未动，忽略其他费用时已实现损益为 **200**，期末现金 **10,200**，累计经济损益也为 **200**。不能用单笔卖出收入减掉全部注资。

运营成本只扣一次：账户内已支出则已影响 V_t；账户外支付另列。当前目标是**税前**交易净利，交易损益与扣除运营成本后的项目损益分别报告，不偷偷改变目标。汇率转换沿用明确日期和来源。

## 6. 母体实例覆盖（开放列表）

**定位坐标不是链名，而是「收益形成方式 × 链/场所 × 协议版本 × 资产阶段 × 决策时点」。**
更换链不自动产生新经济机制；同一链也不自动覆盖所有协议。**同链、同为 EVM、同构发行，都不意味着归因方法或死因可以迁移**——交易签名者、公共工厂、实际控制人、协议版本、样本阶段都可能不同。代码组件可复用，语义与样本口径必须重验。

### 搜索分支

| 分支 | 与右尾的联系 | 本轮处理 |
|---|---|---|
| 新发行、曲线、毕业或首次公开交易 | 从很小的基数扩大 | 当前主要范围，但不同阶段必须拆开 |
| 已流通资产的新催化或重新定价 | 不要求买在发行第一刻 | **原账本偏弱**，列入覆盖登记；不自动开新实验 |
| 拍卖、分配、迁移及事件驱动 | 进入成本与事件结果可能形成不对称收益 | 单列机会单位、资本与时间成本，**不并入普通新币分母** |
| 衍生品或杠杆形成的收益凸性 | 倍数可能来自合约结构而非资产涨幅 | 与现货选择分开登记 |

### 覆盖办法

记录发现来源与日期 → 将链/协议目录与既有清单做**差集** → 对差集查主网状态、官方部署与创建事件 → 记录「已纳入／同机制暂缓／缺数据／超出约束／未核验」及理由。
**保留已删除与已死亡对象**，避免只留当前热门实例。母体由工厂/创建事件重建，**不用热榜替代分母**。

是否继续扩大覆盖，由「差集是否出现改变当前决策的对象」决定，**不由链名数量决定**。

## 9. 当前主线：母体最小经济基线

**要回答的问题：**

> 在一个可重建的固定母体中，按事前确定的可观察触发与入场延迟，用固定规模与退出规则，扣除成本后是否仍观察得到与目标有关的右尾？这些右尾有多少是在**正常可参与条件**下发生的？

**为什么它先于甲**：没有必要先把身份系统做成完整分类器才开始观察母体经济空间；也没有必要在母体与成交数据都拿不到时跑一个形式上的基线。两者互补，但经济空间是前置的。

### 三种倍数必须分开记录

| 口径 | 用途 |
|---|---|
| 历史价格最高倍数 | **仅用于描述** |
| 冻结退出规则下的可执行近似倍数 | **策略评价** |
| 事后最优时点卖出 | 仅标记为事后诊断情景 |

未严格纳入所有路径、市场干预与成本时，**不得把「最好历史卖点」称作方向的硬上界**。

### 首轮只交付四样，不含信号比较

**v2.0 的「一次最小完整测量」把四类信号对照、赢家误删与开发/检验分离都写进了首轮——那已经是筛选研究，会把 8 小时的基线任务重新撑爆。已拆分。**

**首轮交付（基线）：**

| 内容 | 要求 |
|---|---|
| 母体分母 | 固定创建/迁移事件、地址、版本与时间窗；**全量枚举**，包含失败、停止交易及数据缺失对象 |
| 冻结规则下的收益路径 | 事前固定入场与退出，记录净回收倍数；**无法卖出与未完整随访要区分**，不能都删除 |
| 成本 | 手续费、gas、滑点、失败成本，按实际路径累积，不按每事件扣 |
| 数据质量 | 缺失比例、原因、识别区间；有依据才给偏差方向，否则明确不确定 |

时点四项分别保存：**事件时间 / 首次看到时间 / 特征截止 / 拟下单时间**。

**后续工作包（不在首轮，但首轮要保留所需原始数据）：**

- 简单规则基线与随机对照（随机对照须在**当时可见集合**中选择）
- 四类信号对照：无身份基线／身份·历史／简单交易·流动性特征／两者组合
- 右尾保留与误删的赢家
- 两种比较：①匹配交易数与时间/规模 → 解释信号贡献；②完整账户约束下 → 评估真实策略价值

### 本轮已经落实到文件的设计与尚未通过的门

具体参数以 **baseline-execution-config.md v2.0** 为单一执行依据：Ethereum canonical V2、WETH 新池；创建窗口为 2026 年第一季度；首次 Mint 须不晚于窗口结束，截止未触发者保留；买入快照为 Mint+1 块末，退出为实际时间戳+30天；0.05 ETH 固定规模。

主机会率分母是全部新建 WETH 候选，另报触发和成功入场条件分布。没有 Mint 不等于交易全损；无法判定的持仓或接口结果不记零。H1 只问本设定机会率是否至少 1%，零命中不等于右尾不存在；原 H2 改为描述性 D2。

`verify_capabilities.py v2.0` 已实现历史注册表探针、首次 Mint 交叉检查、可观察状态覆盖、同次执行余额测量和受控错误对照。它使用注入的合约钱包，不等于普通 EOA；两个历史时点的调用不构成完整持仓反事实。独立 EVM 离线通过不能升级为主网端点通过，更不能升级为基线完成。

**尚未启动正式样本。** 真实端点能力、全量 N/抽样框、冻结成本口径、候选状态适配和少量候选端到端质量检查，是不同条件；缺哪一项就报告哪一项，不以未使用的 trace 或 Multicall 是否可用增加无关阻塞。

### 甲、乙的定位

| 动作 | 决定 | 完成后允许得出的结论 |
|---|---|---|
| 甲：RT-A 信息可得性 | 保留为**有限探针**，2 小时内交出可审查的能力报告 | 这条信息链在**某母体、某截止时间内**可用／不可用／尚不确定 |
| 乙：旧卡审计 | 2 小时，只查影响当前母体与验证顺序的卡；**必须核对原始证据，不能只看冻结规则** | 某条死因仍成立／需复算／无法核验／仅对原条件成立 |

**甲的能力报告至少包含**：候选总分母、及时返回比例、各类错误与缺失比例、分层时延、字段语义证据、实际追加数据成本，以及**旧样本重建与新样本首次查询分别的结果**。链上发生时间与接口首次可得时间必须分开。

将**部署交易发送者／直接创建合约／公共工厂／推断控制者**分栏；无法确认的控制关系留空或带置信说明。「没查到历史」「接口失败」「确实无符合定义的历史」**不能合并成一个安全标签**。历史事件须附**当时已知**的风险标签，不能把后来的 rug 结局倒灌成过去已知的前科。

没有历史接口快照时，回填报告必须写明：**能重建当时发生的事实，不能证实当时接口可及时返回**；这一项用新候选的前向只读记录补，不需要下单。

甲不承诺任何凭空的合格线。自测通过只支持「代码实现符合既定规则」，**不支持「规则的市场语义正确」**。少量人工样本可验证字段语义，**不足以估计全体误归因率**。

## 10. 验收标准 —— 不需要先成为领域专家

| 你应当能检查的 | 可接受 | 不可接受 |
|---|---|---|
| 一个重要判断的依据 | 能打开来源、找到对应事实，知道是推论还是实测 | 只给一段自信解释或搜索摘要 |
| 一个否定结论的范围 | 明确母体、时点、规模、规则与适用期 | 从一次试验失败扩大到所有同类机会 |
| 下一项工作为什么做 | 说清它的结果会改变哪个决定 | 因为容易、代码现成、已经做了一半 |
| 已知空白怎样处理 | 说明阻塞什么、能否暂缓、何时再检查 | 空白越多越好，或全部塞进停车场 |
| 错误怎样传播 | 找到依赖这条错误的结论并**一起重审** | 改一个句子，但后续优先级不变 |
| 置信度依据 | 材料质量与复核结果 | 回答长度、模型数量或语气 |

**本账本可被推翻的主要条件**：甲已有但未提供的结果显示可靠的经济增量；原始死亡卡足以支撑当前排除；基线表明该母体在可参与条件下经济空间不足；或一个新候选用更低追加成本提供了更关键的证据。**拿到这些材料应更新取舍，而不是保护本账本的结论。**

维度部分由分解关系整理而来，**但不宣称穷尽未知**；实例部分永远补不完，由每周例行持续追加。
