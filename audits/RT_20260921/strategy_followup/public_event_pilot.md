A secondary display contains dated risk messages for the supplied BUvu... mint, including 2026-06-09, but there is no original message URL, timezone, or edit history, so `propagation_time_verifiable` is false and only `displayed_copy_date_available` is true. The 2026-06-25 item was excluded: the same GOKU page identifies a different mint (Dm8g1s9t...). The page was reviewed message by message; ticker-only attribution was not used.

The four misses are recorded as “this channel did not detect a result”; they are not claims that no propagation exists. Current metadata is not used to infer identity at any earlier date. No performance, returns, case-seed, or strategy conclusion is included.
