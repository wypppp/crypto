## 逐项说明

### 1. Helius funded-by 端点
- **功能**：查询某钱包的"初始出资者"——即首笔资金的来源地址  
- **路径**：`https://api.helius.xyz/v1/wallet/{wallet}/funded-by?api-key=YOUR_API_KEY`  
- **返回字段**：原始出资地址及其关联信息（未确认完整字段）  
- **成本**：100 credits（所有 Wallet API 调用统一价格）  
- **免费档**：不支持（403 Forbidden）；需 Developer 计划以上  
- **批量支持**：未确认

### 2. Helius API 各端点 credits 消耗
- **getSignaturesForAddress**：1 credit  
- **getTransaction**：1 credit  
- **getTransactionsForAddress**：1 credit  
- **getProgramAccounts / 归档调用**：10 credits  
- **DAS（Digital Asset Standard）调用**：10 credits  
- **Wallet API 全部端点**：100 credits（统一价格）  
- **参考官方价格页**：https://www.helius.dev/pricing

### 3. Jito Bundle 历史查询能力
- **API 端点**：`https://mainnet.block-engine.jito.wtf/api/v1/bundles` + getBundleStatuses  
- **查询方式**：需提供 bundle_id；不能按交易签名反向查  
- **时间回溯**：仅最近 300 个 slots（约 2 分钟内提交的 bundle）  
- **2026年6月数据**：不可直接查询（超时效）；需用 Bitquery 或链下日志  
- **Jito Explorer**：https://explorer.jito.wtf/bundle-explorer（UI 仅展示最近数据）  
- **费用/限制**：无官方速率限制信息；支持最小 tip 1000 lamports

### 4. CEX Solana 热钱包列表来源
- **Dune cex.addresses**（推荐）  
  - URL：https://docs.dune.com/data-catalog/curated/cex-flows/overview  
  - 覆盖 29 条链；Solana 交易所齐全  
  - 免费 SQL 查询，支持自定义筛选  

- **Solscan 标签系统**  
  - URL：https://info.solscan.io/  
  - 网页查看交易所地址标签；无 API 批量导出  

- **Vybe Labeled Wallets API**  
  - URL：https://docs.vybenetwork.com/docs/labeled-wallets  
  - 含 Binance Hot Wallet 1、Coinbase Commerce、Kraken Hot 等  

- **CEX.IO 官方清单**  
  - URL：https://blog.cex.io/wallet-address-list  
  - 仅列出 CEX.IO 自有地址（3 个 Solana 热钱包）
