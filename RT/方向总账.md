## 怎么读

**状态**（只用这 8 个词；10-03 起不以合规、额度、时间为由把任何方向记为“资源停止”，此前因这三类原因停下的行已改，见文末 §8.4）：

| 状态 | 含义 |
|---|---|
| 活跃 | 用户裁决选定、当前在投入研究资源 |
| 被动前向 | 卡片已冻结，只等前向窗口或留出评分，不再投入新研究 |
| 实现关闭 | 所测的具体实现按冻结判据或明确的全成本结果关闭；**只关该实现**，同一方向的其他实现不受影响 |
| 资源停止 | 没有经济上的否定，因成本、额度、偏好或用户裁决停下 |
| 无效检验 | 做过的检验测不了它声称的假说（测量失配、代理不适用、用已撤销的门槛判死），不能当正负证据 |
| 未测 | 提出过，没有做过任何针对它的检验 |
| 暂缓 | 做过部分测量或设计，等一个写明的条件（数据、裁决、优先级）满足后再推进 |
| 只描述 | 只有描述性结果（无冻结判据，或越权测量已降级），不作正负证据 |

**证据**：案头（文献、规则、无本方数据）／描述／开发（看过数据后定的规则）／确认 T1・T2・T3（02 §10.10）／前向／实盘。
**前人工作**：旧＝查过旧债务；外＝查过外部文献或工具；—＝没有记录。
**代码**：审＝在 10-02 GPT 代码审计范围内；手＝有手算预期值的测试；v2＝已有审计修复版；无＝没有代码或只有案头。
**数据**：免＝免费公开；存＝已存档在仓库；D＝需 Dune（试用期 10-13 结束；之后需要什么档位由执行模型说明需求、用户付费，用户 10-03）；付＝付费。
**场所**：依赖的交易场所，只写场所，**不做资格判断**（用户 10-03 裁决第 1 条：今后不以合规、额度、时间为由淘汰或降级任何方向，只按优先级执行；资格核查结果只作信息留存，见 [平台资格核查](5_参考/检索记录/平台资格核查_GPT_1002.md)）。
**右尾**：是＝目标是少数大倍数结果；否＝收费、做市、卖尾部或小幅漂移；不明。
