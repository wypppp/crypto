**各文件夹里的其他东西**

- `checks/`：复算结果（JSON、CSV）。报告里的数字来自这里。
- `*.py`：审计自己写的核验脚本。与实验脚本一样，按整理前的目录编写，复现方法见 [1_实验/README.md](../1_实验/README.md)。
- `2026-09-20_…/history/`：审计时各历史提交的文档副本，用来核对“当时写了什么”，只读。
- `2026-09-20_…/snapshot_manifest.json`：审计输入快照的逐文件哈希。快照本身已删除，可重建，方法见审计报告顶部的说明。
- `2026-09-21_…/before/`：复核修改前的文件留档，只读。
