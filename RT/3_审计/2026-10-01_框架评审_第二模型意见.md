## B. 第二模型意见（`review.md` 原文）

**我的判断：现有证据支持停止已测的 pump 做多规则，但不支持“右尾优势三年内无法确认”，也不足以据此降低动用 1 万元的证据标准。** 现在最值得修正的，是几个把局部测量提升为整个框架结论的地方。

我核对了指定提交 [`e31db9f`](https://github.com/wypppp/crypto/tree/e31db9f) 的入口、事实库、方法、相关结果和审查文件。本轮是框架评审，没有重新从原始交易完整复算 F120—F126。另有一处版本差异：该提交中的 F121 仍写“最大 10 格占净额约 60%、按币等权 0.984”，与你提供的后续复算“97.78%、0.945”不同；F126 也仍标“待门 3”。后续审计应写入固定版本，避免第三方把不同版本混在一起。

先把四类东西分开：


| 类别 | 当前能够成立的表述                                             |
| ------ | ---------------------------------------------------------------- |
| 目标 | 三年内净赚 100 万；亏损暂停、永久停止规则是用户选择            |
| 事实 | 已测规则多数亏损；窄类做空有开发期正结果；若干均值高度集中     |
| 假设 | 外部参与者存在可复制优势；某种机制能提前识别；优势能持续到兑现 |
| 约束 | 只限加密、不拼毫秒速度、数据预算有限、确认样本需要保护         |

**“有人持续赚钱，所以一定有我们能采用的方法”仍然是未证假设。** 即使前半句属实，也可能依赖你没有的筹码成本、客户流、资金规模、交易权限或信息位置。正确的桥梁是：他们凭什么赚钱，其中哪一部分对你可达。

对整个框架，我先提出四项挑战。

**第一，F121 回答了“这批交易的现金流向哪些组”，没有回答“哪些外部参与者持续赚钱”。** 分组盈利可以由少数币、少数钱包或隐含筹码成本造成。`sellonly` 更不能直接等同内部人：从其他地址转入、其他池购买、空投等，都可能形成这个标签。

记账闭合与盈利组复现有价值，但它们只验证了管线的部分能力。它们没有验证反事实入场、仓位冲击、止损成交和跨协议持仓估值。因此，“管线通过阳性对照”不能升级为“整个策略检测器已经认证”。

**第二，“零优势上界 2.9%”有条件成立，但“尚未验证优势”不等于满足那个条件。**

需要的是：利用当时可用信息采取的下注，其全成本净盈亏过程是超鞅，并且净亏损确实被限制在 3 万以内。此时：

\[
P(\text{先达到净赚100万})\leq \frac{3}{103}.
\]

仅有“样本平均不为正”或“没有显著正结果”，不足以建立这些条件；止损穿透亏损底线，也会破坏该推导。它适合作为无优势情景的参照，不适合作为当前项目成功概率的估计。

**第三，阶段标准混入了与目标函数不同的东西。**

[阶段二容量文件](https://github.com/wypppp/crypto/blob/e31db9f/RT/1_实验/全程序_财富路径函数_WP/阶段二容量下限.md) 把

\[
P=\text{年事件数}\times K\times\text{平均净收益率}
\]

当成“每年最多能赚多少钱”。这通常是平均利润估计，**不是确定性利润上界**。用平均收益率代入平滑增长函数，也不能得到右尾财富路径的严格上界。

60 万元/年可以保留为用户设定的准入要求，但不能称为最终目标的普遍数学必要条件。同样，预期对数增速低于阶段线，不代表达到目标的概率为零。否则，你们又会以另一种形式重复“撑不起目标，所以没有优势”的旧错误。

**第四，“右尾验证墙”被扩大了。**

F125 的约 1,400 个事件，是对某条规则、某个效应量和一个极不稳定方差的功效估计；其中最大的事件还没有建模 ADL。它不能推出“所有右尾优势三年内都无法确认”。

真正成立的是：**如果优势只能靠罕见且尚不可执行的极端事件体现，现有数据无法可靠估计它。** 这是该候选的缺陷，不是所有右尾研究必须接受的证据豁免。

对 Q1，我支持做钱包持续性检验，但必须分开两个问题：

1. 这些钱包自身是否具有可重复的全成本盈利？
2. 外部人在观察到它们之后，是否还能取得盈利？

原设计最大的漏洞如下：

- **仅按已实现盈亏排名，会奖励“卖赢家、留输家”。** 必须处理期初库存、期末持仓、转入筹码成本、跨池交易及网络费、小费；无法可靠归因的库存单列。
- **钱包不等于人。** 一个实体可以用多个地址；一个地址也可能承担中转或服务功能。
- **资金往来不等于内部关系。** 共同交易所来源、归集服务、普通转账会误杀；内部人也可以完全断开可见关系。关系标签必须按排名时已知信息冻结。
- **排名本身有选择偏差。** 钱包数、排名指标、选中数量、最低活动量和验证窗口须先冻结，不能看验证结果后挑幸存者。
- **币与时间仍然相关。** 多个赢家可能只是共同持有同一只币。按币记账之外，还应按时间与实体检查集中性。
- **活跃度相近的随机钱包不足以排除其他解释。** 至少还要考虑入场阶段、交易规模、换手、持有期及市场暴露。
- **自身赚钱不代表跟随赚钱。** 跟随测量必须加入你自己的观察延迟、下一次可成交价格、独立退出和容量。

最值得交付的是“被冻结的钱包集合在下一窗口的整体表现”，不是几个漂亮地址的故事。

如果结果为负，只能说**该排名法没有找到可重复、可复制的外部优势**；不能推出“pump 只有内部人和最快机器人能盈利”。有限检验无法完成这种排除。

工具上可以复用现有 WM 记账，并用 Dune 的 `dex_solana.trades` 补跨池核对。但官方表按多跳交易的每一段分别记录，不能直接把所有行当作独立买卖累加。[Dune Docs](https://docs.dune.com/data-catalog/curated/dex-trades/solana/solana-dex-trades?utm_source=chatgpt.com)

对 Q2，**可以增加这个指标，但不能用它替代经济指标。**

连续价格鞅、起点为 1、最终恰好触及 0.5 或 3，且满足可选停止条件时：

\[
p=\frac{1-0.5}{3-0.5}=20\%.
\]

如果往返后净回收约为价格倍数的 97.5%，理想化保本命中率约为 21%。但真实交易应使用：

\[
p_{\mathrm{BE}}=\frac{1-R_L}{R_W-R_L},
\]

其中 \(R_W,R_L\) 是成功与失败交易的**实际全成本回收**。

举例，赢家平均拿回 2.8，输家只拿回 0.25，保本命中率就变成 **29.4%**。此时 30% 的漂亮命中率几乎没有经济余量。这是推导示例，不是你们的实测值。

还需要补上四个问题：

- **有限期限内两道边界都没触及怎么办？** 不能删掉这些事件；强制平仓又会改变收益分布。
- **跳跃会穿透边界。** “价格先触及”不等于“仓位按边界成交”。
- **历史数据能否识别先后顺序？** 同一根 K 线同时穿越两道边界时，不能默认有利顺序。
- **20% 是理想无方向基准，不一定是你的实际母体基准。** 应同时比较相同决策时点、相同交易条件下的随机选择。

“110 个事件”也需要注明功效。我用精确二项分布复算，单侧显著性水平 5%、真实命中率 30%：


| 零假设命中率 | 110 个独立事件的检验力 |
| -------------- | -----------------------: |
| 20%          |                 约 76% |
| 21%          |                 约 69% |

所以，若要求 80% 检验力，110 个不够；相关性与多次试验还会增加需求。

更值得考虑的替代是：**保留原退出规则，用事前冻结上限截断后的回收均值做保守检验。**

例如：

\[
Z=\min(R,3).
\]

如果可信的区间能支持 \(E[Z]>1\)，那么也支持 \(E[R]>1\)。这样不必真的在 3 倍卖出，也不必依赖百倍事件证明盈利。检验未通过时，则不能据此否定原策略，因为被截掉的尾部可能重要。

有界均值的置信序列已有论文和开源实现，可以复用；它们解决的是统计检验问题，不能消除交易相关性、行情迁移或成交模型错误。[arxiv.org](https://arxiv.org/abs/2010.09686?utm_source=chatgpt.com)

对 Q3，**缩小母体完全合理，但“必须不用价格和成交量”没有方法论依据。**

缩母体、筛选和选币，在统计上都是条件化。关键是条件是否事前可见、是否有经济理由、以及条件化后的真实收益。非价格信息也会被制造；价格信息也可能包含有效信息。


| 范围             | 机制依据                                   | 最关键的问题                                             |
| ------------------ | -------------------------------------------- | ---------------------------------------------------------- |
| 非批量发币账户   | 可能减少工业化出货，但 F118 只支持局部改善 | 新地址可能掩盖同一批量实体；改善仍未达到盈利             |
| 同名币原版       | 注意力可能向公认代表集中                   | 最早创建不等于公认原版；不能用未来出现的仿币定义今天入选 |
| 对应现实热点     | 外部注意力可能带来新增需求                 | 热点人群是否真的买币；注意力先发生还是币价先发生         |
| 存活七天仍有成交 | 可能排除短命发行、进入不同参与者阶段       | 必须按第七天重新入场测量，不能拿早期赢家标签证明剩余空间 |
| 持续盈利钱包买入 | 可能压缩其信息与判断                       | 先证明持续性，再证明观察之后仍可交易                     |

尤其是“原版”：若要求“未来 N 小时出现至少 k 个同名币”，就又引入了未来信息。可以在第二个仿币出现时识别原版，但决策时点和入场价格必须相应后移。

外部论文确实发现仿币和操纵广泛存在、原版更容易毕业；**毕业率差异不等于外部买家的净收益差异**。同一论文的“17%”是研究样本中交易笔数的刷量下界，主要数据截至 2026 年 1 月，不能直接当作你们六月样本的成交额比例或失败原因。[arxiv.org](https://arxiv.org/html/2609.10246v1?utm_source=chatgpt.com)

对 Q4，**“选”应变成可审计的判断，而不是给每笔交易补一个理由。**

一份最小决策记录需要回答：

- 什么新事实改变了判断，来源和可见时间是什么？
- 它会让谁增加需求或减少供给，持续多久？
- 为什么当前价格还没充分反映它？
- 在同一候选集合里，为什么选这只、放弃其他？
- 哪个事实出现时，理由失效？
- 入场、退出、仓位和最大损失如何确定？

必须记录**没交易的候选与拒绝理由**，否则只有买入日志，无法评价选择能力。

评价时至少保留两种对照：同一母体随机选择；只用已有量价信息选择。新理由有没有经济增量，由这两个对照帮助识别。命中率用于解释，净回收与账户路径用于判断价值。

小额实盘只增加执行证据。十笔成交顺利、偶尔赚到钱，都不能证明这套理由有优势。如果用于检验策略，它就应按实盘规则启动计时，不能一直归入校准账户。

对 Q5，**我建议增加第五个选项：保留目标，但实行有限的证据梯度，而不是在“完全确认”与“凭机制下注”之间二选一。**

截至目前，我不建议仅凭“机制论证＋小额实盘＋硬亏损上限”启动策略资金。亏损上限控制代价，不会提升假设为真的概率。

10-16 可以作出以下具体决定：

1. **结束解锁的这一轮便宜测量，但修正它的定位。** 当前快照结果应称为有事后信息的探索测量；它不是天然上界，负结果也不能自动关闭真实时点策略。
2. **只给钱包持续性一个有限的可行性核查机会。** 先解决库存、跨地址成本和跟随时点，核查不通就停，避免直接扩大取数。
3. **给研究设总资源上限。** 包括日历与时间投入，不能只限制数据账单。
4. **任何策略资金准入，都要求候选自己的证据。** 至少包括可信记账、可达信息、冻结规则的独立表现，以及实测执行条件；不因为“右尾难确认”获得统一豁免。

若候选只能靠一个不可执行极端事件盈利，且没有更便宜的独立检验，我会将其暂停。对已经登记的做空窗口，可以维持现状；以后若设计新窗口，可以考虑预先登记中期检验，而不是把“等完整的 32 个月”当成统计严谨的唯一方式。

解锁还有两个具体提醒。Keyrock 原文确有负向压力和提前漂移结论，但它使用 ETH 归一化、涉及约 40 个币的重复事件；这不等于做空策略有 90% 胜率，也未证明扣资金费后的收益。[keyrock.com](https://keyrock.com/from-locked-to-liquidity-what-16000-token-unlocks-teach-us/?utm_source=chatgpt.com)

“没有现成免费的完整按时点日历”也不等于“任何历史解锁都无法免费重建”。部分链上归属合约带有开始、cliff、释放频率与金额参数；仍需逐项核对当时是否已创建、能否取消和是否发生变更。这只能支持一个窄子集，不能冒充完整日历。[Streamflow Documentation & Help Center](https://docs.streamflow.finance/en/articles/9670413-create-a-vesting-contract?utm_source=chatgpt.com)

对 Q6，我没有找到证据足以宣布一个全新的可盈利方向。repo 已经列过协议收入、强平接单、积分空投等，不能把它们重新包装成“盲区”。但有三个环节仍明显欠缺测量：

**一是，谁必须交易。** 解锁接收者、赎回者、清算者可能因约束而交易，研究重点应是其约束何时成立、交易需求是否已经被预先对冲，以及你能否在无需拼速度的期限内承接。大量看似自然的“解锁卖压”，可能早已在别的时点表达。

**二是，价值到底归谁。** 平台使用量增长，不自动意味着平台币升值。手续费可以流向创建者、LP、股东或服务商。C9 应先核对代币持有人的可执行权利，再研究使用量领先价格。

**三是，收益工具是否与信息匹配。** 预测大波动，与预测上涨是不同能力。前者可能在某些工具上有价值，但必须比较购买凸性的价格、点差、期限和成交容量；不能把廉价观察到的波动当作廉价买到的收益。现有 pump 负结果只约束已测的做多表达方式。

我会把下一轮的核心问题写成：**哪一种可达信息，能让我们在特定价格、特定工具和特定期限内，取得扣除错误判断与执行成本后的优势？** 这比“从筛转向选”，也比“什么证据足以赌右尾”，更容易得到可检验的答案。
