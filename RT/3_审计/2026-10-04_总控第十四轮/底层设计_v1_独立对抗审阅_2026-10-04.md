**1 第 0 节诊断：部分成立**

代理指标需要接到最终财富目标，这点成立。但“问题不在数据与流程”不成立；数据可成交性、可得时点、样本暴露、市场漂移和尾部样本稀少都仍是承重问题。160 行总账包含方向、实现、描述、依赖和历史债务，不是 160 次同质独立实验，不能用关闭比例衡量研究效率。

**2 目标层：目标成立，推导和基准部分成立**

目标可写为：在约定的入金、提款、暂停和停止规则下，最大化 36 个月内累计净收益首次达到 100 万元的概率，并要求存在可信的全成本正期望证据。这里“正期望”是总体未知量，不能用同样本点估计大于零当成已经满足。

账本应先冻结：累计净收益 = 可执行净清算价值 + 累计提款 − 累计外部入金。暂停线是累计净亏损，不是所有亏损交易金额相加，也不是从历史最高权益回撤。2 万暂停后何时恢复、需多长纸盘、期间时钟是否继续、无法再下最小订单如何处理，都影响结果。背景.md 还有“一年内 1 万增长到 10 万后追加 2 万”的条件入金；附件没有明确保留或废止，模拟前必须对齐版本，不能默认本金永远只有初始 1 万，也不能默认立刻取得全部 3 万风险预算。

每注分布、机会数、容量、下注规则四项不够。至少还需持有期、信号到达日历、并发与相互相关、成交失败与延迟、收益与容量的联合关系、市场状态变化、暂停恢复机制。成功以整个账户同时可清算的金额判定，不能把各币不同时间的峰值相加。

无优势基准：若全成本累计净盈亏为超鞅、最大亏损确实不超过 3 万、不存在跳空越界和未计负债，则任意合格策略的目标触达概率满足 P ≤ 3/(100+3)=2.9126%。这是含条件的上界，适用于比例下注等可容许策略，不只孤注式下注；它不是某种孤注策略三年内可实现的概率。“比例下注接近零”不是一般定理。“候选必须明显高于 2.9%”可以是额外偏好，但不是正期望的必要条件。

**3 评价层：部分成立，g×机会数不宜成为唯一主指标**

g(f)=E[ln(1+f(R−1))] 是合理的增长诊断，g*=max g 也适合研究仓位。但它优化长期对数增长，不等价于最大化有限期限首达概率。真正主评价应是固定政策、真实资金与成交约束下的账户结果；研究初期不能识别精确 P 时，用证据强弱和情景区间，不能编造一个精确排名。

只有在顺序可复用资金、定义一致、分布足够稳定且容量未改变回报时，g×机会数才有简单解释；它是年预期对数增长，不是百分比收益。期望的可加性本身不要求独立，但首达概率、方差和置信度强烈依赖相关性。不能再乘一次容量形成“g×频率×容量”综合评分：量纲不一致，也会重复计算约束。

三个数学边界：

- 若 E[R]≤1、0≤f<1，则由 Jensen 不等式，E ln(1+f(R−1))≤ln(1+f(E[R]−1))≤0。同一净收益分布换成 Kelly 不能救活负期望。
- 允许 f=0 时，g*至少是 0。它会把没有下注价值的候选都压到零，不能用“g*非负”当通过。
- 在同一样本挑最佳 f、再对这个最优值给普通自助区间，会有选择偏差。f 和策略都应在训练部分确定，测试时固定；或者使用同时有效的置信界。

Z 保留为一个正期望充分证据通道，不只叫“左尾健康”；它还反映截至截断点的正收益。全买保留为经济对照，但不要求所有策略必须胜全买才能盈利；若声称选币增加价值，则仍须与同时间、同规模、同交易数或同资金预算的随机选择比较。取消统一 1400 美元容量判死线合理，取消可执行性和最低经济规模约束不合理。

附件的 q×兑现倍数是回款，不是净收益。应写 Δ现金=实际卖出净回款−实际买入支出−未包含的成本；若 R 已含全部成本，则净利润=q(R−1)，不得二次扣费。R 是仓位和路径的函数 R(q)，不是把零规模 R 乘上 min(q,容量)。未投出的现金仍留在账户。即使 1 万本金，低 p 半 Kelly 的几元订单也可能先被最低成本约束，不必等到本金 50 万才出现容量问题。

稳健 g 下界建议分三步做。

第一步，先建立不依赖极端赢家具体倍数的保守证书。固定 f、K，全部成本包含在总投入中且 0≤R，令 p_L 为 P(R≥K) 的单侧下界，则

g(f) ≥ p_L ln[1+f(K−1)] + (1−p_L)ln(1−f)。

这直接把命中率下界转成增长下界。它把未命中全部按归零、命中全部按 K 处理，成功给出充分证据，失败只说明这张保守证书不够。p_L K−1>0 只足以证明算术期望为正；给定 f 的 g>0 需要更高 p。例如 K=100、f=1% 时，p 必须超过约 1.4395%，而不只是 1%。

可把上述证书扩展成多个预先固定的回收台阶 0=r0<r1<…<rJ，例如 0、0.5、1、2、4、10、100。定义 h_f(r)=ln[1+f(r−1)]，对每个尾概率 p_j=P(R≥r_j) 建立同时有效下界 L_j，则

g(f) ≥ h_f(0)+Σ_j [h_f(r_j)−h_f(r_{j−1})]L_j。

这样保留未命中币残值，也限制单个超大币贡献。尾概率界同时有效时，同一事件分布下该不等式可对全部 f 同时成立；但若 f 改变实际交易规模和 R，就必须分别评估对应分布，不能复用固定 R。

第二步，对固定政策计算封顶后的对数回报 Y=min{ln[1+f(R−1)],u}，u 在读结果前写定，下界 a=ln(1−f)，故 Y∈[a,u] 且 E[Y]≤g。对 n 个独立同分布观测，一种可直接实现的单侧经验 Bernstein 下界为

L=平均Y−sqrt[2 s² ln(2M/α)/n]−7(u−a)ln(2M/α)/[3(n−1)]。

s² 用样本方差，M 是需要同时保护的固定政策/截断选择数。这是有明确条件的有限样本界；以 −Y 应用 Maurer–Pontil 的界即可得到该方向。[E8] 不要把下尾亏损向上截断。u 的封顶不是实际止盈，不能替代交易收益；证书不通过同样不代表原策略无效。

第三步，处理依赖和漂移。逐币 CP/Bernstein 的 iid 条件在本项目通常不成立；不得把 n 换成随意估算的有效样本数后称为精确区间。确认时对固定账户政策按连续日历块评估，保留整段多币共振、并发、持仓与现金流；采用移动块自助，按持有期和开发期相关长度事前定块长，并报告块长敏感性。若用块均值做有界检验，应明示目标变成等权块均值、给出可证明的块边界，并承认块间独立是额外假设。23 个周块对罕见尾部很弱；180 天持仓不能靠一周一块自然解决相关。

必须同时列出贡献最大的 1/3/5 币、1/2 个创建者簇、最佳一周/一行情阶段的剔除压力结果，以及赢家来自多少个不同时间段。剔除测试不是置信区间，也不能以“删掉任何大赢家就必须盈利”为右尾策略的新硬门。只有一个超级币支撑时应写“频率尚未确认”，而不是通过自助复制它来制造三年可靠性。

普通分块自助不够：它不能补出未见过的尾部、修复选择偏差或证明未来制度不变。EVT/Pareto 尾部拟合最多是敏感性情景，不适合用个位数极值产生确认级外推。

**4 分解层：作为诊断部分成立，作为四个独立问题不成立**

幅度、方向、路径结构、持久性高度相关；方向必须相对入场时间和期限定义，持久性是路径性质，退出规则又会改变“上涨/止损”的分类。F83 的赢家富集不是一个与方向完全无关的幅度测试。“路径结构未测”也太宽：F83④、DQ-8A 等已有特定延后、加仓和退出测量；应写“未系统隔离路径信息的增量”。

可改为三个共享接口：事前状态与可见信息；未来可成交路径及其标签；行动政策带来的账户现金流。四个问题保留为标签与消融视角，每项都须固定其他部分，并报告交互，不授予独立通过状态。

选币和择时可以操作性拆开，不能经济上彻底分离。以相同可见事件集合，做 2×2：基准选择/新选择 × 基准时间政策/新时间政策；每格沿真实路径估值。除了两个增量，报告交互 G11−G10−G01+G00。等待期间死亡、再也不触发、资金闲置都留在原分母；不能只比较成功等到第二次入场的币。退出消融同理，先固定入场再比较退出。

同币“时间顺序打乱”作为 AMM 经济安慰剂不成立。乱排价格会割裂储备、交易量、LP 增减、费用累计和迁移事件；乱排交易也可能使卖家尚未取得筹码、储备不足或迁移时序不合法。即使重建一条代数上可行的恒定乘积曲线，也没有证明原交易顺序在零假设下可交换。两种结果相同既可能是没信号，也可能是检验无功效。

最小替代：保留真实路径，在同日、同币龄、同市场状态、同可见流动性风险集中置换信号或随机选相同数量的真实决策事件，再执行同一政策；对择时，用相同风险集上的固定随机等待或预登记偏移。匹配与可交换性仍需说明，先把它称为负对照，不应自动声称精确因果检验。

“公平赌局不能靠时点变正”需限定为：相对于策略可用信息的折现可交易价格是鞅，策略自融资且可容许，满足可选停止条件。AMM 边际报价不是天然满足该前提；流动性和成本变化也能改变净收益。过山车亦不必卖在最高点附近：曾涨 100 倍后在 10 倍卖出仍有右尾；不能把事后峰值兑现率当唯一退出目标。

**5 地图与两类右尾：部分成立，当前定义与试验账需改**

最低可用定义：先固定本方入场价、仓位 q、固定期限 H、可清算回收路径 V(t;q)。令 M_H=max V(t;q)。在 M_H≥K 的币中，用期末 V(H;q) 划分：≥K/2 是“期末保有型”；<1 是“期末回落型”；中间单列；未满 H 或数据不足单列。这样互斥且有有限期限，避免“以后总有一天跌回去”这种无法成熟的标签。若一定叫“持久”，再预定一段时间的占用比例或谷值规则；单个第 90 天报价不证明持续站稳，也不能把 90/180 天事后择优。

**附录 A 独立复算方法**

二点模型中 f=(p−(1−p)/(K−1))/2，a=ln[1+f(K−1)]，b=ln(1−f)。第 n 注、命中 k 次的对数财富为 k a+(n−k)b。动态规划仅保留尚未到达上下边界的概率质量，从 (n−1,k) 分别以 1−p 和 p 迁移；每一步对上界吸收的质量累加，即得到期间首次触达概率。

```python
import math
import numpy as np
from scipy.stats import binom

def first_passage(p, K, N, target=101, lower=0.1):
    f = (p - (1-p)/(K-1))/2
    a = math.log1p(f*(K-1))
    b = math.log1p(-f)
    alive = np.ones(1)
    success = failed = 0.0
    for n in range(1, N+1):
        nxt = np.zeros(n+1)
        nxt[:-1] += alive*(1-p)
        nxt[1:] += alive*p
        k = np.arange(n+1)
        logw = k*a + (n-k)*b
        hi = logw >= math.log(target)
        lo = logw < math.log(lower)
        success += nxt[hi].sum()
        failed += nxt[lo].sum()
        nxt[hi | lo] = 0
        alive = nxt
    g = p*a + (1-p)*b
    return f, g, math.log(target)/g, success, failed

for p in [0.003, 0.02, 0.1, 0.3]:
    for n in [156, 1092]:
        print(p, n, first_passage(p, 1.3/p, n))

for alpha in [0.05, 0.05/3]:
    for desired_power in [0.8, 0.9]:
        for n in range(1, 10000):
            critical = int(binom.isf(alpha, n, 0.01)) + 1
            size = binom.sf(critical-1, n, 0.01)
            power = binom.sf(critical-1, n, 0.03)
            if power >= desired_power:
                print(alpha, desired_power, n, critical, size, power)
                break
```

该程序不是项目账户模拟器：没有费用、容量、异步结算、补仓、真实暂停恢复和市场漂移；只用于核验附件表格。将表里的 433/4.3 当精确数会破坏 pK=1.3；本复算采用未四舍五入值。
