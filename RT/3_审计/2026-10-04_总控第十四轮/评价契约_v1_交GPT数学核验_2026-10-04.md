## 0. 总原则（采纳 GPT 审阅）

**1. 先证明优势，再看到达能力。**
- 一个固定政策要先在本方可成交条件下，通过 §3 的某个确认通道；然后才用 §4 的账户模拟，比较它在真实账本和期限下的到达能力。
- 到达概率和对数增长 g，都不能代替优势证据。

**2. 换指标不会制造新的独立证据。**
- 已经打开过的数据上算出的结果，一律只算开发证据。

**3. 确认时整包冻结。**
- 入场、选择、退出、下注、成本作为一个整体冻结，只关闭被测的那个实现。
- 开发期用配对消融（§5）找出是哪一块起作用。

## 1. 资金账本

本节的细则由总控代定：背景.md 未写明，用户 10-04 授权总控决定，用户可推翻。

### 1.1 记号与成功

- **T0**：第一笔计划资金的实盘交易时刻。≤$300 的校准账户不算（09-30 裁决）。
- **四个量**：
  - D(t)：累计入金；
  - W(t)：累计取出；
  - V(t)：可清算价值，即现金加上每个仓位“此刻整仓卖出”的可执行回款（按当时池子状态，扣费用与冲击；没有可卖路径的记 0）；
  - N(t)＝V(t)＋W(t)−D(t)：累计净收益。
- **成功**：36 个月内首次出现 N(t) ≥ 100 万元。按清算价值判定，不把不同时刻的峰值相加。
- **估值频率**：每笔成交时，以及至少每日 UTC 00:00 各估一次。
- **尘埃核销**：V(t) 低于最小票面 m_min（见 §2.4）时，按 0 计。
- **取出**：成功前不取出，W＝0。背景.md 第 3 条：利润原则上留在账户。

### 1.2 分批入金（背景.md 第 4 条的实例化）

| 规则 | 内容 |
|---|---|
| 第一笔 | T0 投入 1 万 |
| 第二笔 | 阶段 A 中，D＝1 万且 V 核销为 0 时，自动投入 1 万 |
| 盈利追加 | T0 起 12 个月内，D＝1 万且 V ≥ 10 万时，追加 2 万，只一次 |
| 入金上限 | 累计入金 ≤ 3 万 |
| 暂停 | 阶段 A 中 N ≤ −2 万：立即清仓，停止开新仓，三年时钟继续走 |
| 恢复（第三笔） | 暂停 ≥90 天，且某个冻结政策（含下注规则）在**暂停开始后新采集的前向模拟盘数据**上，通过其卡片预先写定的确认通道（§3 的 C2 或 C3）。满足后，若 D < 3 万则投入 1 万，进入阶段 B |
| 阶段 B | 不再有暂停线 |
| 永久停止 | 任意阶段 N ≤ −3 万 |

**代定理由**

- **时钟继续走**：如果暂停时停表，等于延长期限，反而奖励暂停。
- **暂停即清仓**：否则暂停期间的持仓可以把 N 继续推过 −3 万，暂停线就失去作用。
- **恢复标准与确认标准相同**：背景.md 要求模拟盘达到“长期盈利”标准。把它实例化为“同一确认通道、用新数据”，就不会另造一个更宽松的标准。

**已知后果（照写，不回避）**

- 盈利追加之后，如果账户再归零，N＝−3 万，触发永久停止。
- 右尾策略在 90 天的前向模拟盘里可能一次也命中不了，于是无法恢复。这是有意的保守。

### 1.3 账本测试情景（参考实现 T10，全部通过）

1. 第一笔亏完 → 自动投第二笔 → 再亏完 → 暂停，N＝−2 万。
2. 第 6 个月 V＝10 万 → 追加 2 万（D＝3 万，V＝12 万，N＝9 万）→ 归零 → 永久停止。
3. 第 13 个月才到 10 万 → 不追加。
4. 暂停后恢复 → 投第三笔（D＝3 万）→ 阶段 B 中 N＝−1.5 万不暂停 → 归零 → 永久停止。
5. 追加之后回落到 N＝−2 万（V＝1 万）→ 暂停；恢复时入金已到上限，不再投。
6. 第 30 个月 N ≥ 100 万 → 成功；第 37 个月 → 期满，不判成功。

## 2. 下注政策

本节由总控代定，用户可推翻。

### 2.1 研究目标与支付路径不冲突

- 选币研究的目标，是精准选中 10～100 倍以上的事件。这与背景.md“单次极端右尾为跃迁必需”一致。
- 下注规则只在策略通过确认之后才启用。

### 2.2 保守分布与保守 Kelly

- 用 §3.3 的台阶同时下界 L_j，构造保守分布：P(R＝r_j)＝L_j−L_{j+1}，P(R＝0)＝1−L_1。若下界成立，真实分布随机占优于它。
- f_c＝argmax_f E_cons[ln(1+f(R−1))]。若保守期望 ≤1，则 f_c＝0：不下注。

### 2.3 政策族（预登记，只在其中选）

- 候选分数 f ∈ {0.5, 1, 2}×f_c，只保留 g_cons(f) > 0 的。
- 不允许的下注方式：
  - 在保守估计下长期萎缩的下注（g_cons ≤ 0）；
  - 全仓或孤注；
  - 随期限临近改变仓位。时变政策若以后要加，须作为新的预登记成员，并另行审阅。
- 硬上限：
  - 单仓 ≤ 20% V；
  - 同簇 ≤ 30% V（同一创建者、同一叙事标签、或同一小时内入场）；
  - 总敞口 ≤ 100% V，无杠杆。
- 并发：多个信号同时出现时，按卡片预先写定的优先级排队，不对每个币各算一份 Kelly 再相加。
- 选择：在账户模拟（§4）中取到达概率最高的成员；并列时取永久停止概率较低的。所有成员的结果都报告。

### 2.4 最小票面

- m_min 取“往返固定成本 ≤ 票面 2%”的最小票面。固定成本包括网络费、优先费、小费，以及开户租金（扣除可回收部分）。具体数值由执行模型实测。
- 若 f·V < m_min：当 g_cons(m_min/V) > 0 时，下 m_min；否则跳过这次机会。不允许为了凑最小票面而超额下注。

### 2.5 代定理由

1. **还没有任何策略被证明有优势，而且估计会衰减。** 例如：
   - F111 按半年看，全买回收 0.90→0.67→0.60→0.34；
   - 外部毕业标签研究，开发期 AUC 0.86，时间外验证 0.46。

   按高估的优势加大下注，是最典型的亏法。
2. **激进代替不了优势。** 在 §3.5 的条件下，没有优势时，任何合格政策的到达概率都 ≤ 2.9%。
3. **“每笔可以归零”的承受已经由分批资金承担。** 每笔 1 万可以归零，总亏损上限 3 万。这个承受落在资金分批上，不落在单注的激进程度上。
4. **“单次极端右尾”的路径仍然保留。** 按 Kelly 分数下注时，一次大倍数命中仍会让账户跳升。

参考实现 T7 给了一个数值例子。保守分布的期望回收为 1.205，但尾部很薄，所以：

- f_c 只有 0.49%，每注 g 只有 0.00044；
- 要涨到 100 倍，约需 1 万注。

也就是说，通过确认通道不等于能到达目标。这正是 §4 必须单独报告的原因。

## 3. 优势证据通道（确认用；只用于冻结之后、新数据之上）

### 3.1 C1 关闭（现行规则，保留）

R 的平均回收置信上界 < 1 → 关闭被测实现。

### 3.2 C2 截断通道（现行规则，保留，并更正它的地位）

- Z＝min(R,3) 的均值置信下界 > 1 → 支持 E[R] > 1（因为 R ≥ Z）。
- Z 不通过，不否定原策略（10-01 原文）。
- 它是“正期望的一条充分证据通道”，不只是“左尾健康”的诊断。

### 3.3 C3 右尾证书（新增）

**台阶证书**

- 设定：
  - 预先写定台阶 0＝r_0 < r_1 < … < r_J（建议 0、0.5、1、2、4、10、100）；
  - 预先写定一个固定分数 f ∈ (0,1)；
  - 令 h_f(r)＝ln(1+f(r−1))；
  - L_j 是 P(R ≥ r_j) 的同时下界。
- 结论：

  g(f) ≥ G_L(f) :＝ h_f(0) + Σ_{j=1..J} [h_f(r_j) − h_f(r_{j−1})]·L_j。

- 成立条件：
  - R ≥ 0，即 R 是含全部成本的回收倍数；
  - h_f 在 r 上单调增；
  - 各 L_j 同时有效；
  - L 先取累积最小值，保证不增。
- 判据：G_L(f) > 0 → 支持 g(f) > 0。由此也推出 E[R] > 1（见命题 P2）。

**封顶对数的经验 Bernstein 下界（独立同分布时的有限样本界）**

- 令 Y＝min(ln(1+f(R−1)), u)。u 在读结果前写定。下界 a＝ln(1−f)，下侧不截断，所以 E[Y] ≤ g(f)。
- 对 n 个独立同分布观测、同时保护 M 个固定政策：

  L＝mean(Y) − sqrt(2 s²·ln(2M/α)/n) − 7(u−a)·ln(2M/α)/(3(n−1))

  这是 Maurer–Pontil 2009 定理 4 作用于 (u−Y)/(u−a) 的结果；s² 是无偏样本方差。
- 判据：L > 0 → 支持 g(f) > 0。

### 3.4 依赖处理（两种都报，主结果用第二种）

- **(i) 独立同分布参考值**：逐币用 Clopper–Pearson 加 Bonferroni 求 L_j，再算台阶证书和经验 Bernstein 下界。只作参考。
- **(ii) 主结果：按连续日历块评估固定账户政策。**
  - 用移动块自助求 L_j 与 g 的单侧下界。
  - 块长在读结果前按“持有期 + 开发期估计的相关长度”写定，并报告块长敏感性。
  - 若某一窗口只有一两个超级币支撑结果，写“频率尚未确认”，不能靠自助法复制它们来制造可靠性。

### 3.5 无优势基准（只作参照，不作门槛）

- 条件：
  - 全成本下的累计净盈亏是超鞅；
  - 最大亏损确实不超过 3 万；
  - 不存在跳空越过亏损线、也没有未计负债。
- 结论：在这些条件下，任何合格政策到达“+100 万”的概率 ≤ 3/(100+3)＝2.9126%。
- 用途：只作参照。“明显高于 2.9%”是偏好，不是正期望的必要条件。

### 3.6 显著性预算

- 确认账里写清冻结政策的个数 M。各通道之间用 Holm 校正，经验 Bernstein 用 ln(2M/α)。
- 在同一份留出数据上挑最好的那个，必须保护整个家族。
- 每次看过数据之后再改版，需要新的时间批次。

## 4. 账户模拟（到达能力；报告用，不作门）

**输入**

- 冻结政策的单注回收分布 R(q)：随仓位 q 变化，不是用零规模的 R 乘以 min(q, 容量)；
- 信号到达日历：开发期的真实日程，按块重抽；
- 持有期与并发；
- 簇的相关性；
- 成交失败与延迟；
- 成本漂移；
- §1 的分批资金状态机；
- §2 的政策族。

**每个政策的输出**

- 到达概率、暂停概率、永久停止概率；
- 36 个月时 N 的分布；
- 到达时间的分布。

**设定**

- 恢复情景报两种：90 天后立即恢复（乐观）、永不恢复（保守）。
- 分布用保守版和点估计版各跑一次。以保守版为准。

## 5. 开发期配对消融与负对照（诊断，不授予通过）

**选币 × 择时 2×2**

- 四格：基准选择或新选择 × 基准时间政策或新时间政策，记为 G00、G01、G10、G11。四格都在同一组可见事件上、沿真实路径估值。
- 报告：两个增量，以及交互项 G11−G10−G01+G00。
- 分母：等待期间死掉、再也没有触发、资金闲置的币，都留在原分母里。
- 比较退出时，先固定入场。

**负对照**

- 在同日、同币龄、同市场状态、同可见流动性风险的集合中，随机选相同数量的真实决策事件，再执行同一政策。
- 不使用时间顺序打乱的路径，因为 AMM 上那样的路径不可能成交。

## 8. 标签规则

**尾部类型**

- 固定入场价、仓位 q、期限 H，以及可清算回收路径 V(t;q)。令 M_H＝max V。
- 在 M_H ≥ K 的币中，按期末 V(H;q) 分类：
  - ≥ K/2：期末保有型；
  - < 1：期末回落型；
  - 介于二者之间的单列；
  - 期限未满或数据不足的单列。

**使用限制**

- 不得按真实类型分配退出规则，那只能报告为“不可实现上界”。
- 训练只用已成熟的标签；结果窗口重叠的样本做 purge/embargo。
- 创建者履历只累计决策时已经发生、且结果已经可知的事件。
