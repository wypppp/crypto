   **三种价值分开**


   | 价值            | 用于                         | 怎么算               |
   | ----------------- | ------------------------------ | ---------------------- |
   | 可执行清算价值  | 判定成功、盈利追加           | 只计已经能卖的部分   |
   | 风险估值 V_loss | 判定“亏完”、暂停线、停止线 | 见下面的锁定资产三类 |
   | 可用现金        | 开仓                         | 现金                 |

   | 类                             | 怎么计                                          |
   | -------------------------------- | ------------------------------------------------- |
   | 项目未上市                     | 按成本计；从认购截止日起算 180 天仍未上市，记 0 |

   - 起算日不随项目延期而重置。项目宣布取消或失败时，记 0。

   **合格市价**

   - 过去 24 小时成交额 ≥ 我方该资产估值的 10 倍；否则视为没有市价。
   - 目的：防止一笔极小报价就让估值跳变。
   - 30% 折扣是政策选择，不是真实价值的下界。

   **退款**

   - 到账前，不计入成功价值；在风险估值里按退款额计。
   - 到账是资产转换，不是新的入金。
   - 减记后恢复交易时，不重复计资产。

   **状态规则**

   - **资金耗尽暂停**：V_loss < m_min，且没有下一笔可投时，暂停，保留真实的现金与 N。开仓票面不作为“资产清零”的标准。
   - **暂停期间**：清掉可交易仓位，禁止开仓；锁定资产继续跟踪；停止线仍然有效。
   - **永久停止后**：继续记账，不自动恢复。
   - **resume()**：在状态机内校验三项（暂停 ≥90 天、确认凭证、36 个月期限），并记录暂停起点。
4. **最小票面**：

## 四、战略调整：右尾候选走“规则窗口”轨道（总控决定，依据用户 10-02 裁决③）

### 问题

GPT B.4 的计算说明，用不依赖分布假设的有限样本界，在 23 个检验周上确认几个百分点的尾部频率几乎不可能：

- 周均值经验 Bernstein：哪怕方差为零，也要扣约 58 个百分点；
- 鞅 Hoeffding：约扣 32 个百分点。

如果只认这种“确认级”证据，任何右尾策略都过不了关，研究会再次陷入“永远没有结论”。

### 做法

右尾候选沿用用户 10-02 已经裁定的**规则窗口**轨道。

**开窗条件（三条都要）**

1. 冻结的交易规则扣全成本后，对两条基线的配对超额，单侧 80% 下界 > 0。
   - 两条基线：同风险集的负对照，以及全买。
2. 同一冻结政策在固定 f 下，每注对数增长的单侧 80% 下界 > 0，即绝对盈利。
3. 点估计超过事先写定的经济门槛。门槛写进卡片。

**推断方法（卡片预登记）**

- **主结果**：以事件为单位，按周聚类求稳健区间，明示两个假设：周与周之间独立、渐近近似成立。
- **敏感性**：GPT 给的有限样本界（周均值 Bernstein、鞅 Hoeffding）作为最坏情况一并报告，但不作门槛。

**窗口与资金**

- 第一个窗口 ≤3,000 元。重复评分的处理事先登记。动用真钱要过门 2。
- 开窗会启动三年时钟（用户 10-02 裁决②），开窗时机仍由用户裁决。

**“确认级”通道的地位**

- C2、C3 及其可证明的界保持不变，作为更高一级的证据。
- 不要求右尾候选在开窗前先达到确认级。

### 理由

- 用户的资金规则本来就是为“在有限亏损下做实盘检验”设计的：每笔 1 万可以归零，总亏损上限 3 万。
- 统计上证明不了，不等于不能做；而是应当用小额、有上限的实盘去获取证据。
- 冻结、配对基线、80% 下界和经济门槛，仍然挡住了“看结果后改规则”和“没有优势”这两类错误。

**2．DQ-18不只是“小时粒度较粗”。**

**1．P4成立，P6还有一处关键缺口。**

令 \(p_j=P(R\ge r_j)\)，在同时覆盖事件上定义

\[
\widetilde L_j=\max_{k\ge j}L_k.
\]

由于 \(p_j\ge p_k\ge L_k\)，故 \(\widetilde L_j\le p_j\)，且它不增。取

\[
P(R_c=0)=1-\widetilde L_1,\qquad
P(R_c=r_j)=\widetilde L_j-\widetilde L_{j+1}.
\]

概率非负、和为1；逐台阶区间比较尾概率可得 \(R\)随机占优于\(R_c\)。求和消去中间项，恰得

\[
E[h_f(R_c)]
=h_f(0)+\sum_j\bigl[h_f(r_j)-h_f(r_{j-1})\bigr]\widetilde L_j.
\]

所以它对同一个 \(R\) 的全部 \(0\le f<1\)同时成立。原来的累积最小也保守，只是更松。

但若在确认数据上先求 \(f_c\)，再生成 \(\{0.5,1,2\}f_c\)，这**不是三个事前固定的Bernstein候选**；直接设 \(M=3\)不够。应把数值网格在开发期冻结，或采用真正覆盖整个函数族的统一界。[learningtheory.org](https://www.learningtheory.org/colt2009/papers/012.pdf?utm_source=chatgpt.com)

**2．P12不能解释为“没有过度下注”。**

取保守分布本身为：20%概率回收6，80%回收0。其Kelly最优 \(f_c=0.04\)，但允许的 \(2f_c=0.08\)仍满足

\[
g(0.08)
=0.2\log(1.4)+0.8\log(0.92)
=0.2\log(1.002950144)>0.
\]

它已经超过增长最优仓位，仍通过正增长筛选。最小票面上调也有同样问题。保留该政策选择可以，但必须准确表述其保证。

**3．P10的具体反例与改法。**

- **尘埃卡死：**\(m_{\min}=100\)，首笔剩现金50后补第二笔；第二笔又亏至50，此时 \(D=20000,N=-19950\)。不能下注，却没有触发暂停。增设“资金耗尽暂停”，保留真实现金和真实N；开仓票面不是资产清算为零的标准。费用突然上涨也不能自动制造“亏完”。
- **锁定减记误触：**正常12个月归属的认购，在TGE后180天仍不能卖，被R2清零。应区分“项目未上市”“我方约定锁定”“逾期未解锁”；无TGE日期的项目从认购截止日起计，原日期不得随项目延期重置。
- **风险估值不一定保守：**无报价按成本、出现极小报价立即打七折，会在没有对应经济损失时造成跳变；反之，长期无报价能掩盖损失。30%只是政策折扣，不能称为真实价值下界。
- **暂停仍会变动：**累计入金3万、剩1万锁定资产时暂停；随后失败减记到0，应触发停止。若采用“PAUSED不更新V”的修正，会漏掉它。暂停只能清掉可交易仓位，锁定资产仍须跟踪。
- **退款与复活：**未到账、不可转让的退款请求不能按面额计入“可执行成功价值”。退款到账是资产转换，不是新入金；减记后恢复交易也不能重复计资产。永久停止后继续记账，但不自动恢复交易。
- **时间绕过：**参考实现`resume()`未自行验证90天、确认凭证或36个月期限；暂停后立即恢复、期满后恢复均可被调用。需状态机内检查并记录暂停起点。

盈利追加触发也要明确采用哪种价值；建议用可执行净清算价值，不能靠锁定资产的账面报价触发。

**4．依赖稳健方法有，但23周的代价很大。**

可令 \(X_{wj}\in[0,1]\)为预先定义的周内尾命中占比，固定空周处理。若**周块独立**，周内允许任意相关；对每个台阶的周均值应用Bernstein，并用 \(\alpha/J\)作同时保护。独立但不同分布也可界定这些周的平均期望。注意，它首先是**周等权对象**，不是逐币加权命中率。[learningtheory.org](https://www.learningtheory.org/colt2009/papers/012.pdf?utm_source=chatgpt.com)

取 \(n=23,J=6,\alpha=0.05\)，仅Bernstein线性惩罚就为

\[
\frac{7\log(240)}{3(22)}\approx0.581.
\]

即使样本方差为零，也要扣58.1个百分点；所以该方法难以确认几个百分点的稀有尾频率。把持仓跨周的数据简单分成周，不能使周独立。

不假设独立时，固定 \(n\)可用鞅Hoeffding界：

\[
\bar\mu_j\ge
\max\!\left(0,\bar X_j-\sqrt{\frac{\log(J/\alpha)}{2n}}\right),
\quad
\bar\mu_j=\frac1n\sum_w E[X_{wj}\mid\mathcal F_{w-1}].
\]

由条件Hoeffding引理及并集界可证；上述配置惩罚约32.3个百分点。它界定的是**历史平均条件概率**，不能自动解释成未来稳定尾概率。跨周标签须明确成熟时钟与信息集；需反复查看时，可用Howard等人的鞅经验Bernstein置信序列。[arxiv.org](https://arxiv.org/html/1810.08240v9?utm_source=chatgpt.com)

若改用账户周对数收益，还须先证明有限下界：总敞口100%时可能整周归零，不能由“单仓20%”推出周收益有界。没有依赖限制时，23周可能只是同一次共同冲击，不能靠统计方法凭空增加独立信息。

**§12四问的建议：**

1. **数学问题：**先选推断对象，再选有条件保证的方法；移动块自助保留为敏感性分析。
2. **政策选择：**90天作为最短暂停期；恢复还要等标签成熟和足够信息量。不能因功效不足放宽通过线；反复检验需控制显著性预算。
3. **政策选择：**20%/30%可暂作上限，但无最优性保证；锁定资产计入敞口，并明确多重簇及比例被动超限的处理。
4. **政策解释：**累计入金3万且真实价值归零，停止符合原亏损线；入金上限3万、阶段B不再暂停等实例化仍须明确追加，不能假称由数学推出。

**B总判定：改后可用。**

**不改不能执行的条款：**

- **A：**修复逐批观测窗口隔离；禁止用DQ-18压缩路径运行不受支持的延迟退出；压缩数据通过精度及事件唯一性核验后才能重取；分诊和需求曲线不得承担扩大关闭范围的作用。
- **B：**修复数据自适应 \(f\) 的确认方式；补齐锁定、退款、耗尽、暂停和终止状态；明确依赖下的推断对象与保证。完成前，契约及参考实现不能用于正式通过、关闭或恢复判定。
