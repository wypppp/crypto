**我自己要收回的：**上一轮我说"同 slot 里最赚钱的那部分，很大一块是部署者自己的钱包"，F130 不支持这个说法：


| 同槽买家类别           | 全成本回收    |
| ------------------------ | --------------- |
| 与创建者有直接资金往来 | 0.942         |
| 与创建在同一笔交易里   | 0.228         |
| 独立                   | 1.198（上界） |

GPT 说"同槽不能直接认定为内部人"，是对的。速度路线的结论不变，但理由要换：

- 利润集中在头部，前 10 个钱包拿走正净额的 71%；
- 中位钱包回收 0.987，这还没扣服务器和节点等固定成本；
- 名单里 56% 的钱包两个月后已经不再交易，留下来的回收数字带有幸存者偏差。

**需要补充或修正的三处：**

1. **"时间换期权"只对一部分参与成立。**参与至少有四类：


   | 类型         | 例子                    | 占不占亏损预算             |
   | -------------- | ------------------------- | ---------------------------- |
   | 时间型       | 测试网、早期使用产品    | 基本不占                   |
   | 资金加权型   | 按锁仓金额 × 时间计分  | 占：资金被锁，还有合约风险 |
   | 交易量积分型 | 币安 Alpha 积分         | 占：要付滑点和手续费       |
   | 持币型       | HODLer 空投、Launchpool | 占：承担币价风险           |

   后三类都要花钱、承担风险。基础比率研究要按这四类分开算。
2. **要先定账。**按背景.md 的口径（纳入计划的账户净值＋累计提款−累计入金），参与得到的收入算进 100 万。所以要现在就定：参与用的账户纳入计划账本，费用和收入都入账。否则 3 万的亏损上限就管不住这部分。
3. **窗口轨道的上限，Claude Code 建议"合计不超过第一笔 1 万"，我认为太宽。**我的建议是：

   - 第一个窗口不超过 3,000 元；
   - 窗口要从"速度窗口"改成"规则窗口"：靠比别人早弄懂新机制、新规则吃到的机会，而不是靠快。GPT 说得对，新场所第一天就可能挤满了现成的机器人。

**关于 E：支持使用，再加两个条件。**

- **一次性样本要一次问完。**主假说只设一个，就是冻结的规则；首日成交额分组这类次要问题，同时登记，但只作描述，不参与决定。
- **事先写明两种结果分别导致什么。**例如：通过，则这个成分可以按证据阶梯申请动用资金；不通过，因为检验力只有一半左右，不算关闭，前向窗口照常运行。

## 二、对 GPT 的判断

**速度这部分：**

## 四、B：选哪个生态

我的首选是**币安 / BNB 链的中文生态**，理由有四个：

1. B1 的数据已经存好了，80.5 万个中文名币，不需要 Dune。

3. 它和做空窄类在同一条上币管线上：先上 Alpha，再上永续，再上现货。
4. 中文环境。

**也要说清楚另一面：**Alpha 积分是公开的竞争，不是我们的优势。

- 到 2025 年中，单个账号的月净收益已经从上千美元降到约 600 美元；

- 它的价值是低风险的现金流，加上一个能看清上币管线的位置，不是右尾；
- 只能用一个实名账户，多开违反规则。

**右尾从哪里来：**如果判断日志显示，你对"哪些中文叙事、哪些 Alpha 币会走得更远"的判断明显好于基础比率，再用窗口轨道小额下注。

### C2. 执行模型自己的发现

1. **判断日志的设计决定它能不能测出东西。** 不必新造：DQ-6 §五（09-17）已有一套前向盲评设计，直接复用其中四条：
   - **固定题库**：题目由规则产生（例如每个新上 Alpha 的币、每个毕业的中文名 four.meme 币），每题都要给出判断；过期未答记“未答”、留在分母里。否则只答有把握的题，命中率自然好看。
   - **参考价取提交之后**：收益从判断提交后的第一笔成交价算起，不是从上币或触发时刻；人比程序慢，这个成本要算进去。
   - **三方比较**：你的判断要同时好于全体（基础比率）和一条冻结的机器基线。只好于全体，说明机器也能做，应当自动化，而不是靠你。
   - **评分规则事先写死**：概率题用 Brier 分对基础比率，挑选题用所选币对全体的超额收益，按周整块自助法。自由发挥的预测单列，只作描述。
2. **时间戳与检验力**：
