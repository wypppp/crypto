# 未解决问题地图

> 按问题组织，不按方向组织。一个问题可以挂多行总账，一行总账也可以回答多个问题。
> 每个问题只给“现在知道到哪一步”和“什么证据能改变状态”，不给交易策略，也不排投入顺序。

## 0. 怎么读

| 状态 | 含义 | 与“否定”的距离 |
|---|---|---|
| 没有测过 | 没有针对它的取数或检验 | 无任何信息 |
| 测不到 | 试过，数据不存在、不可回放或不可得 | 当前手段下无法回答；换数据源或改为前向记录才可能回答 |
| 测量无效 | 做过，但测的不是它声称的东西，或数据有已知缺陷待重算 | 不能当正负证据 |
| 局部负 | 某个具体实现上为负；“强”有区间上沿与冻结判据或复现，“弱”没有 | 只否定该实现 |
| 局部·未决 | 做过检验，区间跨保本或跨对照 | 不能当正负证据 |
| 局部正·待确认 | 开发数据或代理上为正 | 不是确认；须冻结前向 |
| 描述 | 有数据、无经济判据 | 给出基础比率，不给结论 |

问题分五组：QA 价值流（L1，与我们是谁无关）；QB 可得性（L2，取决于我方约束）；QC 选择与信息；QD 测量本身；QE 财富路径。

**测量层（QD）的问题最先影响其他问题。** QD1 的残差决定内部数字是否可信，QD4 决定旧结论能否沿用。它们不回答“能否赚钱”，但决定其他所有回答的可信度。

**收款位置的问题几乎全部没有测过。** QA3、QA4、QA9 对应项目最少覆盖的价值流（V1、V2）。这是覆盖缺口，不是负结果。

**QB1 不是研究问题，是前提。** 它由用户裁决，不由数据回答。它不定，L2 的每一格都只能写“条件未知”。
