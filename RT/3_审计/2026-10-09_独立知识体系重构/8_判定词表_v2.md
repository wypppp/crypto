# 判定词表 v2（用户 10-12 批准）

> 用途：交叉索引“认识状态”“问题类型”“价值流”三列的判定规则，以及新增的“描述性产出”列。
> 起因：10-11 GPT 盲审 20 行，“问题类型”只有 10/20 一致（[7_争议账](7_争议账_2026-10-11.md) §1）。v1 见 [2_交叉索引说明](2_交叉索引说明.md) §2。
> 本文件的例子只取已揭盲的 20 行，以免泄露其余行的判定。

## 1. 判定对象

**先写命题，再判状态。** 每行先写出它的经济命题：谁、在什么条件下、能否取得净现金。认识状态只回答“对这个命题知道到哪一步”。

**没有经济命题的行记“非方向”。** 设施、方法、取数手段属于这一类。

**新增一列“描述性产出”（有／无）。** 它记该行是否留下可复用的描述或测量，例如基础比率、覆盖率、规则原文、数据质量发现。它与认识状态无关：命题未测的行，也可以有描述性产出。

| 例 | 命题 | 认识状态 | 描述性产出 |
|---|---|---|---|
| K001 DQ-34 | 周末休市定价能取得净现金 | 未测 | 有（规则、成交额、数据留存） |
| K127 RT-A | 无经济命题 | 非方向 | 有（历史联合覆盖 82.25%） |
| K056 胜者公开事前记录 | 能从胜者公开记录学到可执行方法 | 测不到 | 有（209 条编码，严格事前 4 条） |

## 2. 认识状态（11 个词）

| 词 | 判定规则 |
|---|---|
| 未测 | 没有针对该命题的取数或检验 |
| 测不到 | 试过取数，数据不存在、不可回放或不可得 |
| 测量无效 | 检验测不了该命题：代理不适用、用已撤销的门槛判死、用事后信息检验事前命题 |
| 局部负·强 | 见下方“负”的定义；区间上沿低于基准，并有冻结判据、两段样本复现或同源复算之一 |
| 局部负·弱 | 点估计低于基准，但缺上面三者之一，或只有点估计 |
| 局部·未决（新增） | 做过检验，区间跨基准；点估计的正负不作结论 |
| 局部正·待确认 | 点估计与区间都在基准之上，或只有开发数据上的正点估计；未经冻结前向 |
| 描述 | 命题本身是描述性的（如“谁在赚钱”“基础比率是多少”），且已有数据 |
| 停止·非证据 | 因偏好、资源或范围停下，没有证据 |
| 非方向 | 没有经济命题 |
| 排除 | 执行上排除（违法），研究对象保留 |

**“负”与“正”必须写明基准。** 绝对基准是全成本回收等于 1，或净收益等于 0。相对基准是预先写定的对照规则。例：K015 DQ-7 的 11 条新退出都不胜对照 `b50`，记“局部负·弱（相对）”，不表示绝对亏损。

**已知数据缺陷不改认识状态。** F132 一类待重算项，仍按现有结果判状态，并写进“待修标记”。只有当缺陷足以翻转结论、且方向未知时，才改记“测量无效”。

## 3. 问题类型（多值）

| 词 | 判定规则 |
|---|---|
| 错误关闭 | 以已撤销的门槛、过短观察窗、单次快照或缺冻结负分支的开发结果，记为关闭；相对对照无增益、且按冻结规则停下的开发分支不算 |
| 错误归因 | 原件把结论归因于没有被检验的原因；例：用无条件命中率断言“与入场无关”（K072 引用的死亡档案） |
| 遗漏 | 应单列的对象被压进一行，或未入账 |
| 状态误标（新增） | 总账状态词与原件不符；例：“只描述”实为未测（K155） |
| 证据栏误标 | 总账“证据”一栏与原件不符；例：写“确认 T2”而评分从未运行（K007） |
| 重复 | 同一对象被当成两个方向计数；父子关系只填母项，不记重复（K004 记“无”） |
| 标签混用 | 设施、方法、取数手段计为方向（K010、K011、K059、K123、K126 同判）；子母体单独计入“活跃”；一行混装性质不同的对象 |
| 无 | 以上都不成立 |

**多值用“；”分隔，按上表顺序排列。** 第一个为首要问题。例：K121 记“错误关闭；重复”，K136 记“错误归因；标签混用”。

## 4. 价值流

**允许多值。** 多腿组合（如买入折价资产、延迟赎回、永续对冲）加标“多腿”，按联合现金流判定。赎回权与收敛记 V9，不记 V7。

## 5. 一致性

**同类行同判。** 每个判定写出所依据的原件行号。判定者发现同类行判法不一时，先统一规则，再改行。

## 6. v2.1 澄清（用户 10-12 批准）

> 起因：全量双盲后，GPT 列出六处词表不好用的地方，问题类型一致率只有 58%（[9_双盲比对](9_双盲比对_2026-10-12.md)）。下面 13 条只澄清，不新增词。

### 认识状态

| 编号 | 澄清 | 对应 GPT 指出的问题 |
|---|---|---|
| S1 | 经济命题必须写到净现金：谁、在什么条件下、能否取得净现金。检索筛查、分类、方法与设施，没有单一经济命题的，记“非方向” | 钱包盈利测量既像描述又像经济命题 |
| S2 | 一行混装已测与未测对象时，按已测部分中证据最强者判认识状态，未测部分写进备注，问题类型记“遗漏”（应拆行） | 混装行无法用单一状态覆盖 |
| S3 | 总账记有停止或暂停投入的决定、且命题从未检验，记“停止·非证据”；没有这类决定，记“未测” | “未测”与“停止·非证据”缺优先规则 |
| S4 | 区间以原件报告为准，注明置信水平；原件只给均值、标准差与样本量时，按 95% 正态近似推算并注明“推算”；只有单侧界、无法推算的，按“只有点估计”处理 | “局部负·强”未规定置信水平 |
| S5 | 已知缺陷能否翻转结论，以原件或修复记录的说明为准。记录明确说可能翻转的，记“测量无效”；没有说明的，保留现有结果并写待修标记 | — |
| S6 | “基准”只在局部负、局部·未决、局部正、测量无效四类状态下填，其余填“不适用” | — |

### 问题类型

| 编号 | 澄清 | 对应 GPT 指出的问题 |
|---|---|---|
| P1 | 只记当前仍成立的问题：当前总账行，或它引用的事实库条目。总账该行已注明更正的历史错误，移到“历史问题”列 | 已撤回的历史错误是否仍标记 |
| P2 | “状态误标”只在总账状态词违反总账自己的 8 词定义、且有更合适的词时记。总账词表里没有对应词的（如测不到），不算误标 | — |
| P3 | “错误关闭”只用于总账当前记为实现关闭、而依据不足的行：已撤销门槛、过短观察窗、单次快照、缺冻结负分支、检验测不了该命题 | — |
| P4 | 一行压了多个对象，记“遗漏”；“标签混用”只用于设施、方法、取数手段计为方向，子母体单独计入活跃，总括行与子行并列计数 | — |
| P5 | 成对重复只标次要一行（较旧或已并入的那行），主行不标 | — |
| P6 | 多值按 §3 的固定顺序排列；这个顺序就是严重度顺序，第一个即最严重，不另设“首要” | 固定排序与“首要”冲突 |
