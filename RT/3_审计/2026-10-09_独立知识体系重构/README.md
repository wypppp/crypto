## 0. 先说任务定义的问题

**163 个方向不是可比的单位。** 它们混了假说 79、实现检验 32、描述测量 22、基础设施 16、检索筛查 10、方法治理 4。按行计数会高估“已探索的面”。本次把 163 行降为交叉索引，主干改为三张表：位置、检验、主张。

**百万目标是评价函数，不是研究对象。** 把它放进对象定义，会让研究按“能否三年内贡献百万”筛选，抬高小样本正结果的权重。

## 1. 一屏结论

**最扎实的产出是数据与测量层的知识。** 虚拟报价储备缺失（F132）、SOLMEMES 数据错位（F133）、Dune 不收录失败交易（F60、F102）、尘埃成交造成伪穿越（F110）、币安首发开盘时间不可执行（F11）。它们可公开复核，不依赖盈利目标。

**经济结论多是弱负或未决。** 强负只有 3 条：C1（+30 分钟公开状态选币）、F118（创建者发币履历）、R1a v3（早买者资金关系）。另有弱负 11、未决 8、测量无效 12。总账记“实现关闭”的 18 行里，只有这 3 行站得住。负结果边界都很窄，不能推广成“该场所没有机会”。

**局部正结果 5 行，没有一条经过冻结前向确认。** 它们集中在事件的对手方与速度位置：上所后做空、韩国所上币、黑客告警后做空、在场狙击者。这与价值流视角一致，但只是推断。

**测量本身仍不可靠。** 163 行中 148 行没有任何独立核验；事实库 140 条中 61 条带更正、待复核或补注。最大风险不是“没找到优势”，而是“测量是否可信”还没有关闭。

**覆盖偏向可测的地方。** 曲线早期（S1）48 行、21 行有数据；成熟二级与衍生品（S3）26 行只有 3 行。发行方、平台收费、一般做市、付款方画像不在任何行。

**法律与身份前提未定。** 身份与所在地未定（用户 10-02），资格核查只覆盖平台条款，而 DQ-41 选中的 O1b 依赖币安账户。这是前提，不是研究问题。

**10-11 交叉审阅后的更正。** GPT 反方 41 条，我接受 38 条、部分接受 3 条，见 [7_争议账](7_争议账_2026-10-11.md)。三处推论已收窄：公开信息“已被定价”、会计守恒的适用范围、积分位置的“资金不足”。“问题类型”列盲审一致率只有 10/20，词表 v2 批准前不要依赖它。

**10-12 全量双盲后。** 认识状态一致 83%（κ 0.79），问题类型 58%（κ 0.41）。合并后强负只剩 3 条，见 [9_双盲比对](9_双盲比对_2026-10-12.md)。v2.1 已于 10-12 批准，索引与各文件的计数已按合并结果更新。

## 4. 独立性与限度

- 审阅者与项目执行模型、部分审阅者同属大模型，可能同一家族。10-02 的“靠位置不靠预测”也出自 Claude。这不是独立的人类复核。
- 读过项目自己的导航、总账与审计意见。分类与结论在读完原件后形成，但不能排除受这些框架影响。
- 没有运行项目代码或 SQL，没有重算任何数字。“独立核验”一栏只记录仓库里已有的核验。
- 外部核查只用公开网页，日期 2026-10-08～09。法律部分不是法律意见；标“未核实”的不能当结论用。
