## 0. 结论先行

**账户收益按位置、周期两级加总。** 累计净投资收益等于各位置净现金之和加账户层公共现金流；位置净现金等于各周期净现金之和加位置层固定现金流。给定完整的现金与估值序列，收益就确定了（§2）。次数、投入、依赖与时间变化是对这个序列的描述与估计，不是恒等式本身。

**选币、场所、择时是旋钮，不是第一层。** 它们各自同时作用于好几个节点（§7）。

**评估是一串闸门，对象是完整位置。** 决定能否走赚钱分支（甲乙）的是：在我们进得去的位置上，按明确期限和规模，含位置层固定成本的全成本净现金经前向确认为正（§5）。机制解释只用于排序，不判负；“未确认”不等于丙成立。

**它不是新框架。** 它是[盈利路径导航 v1.1](../../4_决策史/2026-10-06_盈利路径导航_v1.1.md) §2 机会合同与 §4 三条主支的恒等式写法。新增的只有闸门顺序、确认途径与参与者维度（§8）。

## 2. 树

```
累计净投资收益（我们，评估时点 t）
  ＝ Σ 位置净现金 ＋ ⑦ 账户层公共现金流

位置净现金（我们的每个位置；其他参与者同样适用）
  ＝ Σ 周期净现金 ＋ ⑥ 位置层固定现金流
│
├─ 0 可进入性：已具备／可形成未验证／不可得／未核实
│
├─ ① 周期净现金（一份完整合同的一个周期，以现金额计）
│   ├─ 1A 基准：同一母体按参考规则全部参与的平均参考毛现金
│   ├─ 1B 选择增量：选中子集的参考毛现金减去基准
│   ├─ 1C 进场执行差额（有符号）
│   ├─ 1D 退出执行差额（有符号）
│   ├─ 1E 直接净费用（有符号：返佣、收到的资金费记为负费用）
│   ├─ 1F 非市场损失：平台、合约、对手方事件
│   └─ 1X 解释栏：付款方；胜出理由（可多选）
│
├─ ② 周期数（估计式）：母体事件率 × 逐层条件的发现率、合格率、可执行率；
│        受期限、并发与占款约束
├─ ③ 每周期投入（约束集）：现金、保证金、配额、场所限额；容量为可部署金额范围
├─ ④ 联合依赖：投入、收益、到达、占款与账户状态之间的关系
├─ ⑤ 时间变化：竞争进入、规则与费率变化、从验证到部署的时滞
├─ ⑥ 位置层固定现金流：为该位置新增、可避免的资格、专用数据与设施成本
└─ ⑦ 账户层公共现金流：税、出入金与汇率、闲置资金的收益与风险、
         共享设施、操作失误
```

**完备性。** 累计净投资收益只由三类现金构成：各周期净现金（含未完成周期的净清算贡献）、各位置的固定现金流、账户层公共现金流。外部入金与提款在定义里已经抵消，只通过账户规模影响③。所以第一层没有遗漏的现金项。②③④⑤ 是对周期序列的描述与估计：它们帮助预测和解释，但几个摘要量不能完整代替序列本身（例如大投入恰好配给亏损的周期，结果完全不同）。

**①的分解按固定次序逐步替换，每笔现金只记一次。**

1. 参考毛现金（1A＋1B）：按参考规则计算的毛现金，包括价格盈亏以及适用的合同分配、费用收入、利息、奖励与结算收入。
2. 换成实际进场，差额记 1C。
3. 换成实际退出，差额记 1D。
4. 扣直接净费用，记 1E。
5. 扣非市场损失，记 1F。

一笔现金或估值损失只分配一个金额归属，可以挂多个原因标签。失败交易的 gas 归 1E；平台、合约、对手方事件造成的损失归 1F；市场流动性造成的卖不出归 1D；已计入参考毛现金的收入，不在 1E 再记一次。

**单位。** 六项先以同一币种的现金额相加。有明确资金分母（本金、保证金、净占款）时，再统一除以同一个分母报告收益率。没有合理分母的位置（如零本金的奖励、赏金）只报现金额，收益率记“不适用”。

## 3. 节点定义

| 节点 | 定义 | 测量要点 |
|---|---|---|
| 位置 | 一份机会合同在我方约束下的完整执行 | 保留导航的合同编号与范围；一行索引含多份合同时，在原索引号下分子记录 |
| 周期 | 一份完整合同从承诺到兑现的一轮 | 多腿、对冲、持续做市、积分取得到兑现，按整份合同记账，各腿只作诊断；跨周期的库存与资格余额连续结转 |
| 参考规则 | 冻结的参考成交或结算规则：方向、数量、时点、缺失处理 | 按事件时间；中间价只对适用的交易腿作诊断参照；配售、积分、期权等按其合同结算规则 |
| 母体 | 生成机会的规则 | 登记事前资格、决策单位、未获配、弃权与失败的现金处理和加权方式；事后死亡的机会留在事前合格母体里；退款不计收益，相关费用与占款保留 |
| 1A 基准 | 同一母体按参考规则全部参与的平均参考毛现金 | 1A 与 1B 在同一母体、同一参考规则、同一单位与权重下比较 |
| 1B 选择增量 | 选中子集的参考毛现金减去 1A | 同上 |
| 1C、1D | 实际成交相对参考规则的差额 | 有符号：做市、挂单可能为正；失败与未成交计入 |
| 1E | 直接净费用 | 有符号；按持有时间累积，不按“每事件”一次扣 |
| 1F | 非市场损失 | 发生率低、损失大，单独记 |
| ② 周期数 | 期限内能完成的周期数 | 各率按同一母体逐层条件化；窗口末未成熟与资金被占用都会减少实际次数 |
| ③ 每周期投入 | 可部署金额 | 以确定约束（现金、保证金、配额、限额）表示；容量指定合同和成本下的可部署范围，不强求一个边际零点；杠杆含强平与负权益 |
| ④ 联合依赖 | 投入、收益、到达、占款与账户状态的联合关系 | 含同簇尾部同时发生、收益先后顺序、暂停线触发后错过机会；有效独立次数只是针对某个统计量的诊断 |
| ⑤ 时间变化 | ①～③ 随时间的变化 | 公开后衰减、平台参数调整、从验证到部署的时滞 |
| ⑥ 位置层固定现金流 | 为该位置新增、可避免的成本 | 沉没成本、共享成本与新增可避免成本分开记，不机械摊销；形成类保留普通路径对照与“首次付费 → 资格形成 → 兑现 → 失效”时间线 |
| ⑦ 账户层公共现金流 | 跨位置的公共项 | 汇率指美元计价资产换算成人民币；闲置资金含稳定币收益与脱锚风险；个人工时不计入，在研究决定里另记 |

## 4. 解释栏（1X）

两栏不是加项。它们解释参考毛现金由谁支付，以及为什么能留在这个位置上。

**付款方。** 分别写直接付款主体与资金的最终来源（例：受托刷量服务的直接付款方是项目方，最终来源可能是后来的买家）。填 §6 的角色编号。转移机制沿用价值流词表：V1 费用与服务收入；V2 分配租金；V3 排序与速度租金；V4 信息与选择；V5 风险溢价、承保与做市；V6 行为漂移；V7 强制交易对手；V8 操纵与欺诈转移；V9 机制与规则错价。

**胜出理由：同样盯着这笔钱的竞争者为什么拿不走。** 可多选，允许“不明”。每项附可观测依据与失效条件。

| 标签 | 含义 |
|---|---|
| 信息 | 别人看不到、看得晚，或处理成本高 |
| 速度 | 看到同一信号，我们更快 |
| 资格与权利 | 账户、配额、白名单、法域、合同、客户与订单流权限。分已具备、可形成、不可得；可形成的代价记入⑥ |
| 承担 | 别人不愿或不能承担的风险、持有期或波动 |
| 成本与运营 | 处理、执行或运营的单位成本更低 |
| 规模过小 | 大资金不做；须同时说明其他小资金为何拿不走，不能单独作胜出证据 |
| 尚无竞争 | 机制太新；须写预期寿命；“未观察到竞争”不能单独作胜出证据 |

**说不出胜出理由，是一条有适用范围的先验，不是测量。** 竞争可能压低 1B，也可能体现为 1C、②、③ 或⑤ 的变化，按实际受影响的节点挂靠。

## 5. 评估顺序（闸门）

| 闸门 | 问什么 | 结果 |
|---|---|---|
| 0 可进入 | 技术、信息、经济上能否进入；资格与法律待评估 | 已具备、可形成未验证、不可得、未核实。只有有据的“不可得”才使该位置成为丙的材料；未核实者的甲乙判定保持条件性 |
| 1a 机制 | 付款方与胜出理由 | 只用于解释和排序，没有通过与不通过，不触发剪枝。新的可靠净现金证据可以恢复优先级 |
| 1b 确认途径 | 这个位置靠哪张冻结卡确认、最早何时能评分 | 分两类记。确定的：按原卡截止前禁止评分、观察期不成熟、没有合格事件。情景的：预期功效偏低，只用于排序。输入不明记“不明” |
| 1c 开发证据 | 完整位置在明确期限与规模下的全成本净现金区间，含⑥，并考虑④对推断的影响 | 按判定词表 v2.1 记认识状态；局部负只关这一实现，不关位置 |
| 1d 前向确认 | 冻结契约下的前向结果 | 确认为正 → 甲或乙；研究截止日之后才确认的同样回到赚钱分支（用户 10-12） |
| 2 规模 | 甲还是乙 | 有效硬上界低于参照线 → 乙；确认的规模证据支持达到参照线 → 甲；其余记“甲乙待分”（界线待用户确认，见 11_ §1） |
| 3 部署前检查 | 压力与操作检查；资格与法律 | 动用资金之前做（用户已推迟资格与法律） |

**未确认不等于丙。** 未确认的位置只记“尚不能支持甲乙”。到研究截止日仍测不清，记“丁，按丙处理”，并保留原因；丙的经济结论需要它自己的证据。

**为什么完整位置的净现金排在规模之前。** F84 ⑥：若在实际决策信息下，全成本净盈亏为超鞅，且净亏损确被限制在 3 万元以内，那么净赚 100 万元的概率不超过 3/103 ≈ 2.9%。这一结论有适用条件（见原件），不否定任何未测的条件选择或完整组合，也不直接套用到负权益或无本金的位置。

**罕见尾部为什么难确认（示意，不是门槛）。** 设每次有 1/200 的机会得 300 倍、其余归零，期望 1.5 倍、方差 447.75。按正态近似，在单侧 5% 显著性下以 80% 功效确认它优于盈亏平衡，约需 1.1 万次独立尝试；双侧约 1.4 万次。正式判断只用各卡冻结的推断方法与依赖处理（导航 v1.1 E11 有同类结论）。

**拆分的停止条件。** 一个节点满足任一条就不再细拆：

1. 已能在事件时间上用明确单位测量；
2. 它的合理取值都在决策线同一侧，再拆也不改变决定；
3. 它所在位置已在 1c 或 1d 不通过。

节点停止只限制这一次测量或这一实现，不关闭领域。每片叶子都允许标“不影响决定，不测”。

**证据栏挂在每个节点上。** 沿用交叉索引的认识状态、证据性质、独立核验三列。另一个模型读过并同意，不算独立核验。只有从原件独立复算才算，而且只算到被复算的那个数，不能升级为整个节点已核验。

## 6. 参与者（丙进同一棵树）

角色是标签，可多值：同一实体可以同时是创建者、内幕者与狙击者。比较时，看每个角色在哪个节点上有我们没有的东西，以及我们为什么进不去（九类约束之一）。本稿只列角色与定义；付款方与胜出理由在挂行与取证之后再填，避免先入为主。

| 编号 | 角色 | 定义（含子角色） |
|---|---|---|
| P01 | 创建者、项目方与发行方 | 发币、持预留份额、控制流动性或金库；含稳定币发行与储备管理 |
| P02 | 平台、交易所与交易服务提供者 | 收交易费、发行费、上币费；含发射平台、DEX、钱包、前端与应用的按成交收费，以及分销方 |
| P03 | 同槽买家与狙击者 | 在创建同一区块或紧随其后买入 |
| P04 | 早期分配者 | 通过配售、积分、空投、白名单取得份额 |
| P05 | 内幕者 | 掌握未公开信息（上币、合作、解锁、漏洞） |
| P06 | 刷量与操纵者 | 自成交、拉高出货、捆绑钱包；含受托提供操纵服务、向项目方收费者 |
| P07 | 做市、流动性与风险承保 | 持续报价、LP、maker；含不持续报价的期权卖方与风险承保 |
| P08 | 排序生产链 | 搜索者、构建者、验证者与区块生产者；含订单流提供者及其分成 |
| P09 | KOL 与推广者 | 喊单、带单或收推广费 |
| P10 | 套利者 | 跨场所、跨链、现货与永续之间的价差交易 |
| P11 | 强制交易的对手方 | 接强平单、收资金费；含代偿债务换取折价抵押物的清算人 |
| P12 | 资金提供者 | 提供借贷或杠杆资金、收利息 |
| P13 | 公开信息选币者 | 用公开信息在二级市场挑币。项目多数已测方向在这里 |
| P14 | 事件对手方 | 在上所、告警、退市等事件后交易。局部正结果多在这里 |
| P15 | 后期买家 | 追高与跟风买入，常是付款方 |
| P16 | 持有者、质押者与治理权持有者 | 长期持币；含质押分成与治理投票激励 |
| P17 | 攻击者 | 利用合约漏洞、钓鱼或私钥窃取获利 |
| P18 | 安全研究与审计服务 | 按赏金规则提交漏洞、收项目方报酬；与 P17 分开 |

**守恒检查是排错工具，不是完备性证明。** 按不重复的实体或账户、逐笔转移核对，不按角色标签分别加总。先固定币种、窗口、边界、期初期末余额与跨边界流入流出。费用的收款方（平台、LP、验证者）已在边界内时，不再扣除；只有流出边界或被销毁的费用才是净流出。库存重估的盈亏与现金守恒分开记。账平了也不能证明清单完整：互相对冲的两方同时漏掉，账照样平。

**丙的写法沿用 7_ §7（用户 10-12 裁决）。** 写到收入转移机制、角色权利、各步动用的账户与资金，以及链上与公开记录里的痕迹。不写具体参数、工具配置与规避检测的方法。GPT 建议违法与操纵类连“步骤”也不写（A25），这与用户裁决冲突，交用户确认。

**导航仍是研究单位。** 每个位置保留合同编号与范围。形成类保留“同本金、同发行、同兑现政策”的普通路径对照（导航 §9.1）：一个已具备资格的子集比全体赚钱，不能回答形成资格是否值得。

**本树新增的三处。** 一是闸门顺序与剪枝规则，它是本视图提出的判定次序，不覆盖已冻结的卡片与现行停止规则。二是闸门 1b 的确认途径，由用户 10-12 把门槛定为前向确认而来。三是参与者维度，由 10-12 的目的规则而来；导航 v1.1 §3 “知识不能替代百万目标”一句已由 7_ §7 的丙分支取代。

## 9. 本树的已知风险

1. **周期与合同边界划错。** 次数、投入与单次净现金会一起错。
2. **参考规则与母体决定 1A 与 1B 的分割。** 母体漏了事后死亡或弃权的机会，选择增量会被高估。
3. **投入与净现金不独立。** 投入越大，单次净现金率越低；③给的是范围，不是一个点。
4. **链外价值流看不见。** 付款方一栏在那里只能写“不可观测”，守恒检查也会留残差。
5. **胜出理由多为推断。** 它不能直接测，只能检查“若理由成立应看到什么”。
6. **0 与⑦不完整。** 资格、法律、税与出入金被推迟，树对“能否真正落地”这一段是空的。
