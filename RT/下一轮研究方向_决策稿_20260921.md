# 下一轮研究方向：先完成对象时序，再决定信息投入

2026-09-21。供方向讨论与执行交接；不是收益策略预注册。用户已授权搜索、计算和低成本模型协作。本轮已完成三组对象的本地路径整理，没有打开确认样本、使用付费查询或启动长期采集。

## 1. 我的判断与理由

**继续一轮有边界的发现研究，优先改变问题的提出方式和信息来源；暂不扩大旧特征组合，也不把 Telegram 或 KOL 确定为唯一主线。**

核心问题是：在大量看起来相似的币中，是否存在当时可观察的差异，能使一条明确参与规则在误选、延迟、退出、成本和仓位约束下仍有净价值？最终仍须回到既定本金与三年百万净收益目标。挑中事后赢家、提高 AUC、取得某个 API 都只是中间结果。

现有结果足以降低“继续组合旧市场状态特征”的优先级，尚不足以判断新信息能否解决这个问题。收益集中说明少数对象值得解剖，不证明它们事前有共同标签。案例发现是一种产生假说的办法，不是唯一办法，也不能代替有完整分母的检验。完美预言机的近似收益更不能排除摩擦、容量和资金占用。

**我上一轮把固定消息源档案检查放成了唯一下一步，这个安排需要改。**执行方完成了一项有用的可得性检查，但对象的价格、交易与公开信息还没有对齐。继续让“哪个 API 可用”决定研究什么，会重现用户指出的偏移。

第一行已完成粗粒度价格路径，尚未完成信息时序。**当前最小缺口是把转折区间落到 UTC，并补能区分解释的原始记录。**本地已查到的 F1/F2/F3/M1/M2 导出只有日索引或相对时间，没有所需精确创建 UTC；这不等于链上不可取。下一次取数应明确针对这些对象与区间，不能默认升级为全量采集。

不为了每个赢家都写出故事而扩大案例清单。第三组储备匹配较差；做正式比较前需预先确定匹配容差，匹配不上的对象保留为单例或退出配对推断。三组只负责发现，后续收益估计必须恢复候选适用人群的分母。

## 4. 怎样吸收 F100，而不让它决定方向

保留其来源试取记录；本轮未找到所引 `social_probe.csv`、`tg_probe.txt` 原件，具体计数暂按执行方报告使用。它没有提供能淘汰整个公开传播信息类的证据。

- **自动发帖不能直接判为无用。**链上状态摘要、发布时点和传播触达是不同对象。F83 未覆盖所有自动发布规则。可用机器人档案可以作为时序锚点或对照；这也不构成它值得全面回测的理由。
- **不把网页 ID 缺口直接换算成删帖率。**官方对 API 消息序列的说明不能保证网页预览完整。四个便利样本也不能证明存活频道就是历史表现好的频道。
- **按币搜索和前向采集都有局限。**公开频道全文搜索确有官方接口，但有访问/额度条件，并无无偏历史全集的承诺；前向留存能保存收到的内容，仍有来源选择和漏收问题。见[官方核验记录](../audits/RT_20260921/direction_reset/source_note.md)。

因此当前无需用户申请 Telegram 凭据，也不启动长期前向采集。若一个具体假说只缺该通道能补的证据，再给出所需查询或采集范围、事件量及预期改变的决定。**来源建设的投入必须能改变候选选择或验证可行性。**

## 5. 如何保证这一轮结束时能作决定

本轮止于三组关键时序核验和至多两个可检验假说；这个探索上限不是新增确认名额，沿用全局 ≤3 候选、每候选 4 cohort 等既有约束，A/B 均为开发数据。若这轮仍只有事后解释、拿不到所需时点证据，或没有能覆盖误选与摩擦的规则，就结束这条案例发现路径，不自动再找一批赢家或搭新采集系统。

没有合格候选时，不必凑满三个名额；可以暂停策略开发，保留“尚无可验证优势”的结论。新的投入须有能改变这一判断的具体证据或假说依据，不能只因为某个 API 还能查或某项计算成本低。

发现“有可观察差异但没有经济空间”，应据损失来源决定是否改参与规则、核对场所成本，或停止；发现“差异只能事后知道”，应换信息假说或停止；发现“某来源缺数据”，只决定该通道的投入。关闭本轮投入不要求证明整个信息类永远无效，重启则须有新增证据或明确改变的资源条件。

每项任务保留一句足够具体的开工理由：**哪种结果会使哪个决定改变？**发现阶段允许答案是“决定优先检验哪个假说”，不强迫尚未形成的候选先编出收益增量。

主审负责综合证据、排序与解释决策；低成本模型负责边界明确的检索、整理与计算；承重结果按所需层级独立核验。用户保留目标、总预算和风险边界，不必在 API、SQL 与模型措辞之间充当技术裁判。
