## 问了什么

币安首发上市的 206 条已验收事件（精确 T0 来自旧债务 direction），以 T0+30 分钟为入场、180 天为窗口，是否存在 ≥10×、≥50× 的上市后价格右尾。

## 结论

- ≥50×、≥100×：0 条确认命中，195 条确认未命中，11 条未知。
- ≥10×（最高收盘价口径）只有 GMT（25.27×）和 GALA（12.95×），都在 2021–2022 年。按卡片满足 if_A，但对百万目标支撑很弱。
- 不筛选、持有 180 天，价格中位数 0.30。
- 所有倍数都是零规模价格代理，不是可执行收益。证据：[事实库](../../01_事实库.md) F29–F31。
