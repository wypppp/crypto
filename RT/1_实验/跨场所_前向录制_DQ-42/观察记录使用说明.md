# 热点观察记录：使用说明

这页写给你本人。它说明怎样用一条命令记下你看到的中文热点。

## 为什么要记

你说过在中文热点上“有位置”。这份记录用来测这件事：你什么时候看到、判断会不会出币、币叫什么。以后把它和链上同名币的创建时刻对照（H 第三段，卡冻结之后才做）。

## 两条规则

1. **先记再查。**看到热点就记。不要先去查币、价格或链上数据。
2. **只追加，不修改。**记错了就再记一条更正。每一行都带着前一行的哈希，改动旧行会被发现。

## 在电脑上记

打开 WSL 终端，运行：

```
python3 /home/ancillary/RT/1_实验/跨场所_前向录制_DQ-42/obs.py
```

工具逐项提问，回车用默认值：

| 问题 | 怎么填 |
|---|---|
| 在哪看到 | 平台、群、账号或链接 |
| 看到了什么 | 一句话 |
| 会不会出币 | 是、否、不确定 |
| 预计的币名或关键词 | 可以写几个，用逗号隔开；可空 |
| 预计在哪 | 例如 pump.fun、four.meme；不确定就回车 |
| 把握 | 1～5 |
| 备注 | 可空 |

时刻由工具自动写入，UTC 与北京时间各一列，你不用填。

想少打字，可以在 `~/.bashrc` 里加一行，以后只打 `obs`：

```
alias obs='python3 /home/ancillary/RT/1_实验/跨场所_前向录制_DQ-42/obs.py'
```

也可以一行记完：

```
obs add --where 微博热搜 --what "某某事件" --coin 是 --names "关键词1,关键词2" --venue four.meme --conf 3
```

## 在手机上记

手机上不能直接运行工具，按下面三步做：

1. **先发给自己一条消息。**用会记服务器时刻的应用，例如微信“文件传输助手”或 Telegram“收藏夹”。内容按上表写，写不全也可以。
2. **当天转录。**回到电脑，运行工具；问到“这是转录吗”时回答 `y`，再填消息上显示的时刻（北京时间，例如 `21:05`）和载体（例如 `微信文件传输助手`）。
3. 一行完成转录的写法：

```
obs add --where 微博热搜 --what "某某事件" --coin 是 --conf 3 --transcribed --orig-time "21:05" --orig-carrier "微信文件传输助手"
```

过了零点才转录前一晚的消息，只写 `23:50` 也可以，工具会算到前一天。跨天更久的，写完整日期，例如 `2026-10-13 21:05`。

## 记错了

再记一条，加上 `--corrects 序号`，在备注里写清改了什么：

```
obs add --where 微博热搜 --what "某某事件" --coin 是 --names "正确的币名" --conf 3 --corrects 12 --note "第 12 条币名写错"
```

## 其他命令

| 命令 | 做什么 |
|---|---|
| `obs verify` | 核对哈希链，只输出条数与通过或失败 |
| `obs manifest` | 写一份清单（条数、文件哈希），执行模型每周提交进仓库 |
