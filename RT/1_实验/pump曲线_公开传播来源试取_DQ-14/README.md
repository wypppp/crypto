## 问了什么

外部传播（pump 评论区、Telegram、X 等）能否提供当时市场状态以外、扣除误选与执行成本后仍有价值的增量信息。本轮只做了三组成功/失败对象（6 个币）的公开来源试取。

## 结论

- 没有取得足以认定“当时可知”的原始事件。
- pump.fun 每币评论区的逐条带时间戳档案不可得；固定消息源的档案机制可行，但未找到符合条件的来源。
- 主审发现同名页面混有其他 mint，已纠正。证据：F100。
- 这是数据可得性的结论，不是“公开传播没有信息”的证明。
