## 问了什么

用户问：挑右尾的特征贡献多少、删左尾的特征贡献多少，谁误删了谁？进而问：下一类信息要改善哪一项、改善多少，才值得消耗一个确认 cohort。

## 结论

- 在已测特征上，挑右尾与删左尾是同一种能力：两个任务的 AUC 相关约 +0.96；判别力真实且能跨周（AUC 约 0.66），但按分数买得越准，平均回收越低（F93）。
- 三个附录（F94–F96）进一步分解：概率质量搬运的结构可复现，控制活跃度后的残差信号不可复现；把收益拆为 V/Q/capture，再拆为四层；赢家兑现缺口的 72% 落在“机会 × 兑现率”的协方差上。
- **09-20 审计限定**：文中“普遍候选约束”已撤销；改善上限混用了现金与保留交易两种分母；“前 5%”实际覆盖 6.23%/6.48%；30 天赢家标签漏掉 B 周 3 个赢家。复用前先读总入口 §5.1。
