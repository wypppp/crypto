# WM2 v4：构造效度与继承组件（一页说明）

2026-10-17，回应用户第十六轮；在全量S3之前补写。
v4冻结原件不改。第十七轮将处理办法纳入v5，待红队审阅。
本页不含数据与执行结果；最新红队输入以v5及两份参考为准。

| 关键定义 | 三种现实反例 | 处理或不处理、结论偏向 |
|---|---|---|
| 实体（第十五轮） | 无边轮换；服务地址桥接；共同出资却非共同控制 | 固定W、只挂靠、强连接敏感性；隐藏轮换仍漏，持续性多偏低；误并可能偏高 |
| 毕业事件/自身 | 自己买到毕业；关联体代触发；同slot误当同tx | 完整键及逐事件自身排除；C未知不能当空；隐藏协调仍可能把关联推高 |
| 成熟 | 止点前才买；短观察币被排除；同秒顺序不明 | 严格终点，未成熟单列，缺键拒绝；结论限成熟群，可能偏早参与者 |
| 状态分层 | 对倒净额小但总量大；同桶内速度不同；AMM池深不同 | 边界仅W拟合；现行AMM是粗层，原卡池深分箱尚未实现；残余混杂方向不定 |
| 窗口 | 跨周换钱包；三对受共同冲击；活动转向队列外 | as-of挂靠、活动诊断；不称独立重复，不把队列活动当全市场活动；漏测多偏低 |
| 抽样 | 小主体不足5币；多钱包拆资格；关系币未抽中 | 图与资格都在抽样域；按预定阶梯扩样；不放大资格，不推广全体，偏向未知 |
| 首笔买入 | 未成熟首买消失；先转入库存再买；同秒多腿错序 | 原始锚点与首笔成熟检验行分离；库存成本单列；不叫终生首次买入 |

| 继承组件 | 原实验回答的问题 | 本卡不适用处 |
|---|---|---|
| S/G/T、0.05 SOL、200、CEX | DQ-26：钱包关系及固定排名跟随 | 不是真实身份或控制者阈值；需敏感性/规模分布 |
| C与一跳标签 | DQ-21/WM2设计：创建者位置与钱流 | C不在当前SGT；无输出不能当无关联 |
| 30分钟、首笔成熟、分箱 | WM2 A：条件关联与重复买入反例 | FIRST不包含所有原始首买；粗层不保证交换性 |
| 10%哈希、≥5币、≥20实体 | WM2 v4：抽样及检验人数 | 改变母体与关系可见度，不代表独立人数 |
| 超几何置换/双向重抽 | WM2 v3：条件标签与共同冲击 | 旧校准不自动覆盖v5附着或按触发者删行 |
| 成本上下界与HELD | WM2 v4/DQ-21：现金、残差与兑付边界 | 描述账不等于可跟随的实际收益 |
