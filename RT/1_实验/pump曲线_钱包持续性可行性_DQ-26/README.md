## 问了什么

排名期全成本盈利最多的钱包实体，①在下一个窗口是否仍然全成本盈利；②外部人看到它们买入后（加观察延迟、按下一笔可成交价）跟随，是否还能盈利。两问分开回答，交付冻结集合的整体表现，不挑地址。第一步只问：记账（库存、转入、跨池、网络费、小费）能否闭合，以及它们距 t3 的进场时差。

## 复用须知

- 检验窗口（08-17 起创建的币、08-17 起的分区）没有读过；第二步执行前不得读取。
- 实体关联只表示资金或代币有往来，不是内部人认定；有一个 2,025 个钱包的连通块疑似过度合并；同一操作者切断可见往来时也合不到一起。
- 曲线成交的费用要用事件实际字段（`fee`＋`creator_fee`＋`buyback_fee`），按费率推算会低估；`cashback` 另列。
- 成交交易里也会有转入筹码（捆绑交易），不能按“交易里有成交”整笔归为成交腿。
- `dex_solana.trades` 的 PumpSwap、Meteora 金额在 G1b 中闭合率低于曲线事件；记账优先用协议事件。
