## 问了什么

预注册一个非线性模型（梯度提升树），直接预测每个币的净期望；按分数买前 10%，平均净回收能否 ≥1.03，并跨周成立。

## 结论

- A→B 前 10% 平均净回收 0.895（全买 0.948）；B→A 0.996（全买 0.972）。三条判据都不满足（F87）。
- 现有入场特征只能认出最差的币，认不出净期望 >1 的币。
