# pump 曲线 +30 分钟：右尾测量（DQ-1M）

> **状态：暂停**（按冻结判据判“继续”，随后用户 09-16 暂停整条 pump 曲线路线）｜2026-09-15～16｜Dune 约 130 credits｜现状以 [总入口](../../00_总入口.md) §2.1 为准

## 问了什么

2026-06-01～07 发行的 pump 币，创建后 30 分钟用固定 0.5 SOL 入场，按冻结的退出规则能兑现 ≥10× 的有多少，入场容量多大。

## 结论（v2，修正口径后）

- 主样本 160,313 个币；按 T50 退出能兑现 ≥10× 的 18 个，全部是后来毕业的币；全买平均回收 0.969。
- 赢家的单币入场容量代理中位 $60（$23–152），没有一个 ≥$1,400。这是单币代理，不是账户级资金配置模拟（见总入口 §4 第 4 条）。
- 更正（F64）：按曲线进度挑出的币，赢家占比可达基础的 78 倍，但平均回收只有 0.63；判据应是“选中集合的平均回收 >1”。
- v1 结果（全买 0.753）因卖出上限没计入我方买入而偏低，已被 v2 取代。证据：F55–F64。
