## 2. 写卡时必须满足的（总控第十三轮追加第 4 条）

- **主指标**：每单位投入资金的收益——按超募后的实际获配比例与资金占用时间（认购锁定、退款到账、锁仓释放）计算，不用“每单位额度的收益”。
- **卖出规则冻结时写定**（例如上市后固定时点），并报告长期持有作为对照。
- **母体**包括失败、破发、延期、未上市、退款的发行。
- **数据来源**：MetaDAO 公开 SQL、Uniswap CCA 工厂合约事件、CoinList 2025 年名单、Bitquery 2026 年空投 CSV、币安钱包 TGE 逐次公告。
