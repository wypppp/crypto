## 1. 账户资格原则（总控第四轮第一节）

- 资格按**账户持有人本人的身份与交易时的实际所在地**判断。不用他人身份开户，不代他人操作，不用 VPN 隐藏所在地。
- 任何参与或下单之前，先逐个平台核实实际账户持有人的资格，并记入卡片。研究只用公开数据，不受影响。
- 已知：澳大利亚在 Kraken 与 Bybit 的 xStocks、Polymarket、Kalshi 的限制名单上；本机访问 Bybit 公开接口返回 403（10-02）。

## 2. 四周试攻的退出门（只是资源决定，不是证伪）

①有可机械检验、付钱方明确的规则；②免费数据足够；③实际账户持有人的资格已核实；④参与一侧的单身份净得为正或可估。注意：HIP-3 的成交在 8～9 月明显回落（总控），“正在形成”不等于“持续增长”。

前向记录器的局限：它跑在本机 WSL 里，电脑睡眠、关机或 WSL 停止时会有缺口（`raw/recorder/heartbeat.txt` 与 `recorder.log` 可查）。**已发生一次**：10-02 主机睡眠约 84 分钟，04:00 那一拍漏了（快照只有 02:09、03:02、04:56）。原因是旧版一次睡到下一拍，主机睡眠时单调钟停走，醒来后还要补睡同样长；04:56 改为每 30 秒按墙钟检查一次、过点即补拍，并重启（`recorder.log` 两条 start）。睡眠期间的缺口无法补回。执行模型想加一个每 5 分钟检查、掉了就重启的 cron 看门狗，被权限检查拦下（属于在你机器上设置常驻任务），没有设。要不要加、或者改放到便宜的服务器上，由你决定（见总入口 §0）。
