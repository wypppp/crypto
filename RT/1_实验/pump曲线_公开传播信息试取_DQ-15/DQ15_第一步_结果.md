# DQ-15 第一步结果：没有合格来源

> 2026-09-22｜只回答"是否存在可研究的公开传播信息"，不做收益检验｜检索方与执行方都没有连接任何收益或赢家标签｜成本：Dune 0、Helius 0、付费接口 0；公开网页/接口请求约 400 次（Telegram 305、Reddit 约 54、4chan 约 21、Farcaster 约 10、Bluesky 约 9）

## 1. 结论

**按卡 §2 的负分支处理：在本轮检查的范围内，没有来源同时满足 §4.2 四个条件并达到"数十个不同 A 周币"的量级。**本轮 B 的来源投入结束，卡 §3 中"公开传播"的排序撤回。

这是**资源退出决定，不是证伪**。它只说明：在下列平台、用下列方法，找不到能支撑一次开发比较的公开传播档案。它不说明公开传播信息没有价值，也不覆盖 X/Twitter（没有免费历史接口）、私人群和付费群。

## 3. 顺带观察（未检验，不构成建议）

1. **能取到的人工来源都很稀：**A 周人工撰写、带合约地址的公开提及合计 26 个币，与 308 个 H1 触发只重叠 3 个，且都在触发之后 1.6–2.8 天。机器人频道提到的币多一个数量级（405、70 个），多数在 H1 触发之前。
2. **公开的"喊单频道"历史可能是结果选择过的：**@solana100xcall 公开区只发赚钱的战报。只看了这一个频道，不能推广。
3. **@devcabal 是定时喊单群的形态**（固定时刻、倒计时、发后编辑）。一周 6 个币，量太小，本轮不展开。
4. **DEX PAID（Dexscreener 付费资料）是一种链外的开发者付费事件**，直接来源是 Dexscreener，不是传播平台，不在本卡范围。历史可得性未查。

## 4. 覆盖缺口（结论只在此范围内成立）

- X/Twitter 未覆盖，这是 meme 传播最主要的渠道。
- Telegram 发现方法：16 条搜索引擎查询加一个 GitHub 第三方工具的配置项；搜索召回系统性偏向品牌化机器人频道，唯一的人工喊单频道来自 GitHub 配置而不是搜索。人工频道的召回率很可能低。
- Reddit 只查了 5 个版块；4chan 只能按关键词检索，词表不穷尽。
- `t.me/s` 的 ID 缺口不能区分删帖和网页层不显示的内容类型。
