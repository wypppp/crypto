# Meteora DBC→DAMM v2：报价复现与跨迁移测量（DQ-4）

> **状态：暂停**（用户 09-15 改判 if_C）｜2026-09-15｜费用 0，只读 RPC 13 次｜现状以 [总入口](../../00_总入口.md) §2.1 为准

## 问了什么

在 Meteora 的 DBC（联合曲线）迁移到 DAMM v2 的发行上，固定金额“买入—持仓—退出”能否低成本测量：历史报价能否离线复现，能否跨迁移追踪同一仓位。

## 结论

- 3 组相邻成交，用“上一笔事件状态 + 静态配置”经官方 SDK 离线复现，输出额、成交后价格、各项费用逐位一致。
- 但 DAMM v2 的复现用了较晚快照的 liquidity，只证明输入与已发生成交相容；历史 liquidity 未能从事件唯一重建，跨迁移仓位测量没有跑通。
- 工程样本较晚快照的 liquidity 约为初值的 11%，退出测量必须追踪撤池。
- 这是“测量未闭合”，不是“场所没有机会”。证据：F38–F44。
