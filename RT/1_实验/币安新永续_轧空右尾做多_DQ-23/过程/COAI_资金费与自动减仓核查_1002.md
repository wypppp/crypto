# COAI 的资金费能否收到、自动减仓的假设（10-02 案头核查）

> 依据：用户 10-02 裁决〇-3（[存档](../../../3_审计/2026-10-02_总控第八轮与用户裁决_资格Hydromancer前向卡数据落袋.md)）：DQ-23 前向卡登记前，先案头核查 COAI 那笔资金费能否真正收到，以及自动减仓（ADL）的假设。
> COAI 是已看过的开发事件。0 credits；脚本 [coai_check.py](coai_check.py)，输出 [coai_check.json](coai_check.json)；规则检索见 [检索记录](../../../5_参考/检索记录/币安自动减仓与资金费规则_COAI_检索.md)。

## 1. 资金费

| 项 | 结果 |
|---|---|
| 持有 30 天内的结算 | 444 次；间隔 4 小时 92 次、1 小时 351 次（触及上限后改为每小时结算） |
| 触及 −2% 上限 | 28 次；费率合计 −161%（按入场名义额） |
| 机制 | 币安 FAQ：资金费在结算时刻的持仓者之间直接划转，平台不收；只对结算时刻持仓者收付。归档里的费率是否就是实际结算费率，没有官方说明（与 DQ-22 一样按它计） |
| DQ-23 原口径（结算当日收盘标记价） | **+124.0** 倍保证金 |
| 按结算时刻的小时标记价重算 | **+138.4** 倍保证金（原口径偏低 14.4） |
| 集中度 | 资金费贡献最大的 5 天占 81%，都在 10-12 之后（价格已涨了很多倍） |

结论：只要仓位一直在，这笔资金费按规则是收得到的；大头来自后期、按放大后的名义额收取，所以**完全取决于仓位能活到后期**。前向卡改用结算时刻的小时标记价计资金费。

## 2. 自动减仓

| 项 | 结果 |
|---|---|
| 触发 | 只在保险基金接不住破产仓位时（币安 FAQ） |
| 排序 | 盈利仓位按“盈利百分比 × 有效杠杆”排队，被减仓者按被强平订单的破产价平仓。1 倍逐仓多头大涨后有效杠杆约 1，排在高杠杆同向仓位之后，但**不是零风险**（推算，逐仓下“余额”口径未核实） |
| COAI 期间的公开记录 | 没找到 ADL、保险基金耗尽、调杠杆或持仓上限、暂停、下架的公告或报道（不等于没发生） |
| 持仓限制 | 3,000 元仓位涨 30 倍后名义额约 9 万元，推算远低于“只能减仓”的触发线 |
| 持有期内标记价 | 最低为入场价的 0.85，最高 **156.8 倍**，期末 31.7 倍 |

**若在持有期内任一小时末被减仓**（按该小时收盘标记价加上之前收到的资金费）：最小 −0.14、10% 分位 0.17、中位 38.3、90% 分位 173.1、最大 225.9 倍保证金；若在前 10 天内被减仓，最多 15.1 倍。

结论：DQ-23 的 +154.7 倍建立在“一直没被减仓”上；被减仓的时点不同，结果可以从约 0 到 226 倍。假想仓位无法观察是否被减仓，所以前向卡：①主统计量用截断回收 Z＝min(R,3)，像 COAI 这样的赢家，只要在回收过 3 倍之后才被减仓，主统计量就不受影响；②另报“若在任一小时末被减仓”的逐事件分布作敏感度；③动用真钱之前（门 2）须实测 ADL 指示与保险基金状况。
