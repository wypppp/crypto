## S0 结构核对（10-05；[S0_结构核对.md](S0_结构核对.md)，脚本 `s0_structure.py`，链上锚 `sql/S0_链上时间锚.sql` 0.27 credits）

| 项 | 结果 |
|---|---|
| 版本与哈希 | 修订 `71211f6d`；parquet sha256 `1ac22b5c…`，与 HF 的 LFS 记录一致；8,960 行、7,965 个 token |
| 分类（按链上曲线创建） | 开发 3,856 个 token（4,366 行）；检验周 3,801；留出同名 55；早于 DQ-37 范围（2025-02-24 前创建）192；无链上创建记录 61 |
| 时间锚 | 数据 `created_at`＝链上曲线创建，7,786/7,786 逐秒一致。数据 `graduated_date`＝链上 **PumpSwap 建池**时刻，6,280/6,280 逐秒一致；它不是曲线完成时刻（完成早 0～41 秒，p99）。另有 1,575 个 token 查不到“pump 迁移、池序号 0”的建池事件，原因未查 |
| 多出的 995 行 | 291 个 token 重复出现。组内创建与毕业时刻相同，名称、代号、图片都不同；开发 token 的重复行价格与成交列完全相同（161/161） |
| **元数据错位** | 不重复的 7,674 个 token 里，名称、代号与链上初始值一致的只有 10 个。有 7,725 行能按“代号＋名称”唯一认领到本数据集某个 token，但只有 10 行认领到自己；所属 token 的创建时刻相差中位约 6 天，分布很散。**发布的数据里文本特征基本接在别的币上，价格列与 token 对应。** |
| 缺值 | 开发行的价格列、成交列各 2,722 格为空（共 4,366×15 格） |

**这对复现意味着什么**（只限本数据版本）：
- S1／S2 的文本特征一律用链上创建事件（name、symbol、uri）重建，不用数据里的元数据列；
- 论文所用数据是否有同样的错位，从发布版本推不出，不下结论；
- 995 行多余的原因是元数据一对多连接；同一 token 的价格只算一次。
