# pump 曲线：案例逐笔时序与点火跟随 H1

> **状态：停止**（H1 v0 负结果分支；用户 09-22 确认）｜2026-09-21～22｜Dune 约 29 credits；Helius 用量分段记在工作日志｜现状以 [总入口](../../00_总入口.md) §2.1 为准

## 问了什么

分两步：

1. **案例时序**（F101）：A 周 3 个高回收币与 3 个失败对照，重建创建到入场后 24 小时的全部成交，看主升段从哪里开始。
2. **H1 点火跟随 v0**（F102–F105）：把第一步发现的“点火”（首笔净注入 ≥4 SOL、此前 30 分钟 <4 SOL）固定成规则，在 A 周全部 SOL 币上枚举触发，按 30/120/300 秒延迟跟进，看净回收。

## 结论

- 案例：三个赢家的主升段都始于入场后 3.1–7.6 小时的一次大额“点火”买入，三个对照都没有点火。
- H1：A 周约 18.4 万个币中 308 个触发。去掉三个开发种子后，120 秒延迟的净回收 **0.911**（事件自助 90% 区间 0.830–1.006）；正的总均值全部来自种子。
- 更快进场不更好（30 秒 0.897）；按点火钱包的点火次数分组，没有一组 >1，H2 启动条件不满足。
- 09-22 主审复核：撤回“信息必须早于点火”和沿用 1.03 门槛两条推论；修正退出时钟后，峰值持仓 63 笔、31.5 SOL。
