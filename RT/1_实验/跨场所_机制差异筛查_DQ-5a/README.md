# 跨场所：机制差异筛查（DQ-5a）

> **状态：停止**（冻结判据 if_B）｜2026-09-17｜费用 0（Dune 只读目录与公开网页）｜现状以 [总入口](../../00_总入口.md) §2.1 为准

## 问了什么

是否存在某个场所或发行机制，其规则差异可能改变“用公开状态做事前筛选会失败”这一原因。8 个候选按机制（M）、数据（D）、参与（P）、右尾（R）四项打分。

## 结论

- 8 个候选（Virtuals Genesis、币安 Alpha、Buidlpad、Legion、Clanker v4、Virtuals 防护模块、Pons、Meteora DBC 防狙击）无一同时满足条件（F71–F72）。
- 观察到的规律：消除速度优势的分配类机制（积分、额度），几个月内就被刷分工作室工业化，随后平台改规则或收益塌缩；按时间衰减的抢跑税只作用于开盘后数秒到 98 分钟。
- **09-20 审计限定**：这一规律只来自两个例子，不能推广为“其他场所大概率重复失败”；“测不到”“未查到”和“经济上不存在”要分开。
