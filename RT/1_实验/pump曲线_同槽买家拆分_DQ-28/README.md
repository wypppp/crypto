# pump 同槽买家拆分（DQ-28）

> **状态：完成（10-02）。按冻结读法为读法 1（停），但被“创建即迁移”币上的巨额薄池买入主导，不能作证据；看结果后只看曲线币，独立同槽买家全成本回收 1.20（1.17～1.23），即速度策略的上界为正**（[结果](结果_v1.md)，F130）。依据：总控 10-02 安排的试用额度第 1 项，设计由执行方定；执行决定，可推翻。现状以 [总入口](../../00_总入口.md) §0 为准。

## 问了什么

与创建同一 slot 买入的钱包里，和部署者无关的那部分，扣网络费、优先费、Jito 小费和平台费后是否赚钱。只算抢到同槽的，所以是“拼速度”策略回收的**上界**：上界 <1 就停掉 pump 上的速度这条；>1 只说明要再测，不说明值得做。
