# pump 曲线：实体聚类迁移冒烟（DQ-10M）

> **状态：暂停在冒烟后**（完整模式因成本出局）｜2026-09-17｜Dune 约 323 credits（其中一次超时中止扣 320），Helius 约 2,300｜现状以 [总入口](../../00_总入口.md) §2.1 为准

## 问了什么

把 MELT 论文的实体聚类（同笔交易、Jito bundle、钱包首笔交易签名者）截断到入场 +30 分钟，看能否把“被止损的币”剔除掉而保留赢家。本文件夹只完成了第一步：冒烟，确定可行性和成本。

## 结论

- 技术可行：Helius 取首笔签名者 229/229 成功，与 MELT 数据 30/30 一致。
- 成本出局：完整模式每钱包 10 credits，A 周约 25.5 万钱包，单周约 255 万 Helius credits，超过 2M 总额。便宜路径约 60% 钱包一页可取，单价未读。
- 教训：`S2_calib` 超时中止仍扣 Dune 320 credits；付费 SQL 必须带平台费用上限。
- 另有已登记的设计缺陷：服务型签名者的分类有时点泄漏（总入口 §5.1）。证据：F89–F92。
