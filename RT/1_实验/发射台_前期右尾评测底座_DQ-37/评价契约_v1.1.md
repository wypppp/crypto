## 0. 总原则

**先证明优势，再看到达能力。** 一个固定政策先在我方可成交的条件下通过第 3 节的某个确认通道，再用第 4 节的账户模拟看它在真实账本和期限下的到达能力。到达概率和对数增长 g 都不能代替优势证据。

**换指标不会制造新的独立证据。** 在已经打开过的数据上算出的结果，一律只算开发证据。

**确认时整包冻结。** 入场、选择、退出、下注、成本作为一个整体冻结，只关闭被测的那个实现。开发期用配对消融（第 5 节）找出起作用的部分。

## 1. 资金账本

本节细则由总控代定，用户可推翻。背景.md 第 3～5 条是上位规则。

### 1.1 记号与成功

- **T0**：第一笔计划资金的实盘交易时刻。不超过 $300 的校准账户不算（09-30 裁决）。
- **D(t)**：累计入金。**W(t)**：累计取出，成功前为 0。
- **三种价值分开**（v1.1）：

| 价值 | 用于 | 怎么算 |
|---|---|---|
| 可执行清算价值 liq | 判定成功、盈利追加 | 现金＋可交易仓位按此刻整仓卖出的可执行回款；锁定资产与未到账退款不计 |
| 风险估值 V_loss | 判定“亏完”、暂停线、停止线 | liq＋锁定资产按 1.3 节三类计价＋未到账退款按退款额 |
| 可用现金 | 开仓 | 现金 |

- **N(t)**＝价值＋W−D。成功用 liq 计，亏损线用 V_loss 计。
- **成功**：36 个月内首次出现按 liq 计的 N ≥ 100 万元。不把不同时刻的峰值相加。
- **估值频率**：每笔成交时，以及至少每日 UTC 00:00 各一次。
- **尘埃核销**：只作用于持仓，不作用于现金（第十五轮第 5 条）。

### 1.2 分批入金

| 规则 | 内容 |
|---|---|
| 第一笔 | T0 投入 1 万 |
| 第二笔 | 阶段 A 中，D＝1 万且 V_loss < m_min 时，自动投入 1 万 |
| 盈利追加 | T0 起 12 个月内，D＝1 万且 liq ≥ 10 万时，追加 2 万，只一次 |
| 入金上限 | 累计入金不超过 3 万 |
| 暂停线 | 阶段 A 中 N ≤ −2 万：清掉可交易仓位、停止开仓；三年时钟继续走 |
| 资金耗尽暂停 | V_loss < m_min，且没有下一笔可投：暂停，保留真实现金与 N（v1.1） |
| 恢复（第三笔） | 见 1.5 节。满足后，D < 3 万则投入 1 万，进入阶段 B |
| 阶段 B | 不再有暂停线 |
| 永久停止 | 任何阶段、包括暂停中，N ≤ −3 万 |

已知后果照写：盈利追加之后若账户归零，N＝−3 万，永久停止。右尾策略在 90 天的前向数据里可能一次也命中不了，因而无法恢复，这是有意的保守。

### 1.3 锁定资产（v1.1）

锁定资产分三类计入 V_loss：

| 类 | 怎么计 |
|---|---|
| 项目未上市 | 按成本；从认购截止日起 180 天仍未上市，记 0 |
| 已上市、我方额度在约定归属期内 | min(成本, 合格市价×0.7)；没有合格市价按成本 |
| 逾期未解锁（过了约定解锁日） | 记 0 |

- 起算日不随项目延期重置。项目宣布取消或失败，记 0。
- **合格市价**：过去 24 小时成交额 ≥ 我方该资产估值的 10 倍；否则视为没有市价。目的是防止一笔极小报价让估值跳变。
- 30% 折扣是政策选择，不是真实价值的下界。
- 单笔认购受单仓上限约束；锁定期内的金额计入总敞口（第十五轮第 4 条）。

### 1.4 退款

- 到账之前：不计入 liq；在 V_loss 里按退款额计。
- 到账：资产转换，现金增加，累计入金 D 不变。
- 减记后恢复交易时，不重复计资产。

### 1.5 暂停、恢复与停止

- **暂停期间**：清掉可交易仓位，禁止开仓与认购；锁定资产照常跟踪；停止线照常有效。
- **恢复**：暂停 ≥90 天，且某个冻结政策（含下注规则）在暂停开始后新采集的前向数据上，通过其卡片预先写定的确认通道（第 3 节的 C2 或 C3）；不超过 36 个月期限。三项都在状态机内校验，并记录暂停起点。
- **永久停止之后**：继续记账，不自动恢复。

### 1.6 实现约定（10-06，GPT 批 1b 反例；把 1.1～1.5 写到可执行）

1. 恢复之前先按恢复时刻重估。重估触及停止线，即永久停止，不能恢复。
2. 确认凭证必须绑定政策编号，以及确认所用数据的时段；时段必须在暂停之后、恢复之前。只验“非空”不够。
3. 暂停期间解锁的资产，按当时的可执行清算价值直接转为现金。
4. 每个仓位、每笔认购都有唯一编号。同名资产的两次认购各自计账。
5. 退款到账之前必须先有退款申请。负金额、未知编号一律拒绝；任何事件先校验、后改账。
6. 永久停止不会被期限检查改写成“期满”。
7. 期望回收 ≤1 时（包括确定回收 1 倍），Kelly 返回 0。

### 1.7 账本测试情景（实现 T10，全部通过）

1. 第一笔亏完 → 自动投第二笔 → 再亏完 → 暂停，N＝−2 万。
2. 第 6 个月 liq＝10 万 → 追加 2 万 → 归零 → 永久停止。
3. 第 13 个月才到 10 万 → 不追加。
4. 暂停后恢复 → 投第三笔 → 阶段 B 中 N＝−1.5 万不暂停 → 归零 → 永久停止。
5. 追加之后回落到 N＝−2 万 → 暂停；恢复时入金已到上限，不再投。
6. 第 30 个月 N ≥ 100 万 → 成功；第 37 个月 → 期满，不判成功。

另有 GPT 批 0 与批 1b 的反例测试（尘埃卡死、锁定减记误触、暂停中减记触发停止、退款到账、恢复绕过，以及 1.6 节七条），见 `test_eval_contract.py`。

## 2. 下注政策

本节由总控代定，用户可推翻。

### 2.1 研究目标与支付路径

选币研究的目标是选中 10～100 倍以上的事件。下注规则只在策略通过确认之后启用。

### 2.2 保守分布与保守 Kelly

- 用第 3.3 节的台阶同时下界 L_j 构造保守分布：P(R＝r_j)＝L_j−L_{j+1}，P(R＝0)＝1−L_1。下界成立时，真实分布随机占优于它。
- f_c＝argmax_f E_cons[ln(1+f(R−1))]。保守期望 ≤1 时，f_c＝0，不下注。

### 2.3 政策族（预登记，只在其中选）

- 候选分数在开发期冻结成一个网格（P6）。不能在确认数据上先求 f_c，再生成 {0.5, 1, 2}×f_c 当候选。
- 只保留 g_cons(f) > 0 的成员。
- **P12 的准确含义**：这只排除了“在保守分布下 g ≤ 0”的下注；它不保证不超过 Kelly 最优比例，也不控制有限期限内的大亏风险。2×f_c 作为政策选择保留（v1.1）。
- 不允许：全仓或孤注；随期限临近改变仓位（时变政策须作为新的预登记成员，另行审阅）。
- 硬上限：单仓 ≤ 20% V；同簇 ≤ 30% V（同一创建者、同一叙事标签、或同一小时内入场）；总敞口 ≤ 100% V，无杠杆。这两个比例是政策选择，没有最优性保证；锁定资产计入敞口。
- 并发：多个信号同时出现时，按卡片预先写定的优先级排队，不对每个币各算一份 Kelly 再相加。
- 选择：在账户模拟中取到达概率最高的成员；并列时取永久停止概率较低的。所有成员的结果都报告。

### 2.4 最小票面

- m_min 取“往返固定成本 ≤ 票面 2%”的最小票面，数值由执行模型实测。
- 若 f·V < m_min：只在 m_min/V ≤ 2f_c 且 g_cons(m_min/V) > 0 时下 m_min，否则跳过（第十五轮第 3 条）。
- 升票须同时满足现金、单仓、同簇、总敞口四个上限；升票后按实际的 R(q) 重新评价（v1.1）。

## 3. 优势证据通道（只用于冻结之后、新数据之上）

### 3.1 C1 关闭

R 的平均回收置信上界 < 1 → 关闭被测实现。

### 3.2 C2 截断通道

Z＝min(R,3) 的均值置信下界 > 1 → 支持 E[R] > 1（因为 R ≥ Z）。Z 不通过，不否定原策略。它是正期望的一条充分证据通道。

### 3.3 C3 右尾证书

**台阶证书。** 预先写定台阶 0＝r_0 < r_1 < … < r_J 与固定分数 f；令 h_f(r)＝ln(1+f(r−1))；L_j 是 P(R ≥ r_j) 的下界。则

g(f) ≥ G_L(f) :＝ h_f(0) + Σ_{j=1..J} [h_f(r_j) − h_f(r_{j−1})]·L_j。

- 条件（v1.1，P4）：R ≥ 0（含全部成本）；0 ≤ L_j ≤ 1；各 L_j 在同一事件上同时成立；L_{J+1}＝0。
- 证书本身不要求 L 单调。构造保守分布时，用“从右往左的累积最大”单调化（第十五轮第 1 条）。
- 在同时下界下，证书对同一 R 的全部 f 同时成立（P6）。
- 判据：G_L(f) > 0 → 支持 g(f) > 0，也推出 E[R] > 1。

**封顶对数的经验 Bernstein 下界（独立同分布）。** 令 Y＝min(ln(1+f(R−1)), u)，u 在读结果前写定；下侧不截断，所以 E[Y] ≤ g(f)。对 n 个观测、同时保护 M 个固定政策：

L＝mean(Y) − sqrt(2s²·ln(2M/α)/n) − 7(u−a)·ln(2M/α)/(3(n−1))，a＝ln(1−f)。

M 取开发期冻结的 f 网格大小（P6）。判据：L > 0 → 支持 g(f) > 0。

### 3.4 依赖处理

- 先选推断对象，再选有条件保证的方法；移动块自助只作敏感性分析（第 12 节第 1 问）。
- 独立同分布的逐币界只作参考。
- 若某一窗口只有一两个超级币支撑结果，写“频率尚未确认”，不能靠自助法复制它们来制造可靠性。
- 右尾候选的确认走“规则窗口”轨道，推断方法见 [规则窗口_推断方法_v1.md](规则窗口_推断方法_v1.md)。

### 3.5 无优势基准（只作参照）

全成本累计净盈亏是超鞅、最大亏损确实不超过 3 万、没有跳空越线或未计负债时，任何合格政策到达“+100 万”的概率 ≤ 3/(100+3)＝2.9126%。“明显高于 2.9%”是偏好，不是正期望的必要条件。

### 3.6 显著性预算

确认账里写清冻结政策的个数 M。各通道之间用 Holm 校正，经验 Bernstein 用 ln(2M/α)。在同一份留出数据上挑最好的，必须保护整个家族。看过数据之后再改版，需要新的时间批次。

## 4. 账户模拟（到达能力；报告用，不作门）

- 输入：冻结政策的单注回收 R(q)（随仓位 q 变化）、信号到达日历（开发期真实日程，按块重抽）、持有期与并发、簇相关、成交失败与延迟、成本漂移、第 1 节的状态机、第 2 节的政策族。
- 输出：每个政策的到达概率、暂停概率、永久停止概率；36 个月时 N 的分布；到达时间的分布。
- 恢复情景报两种：90 天后立即恢复（乐观）、永不恢复（保守）。分布用保守版和点估计版各跑一次，以保守版为准。

## 5. 开发期配对消融与负对照（诊断，不授予通过）

- 选币 × 择时 2×2：G00、G01、G10、G11 四格在同一组可见事件上、沿真实路径估值；报两个增量与交互项。等待期间死掉、未触发、资金闲置的币都留在分母里。比较退出时，先固定入场。
- 负对照：在同日、同币龄、同市场状态、同可见流动性风险的集合中随机选相同数量的真实决策事件，执行同一政策。不用时间顺序打乱的路径。

## 8. 标签规则

- 固定入场价、仓位 q、期限 H 与可清算回收路径 V(t;q)，令 M_H＝max V。M_H ≥ K 的币按期末 V(H;q) 分为期末保有型（≥K/2）、期末回落型（<1）、介于二者之间、期限未满或数据不足四类。
- 不得按真实类型分配退出规则，那只能报告为“不可实现上界”。
- 训练只用已成熟的标签；结果窗口重叠的样本做 purge/embargo。创建者履历只累计决策时已发生、结果已可知的事件。
