## 问了什么

DQ-2 触发 if_A 后：上市前可见的特征（公告、市场环境等）能否区分 9 个赢家与 161 个失败案例；赢家在可执行退出规则下能兑现多少。

## 结论

- 没有任何特征取值同时覆盖赢家 ≥50% 且覆盖全部 ≤30%，按冻结判据不值得验证，不再对 DQ-2 子集追加投入（F45）。
- T50 退出下赢家组中位 3.28；GMT 可到 11.71（F47）。
- “BTC90≥1.2”一档零赢家，只作线索，没有开新卡（F46）。
- 性质是开发性分析：DQ-2 结果此前已被查看；55 条留出集未打开。
