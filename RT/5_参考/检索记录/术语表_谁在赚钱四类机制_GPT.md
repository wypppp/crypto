# 术语表：“谁在赚钱”的四类机制（GPT 原文摘录）

> 来源：GPT 10-02 之前一轮回答的第四节，原样摘录；全文存档于 [3_审计/2026-10-02_GPT复核与用户裁决_判断日志计时留出.md](../../3_审计/2026-10-02_GPT复核与用户裁决_判断日志计时留出.md)。总控 10-02 第二轮建议存作术语表；结尾的四个归因问题已作为“谁在赚钱”类结果的固定小节写进 CLAUDE.md。
> 用途：解读结果时区分注意力操纵、刷量、内幕、MEV 四类收入来源。这里不是事实来源，法律举例来自美国公开案件，具体认定取决于行为、资产和法域。

**四、非法优势不止三类，但“有优势”与“违法”不能混为一谈**

普通推广、合法做市、公开信息的快速反应、多钱包使用，都不能自动归为违法。以下用美国公开案件和规则说明机制；具体认定取决于行为、资产和适用法域。


| 类型                           | 高层运作机制                                                                             |
| -------------------------------- | ------------------------------------------------------------------------------------------ |
| **虚假宣传与协同拉盘出货**     | 提前持仓，再通过虚假信息、伪造背书或协同宣传诱导买盘，借此兑现；推广和持仓本身不自动违法 |
| **刷量、伪造独立需求**         | 同一控制方的账户相互交易，把自己的活动包装成市场成交和买家兴趣，吸引外部参与者           |
| **滥用保密信息**               | 接触尚未公开的上币、订单或项目决策信息，违反保密义务用于交易或向他人泄露                 |
| **虚假挂单**                   | 挂出没有真实成交意图的订单，制造供需假象，引导别人交易；正常撤单不能直接认定为此类行为   |
| **欺诈发行、挪用资金或流动性** | 对资金用途、流动性锁定或管理权限作虚假承诺，再利用实际控制权取走资金或阻碍退出           |
| **盗窃与未经授权访问**         | 通过盗取密钥、钓鱼或系统漏洞取得他人资产；收益来自盗窃                                   |
| **操纵计价或结算依据**         | 扭曲薄弱市场的价格，影响依赖该价格的抵押、清算或结算；是否构成违法需要具体判断           |

这些有实际案例支撑：Gotbit 因刷量、操纵及欺诈被定罪；Coinbase 的 Ishan Wahi 因泄露保密上币信息供关联人交易被判刑；SafeMoon 案涉及对流动性池控制权的虚假陈述与资金挪用。[justice.gov](https://www.justice.gov/usao-ma/pr/cryptocurrency-financial-services-firm-gotbit-and-founder-sentenced-market-manipulation?utm_source=chatgpt.com) CFTC 对虚假挂单的规则则强调下单时取消而不成交的意图，不能仅凭大量撤单判断。[CFTC](https://www.cftc.gov/LearnAndProtect/AdvisoriesAndArticles/CFTCGlossary/index.htm?utm_source=chatgpt.com)

MEV 应另外拆开看：套利、强平、三明治各有不同机制，法律地位也不能一概而论。“先买后卖”“同槽买入”这些链上现象，本身不是违法认定。

**你们现在值得验证的是：能否利用合法、公开的信息和可购买的执行服务，在成本后取得有价值的交易顺序。租服务器让这个问题更值得测，但尚没有替你们回答它。**

先把四者的区别放清楚：


| 类型       | 优势主要来自哪里                     | 钱主要怎样获得                                 |
| ------------ | -------------------------------------- | ------------------------------------------------ |
| 注意力操纵 | 影响别人关注什么、相信什么、何时买入 | 提前持货后向被吸引来的买家兑现，或收推广费     |
| 刷量       | 制造交易活跃、买盘旺盛的假象         | 收取操纵服务费，或帮助持货方吸引买盘、兑现筹码 |
| 内幕       | 提前掌握受保密约束的重要信息         | 在信息公开、价格调整之前建仓                   |
| MEV        | 交易的纳入、排除和执行顺序           | 获取套利差价、清算奖励或顺序带来的收益         |

**它们可以同时出现，但不能仅凭“早买”“多钱包”“成交很多”认定存在违法操纵。**下面的法律例子主要来自美国公开案件，具体认定仍取决于行为、资产和法域。

**1．注意力操纵：让人群在自己准备好的时候到来**

它的核心是掌握需求到达的时机。可以把一个典型的拉盘出货过程理解为：持货方先取得筹码，通过宣传、喊单、背书等方式吸引关注，外部买入推动价格和成交，再借新增买盘兑现。

这里可能有几种不同的角色：

- 持货方赚筹码升值和兑现的钱。
- KOL、频道或营销公司赚推广费，也可能同时持货。
- 交易工具和平台从新增交易中收费。
- 后来的参与者赌还有下一批买家，或者赌自己能更早退出。

这些角色不一定属于同一团伙，也不一定全部赚钱。

举个忽略费用的示意：同一枚币，早期持货者成本为 1，跟随者成本为 10，两人最终都以 5 卖出。前者赚 4，后者亏 5。**市场价格已经大跌，早期持货者仍然可以盈利。**因此，仅看盈利钱包，不能认定它判断出了一个有长期价值的币。

需要区分三种宣传：


| 情况                                               | 性质                                 |
| ---------------------------------------------------- | -------------------------------------- |
| 用户自发讨论、真实体验、公开表达持仓观点           | 可以形成真实需求，不能自动认定为操纵 |
| 付费推广、项目方营销                               | 有利益冲突；适用情况下有披露义务     |
| 伪造背书、虚假承诺、假装独立推荐，配合协调交易出货 | 可能涉及欺诈或市场操纵               |

有些喊单群甚至公开宣布“我们要一起拉盘”。研究发现，参与者明知如此仍会加入，赌自己有速度或技巧优势。公开宣布也不能单独排除操纵风险。[Review of Finance](https://revfin.org/a-new-wolf-in-town-pump-and-dump-manipulation-in-cryptocurrency-markets/?utm_source=chatgpt.com)

SEC 对 Kardashian 的案件涉及**没有披露付费推广报酬**，这与认定她亲自操纵价格是不同的问题。[sec.gov](https://www.sec.gov/newsroom/press-releases/2022-183?utm_source=chatgpt.com)

对你们而言，关键是区分：关注是否在扩大到新的独立人群，还是同一组织在反复制造声量。热度高、评论多、很多账号同时推荐，都不能单独证明后续需求会持续。

**2．刷量：交易是真的，所表达的需求可能是假的**

刷量最容易被误解成“伪造交易记录”。实际上，很多刷量交易确实成交、确实上链，也确实付了手续费。

问题在于：**买卖双方可能受同一控制，交易没有表达独立投资者的需求。**

在不同场所有不同表现：

- 在订单簿交易所，同一控制方的账户相互买卖，制造成交记录。
- 在 AMM 中，同一控制方反复与池子交换，产生买入、卖出和成交量。
- 多个地址的协调活动，可能被统计成多个买家，营造参与者众多的印象。

多钱包和高周转本身并不违法；套利、做市、资金管理也会产生这些现象。判断需要结合控制关系、资金流、交易目的等证据。

刷量主要有几种经济用途：让币看起来容易交易，进入交易量或热度榜，向潜在买家展示“市场已经认可它”，或者帮助项目争取更多曝光及交易场所支持。

**刷量服务商也不一定靠炒币赚钱。**它可以向项目方收服务费。项目方支付这笔成本，期望以后从外部买盘中兑现更多筹码。Gotbit 的公开案件就涉及人为制造交易量，并从客户获得服务收入。[United States Department of Justice](https://www.justice.gov/usao-ma/pr/cryptocurrency-financial-services-firm-gotbit-and-founder-sentenced-market-manipulation?utm_source=chatgpt.com)

两点尤其重要：

**刷量不等于持续拉升。**反复买卖可以制造很大的成交量，却没有多少净资金进入；持续抬高价格还需要其他条件。

**对刷量付费不等于刷量有真实投资需求。**费用是制造假象的成本，不能据此证明交易者有真实看涨信念。

你们测量时，可以观察资金是否循环、买卖是否高度协调、筹码与收益是否回到相同控制方。但共同资金来源也可能是交易所或公共服务，规律交易也可能是合法机器人。这些是线索，不是单条定罪规则。

识别出刷量，也不自动形成交易优势：它既可能出现在上涨前，也可能出现在出货阶段，还可能全程没有吸引到外部买家。

**3．内幕：先知道重要事实，等市场知道后兑现**

内幕优势的来源是信息。典型的信息包括尚未公开的上币决定、重要交易或项目决策。相关人可能因工作、合作或受托关系提前接触这些信息。

收益机制很直接：信息尚未被价格充分反映时建仓，信息公布后，其他参与者重新评估资产或开始交易，提前建仓者兑现。

Coinbase 的 Ishan Wahi 案中，他因工作接触保密上币信息，再向兄弟及朋友泄露，供其提前交易；他最终因电信欺诈共谋被判刑。这个案例的核心包括保密信息、职务信任以及向关联人泄露，不只是“公告前有人买了币”。[United States Department of Justice](https://www.justice.gov/usao-sdny/pr/former-coinbase-insider-sentenced-first-ever-cryptocurrency-insider-trading-case?utm_source=chatgpt.com)

因此，以下情况不能混为一谈：


| 情况                                   | 能否直接认定为违法内幕交易       |
| ---------------------------------------- | ---------------------------------- |
| 根据公开治理提案、公告、产品进展作推断 | 不能仅因推断正确就认定           |
| 买入后碰巧出现利好                     | 不能                             |
| 创建者知道自己计划何时发布项目消息     | 需要看具体行为，不能一概而论     |
| 员工滥用保密信息供自己或关联人交易     | 可能涉及内幕交易、欺诈或其他责任 |

链上能够显示“它在公告前买了”，通常不能直接显示“它为什么买、是否收到保密消息”。识别内幕需要交易时序之外的身份、信息来源和关系证据。

这类优势与服务器速度有一个根本区别：**如果对方提前几天知道事实，你把公开公告的接收时间缩短几百毫秒，仍然没有取得相同的信息条件。**公告后的快速反应是另一个可研究的问题。

**4．MEV：同一批交易，顺序不同，收益就不同**

MEV 是 *Maximal Extractable Value*，通常译作“最大可提取价值”：通过影响交易纳入、排除和执行顺序，在普通区块奖励与交易手续费之外获得价值。它是一组机制，不是单一策略，也不是“违法行为”的统一名称。[ethereum.org](https://ethereum.org/en/developers/docs/mev/?utm_source=chatgpt.com)

最常见的几类可以这样理解：


| 类型         | 运作机制                                           | 收益来源                       |
| -------------- | ---------------------------------------------------- | -------------------------------- |
| **套利**     | 在报价不同的市场买低卖高，或修正一次交易造成的价差 | 不一致的可成交报价             |
| **协议清算** | 按协议规则处理抵押不足的仓位                       | 清算奖励或抵押品折价           |
| **前置交易** | 让自己的交易先于目标交易执行                       | 顺序带来的价格或机会优势       |
| **后置交易** | 紧接某笔交易执行，利用其造成的新状态               | 交易后的价差或其他机会         |
| **三明治**   | 将自己的交易排列在目标交易前后                     | 目标交易遭受的部分额外执行损失 |

套利与清算不要求提前判断某个币会成为百倍币。例如，假设同一资产在两个市场的可成交价格是 100 和 102，毛价差为 2；若费用、冲击和排序成本合计 2.5，最终仍然亏损。看见机会与拿到净利润，是两回事。

三明治则利用目标交易本身的价格影响。在典型的 AMM 买单情形中，前面的交易先改变池子价格，使用户买得更贵；用户交易继续改变价格后，后面的交易撤回攻击者的仓位。用户通常得到更少的代币或更差的执行价。[ethereum.org](https://ethereum.org/en/developers/docs/mev/?utm_source=chatgpt.com)

不是所有“先买后卖”都是三明治。需要证明它围绕目标交易取得了顺序优势。新币早买狙击也可能与 MEV 重叠，但单纯提前买入、等待后来涨价，不足以说明它属于这种顺序提取。

MEV 的参与者也要分开：

- **搜索者**发现机会、构造交易，承担开发、费用和执行失败风险。
- **区块构建或交易排序服务**收集交易，选择能够纳入的组合。
- **验证者或出块者**执行并发布区块，取得相应费用或小费。

在 Jito 的机制中，搜索者提交捆绑，区块引擎进行拍卖和组合选择，验证者执行获选捆绑。因此，某笔机会产生的价值可能在搜索者、基础设施和验证者之间分配。[High Performance Solana Infrastructure](https://docs.jito.wtf/lowlatencytxnsend/?utm_source=chatgpt.com)

竞争的重要部分是：更早看到相关状态、更快计算、更可靠提交，以及愿意为排序支付多少成本。早期 MEV 原始研究已经记录了机器人通过提高交易费争夺执行顺序。竞争会侵蚀净收益，不能只看成功交易的毛利润。[arxiv.org](https://arxiv.org/abs/1904.05234?utm_source=chatgpt.com)

不同链的信息条件也不同。Solana 没有以太坊式的原生公开待处理交易池，私人订单流、已处理交易通知及区块数据传播，代表不同的信息阶段。**买到快速发送服务，不代表同时买到了最早的订单信息。**[Helius](https://www.helius.dev/blog/solana-mev-an-introduction?utm_source=chatgpt.com)

套利、协议清算、三明治及其他排序行为的法律性质需要分别判断，不能用“MEV”三个字完成合法性认定。

**这四类可以在一个币上叠加。**

例如，某个持货方知道即将进行的推广安排；协调交易制造活跃假象；宣传引来真实外部买盘；独立 MEV 机器人再围绕这些买单提取顺序价值。它们不一定属于同一团伙，却可能从同一批外部交易中获得不同收入。

所以，看到一个钱包盈利，至少要分清：

- 它的筹码以什么成本取得，是否从别处转入；
- 它赚的是方向上涨、价差、清算奖励，还是服务费；
- 盈利是否依赖保密信息或特定执行顺序；
- 外部观察者能否在自己的成交条件下取得同样结果。

对你们的账本，**“真实成交”“地址很多”“钱包盈利”都还不是选币能力的证明。**先把收入来源与优势机制归因清楚，才知道其中哪些值得学习，哪些需要完全不同的参与条件。
