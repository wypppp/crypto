## 0. 要回答什么（按顺序）

1. **参与本身值不值得**：一个真实身份、小本金参与 Alpha 积分空投和 HODLer 空投，扣全部费用后每月净得多少，趋势怎样（基础比率）。
2. **中文名币在可见之后是否还有带容量的右尾**：即 DQ-6 的 G0，改用 DQ-29 留存的数据零费用做。
3. **你的判断是否同时好于基础比率和机器基线**：判断日志，是 DQ-6 G1 前向盲评的扩展。

机制（清单第 7 条的统一问法）：
- 空投：付钱的是项目方的分发预算。问的是，我们能否以自己的成本（门槛、交易量成本、持币风险）拿到它，扣完是否为正。
- 右尾：信号出现之后，是否还有新的、独立的、尚未被定价的买盘（例如 Alpha → 永续 → 现货这条上币管线带来的买盘，或中文叙事的扩散）；我们能否以自己的成交价和成本吃到它。
