## 2. 与目标和背景的关系（请在裁决时一起看）

- **它不是右尾，也是机构充分参与的成熟玩法**。[背景.md](../../../背景.md) 写明不希望进入“机构资金、基础设施、信息系统、交易速度都远胜个人的成熟游戏”。总控的理由是：容量够、不拼速度、正偏，与你股市“右侧跟随”的经验同源。这是方向取舍，由你决定。
- **确认需要的年数取决于 Sharpe，不取决于交易次数**：各币趋势高度同步，交易多不等于独立样本多。要让年化净收益的 95% 区间下界 >0，Sharpe 1.5 约需 1.7 年数据，1.0 约 3.8 年，0.7 约 7.8 年。2024～2026 不到 3 年，只有 Sharpe ≥约 1.2 时才可能确认。
- **对 100 万目标的贡献取决于杠杆**（只作量级参考）：在理想化的几何布朗运动里，不计跳空、恒定 Sharpe、连续调仓，从 1 万出发 3 年内到达 100 倍的概率在最优杠杆下约为：Sharpe 0.5 时 5%，1.0 时 18%，1.5 时 46%。对应的年化波动约 200%，单币杠杆 4～7 倍。零优势时每笔 1 万不超过 1%。加密的跳空与连环清算（例如 2025-10-10）会让高杠杆下的实际概率明显更低。所以本卡在主统计量之外，用实际日收益做分块重抽样，报告不同杠杆下 3 年到达目标的概率（描述，不作读法）。
