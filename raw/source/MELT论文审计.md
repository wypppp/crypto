## 1. 审计结论

这篇论文是目前最接近候选 5“迁移前特征、时间留出、事后风险排序”的 Solana/Pump.fun 研究。它支持一个窄问题：

> 在已经确认迁移到 DEX 的 Pump.fun 代币中，迁移前行为轨迹是否能富集较低事后风险的代币？

它不支持以下扩大表述：

- 不支持“覆盖 Pump.fun 全部发行总体”；
- 不支持“追踪完整代币生命周期直至死亡”；
- 不支持“预测普通账户真实亏损”；
- 不支持“已经筛出可执行的极端赢家”；
- 不支持“策略具有正收益或提高账户 `P100`”。

论文的方法和数据声明足以进入复制审计，但不能把候选 5 升级为主研究线或实盘候选。

## 2. 文件与数据总体

### 2.1 论文报告的总体

论文第 2–4 页报告：

| 项目 | 论文报告值 | 证据标签 |
| --- | ---: | --- |
| 时间窗 | 2024-12-01 至 2025-03-01 | `F`：论文原文 |
| 检测到的已迁移代币 | 41,470 | `F`：论文报告；总体完整性为 `D` |
| 总交易 | 218,530,716 | `F`：论文报告 |
| 迁移前交易 | 30,833,503 | `F`：论文报告 |
| 迁移后第一小时交易 | 187,697,213 | `F`：论文报告 |
| 特征数 | 122 | `F`：论文报告 |

论文把完成创建、launchpad 销售、迁移和 DEX 交易四阶段的代币称作完成 four-stage lifecycle。这只表示样本到达四个阶段，不表示持续追踪到代币死亡；链上交易数据在迁移后只覆盖第一小时。

### 2.2 分母边界

41,470 个样本是论文迁移识别规则检测到的代币，不是窗口内全部 Pump.fun 发行。论文援引的外部说法是全部发行中不足 2% 能迁移。

因此：

- 若策略只在**确认迁移后**决策，所有确认迁移代币可以成为合理的条件总体；
- 若策略要在 bonding curve 或迁移前下注，只保留后来迁移的代币会产生严重事后条件化；
- 论文没有用独立 Pump.fun 总账验证迁移识别规则的召回率；异常迁移或 fee-account 规则变化是否漏检仍为 `D`；
- “论文报告检测到 41,470 个迁移样本”为 `F`，“已经证明这是完整迁移分母”为 `D`。

## 3. 标签审计

论文第 5–6 页的标签核心是迁移后的最低价格比率：

\[
min\_price\_ratio=\frac{\text{迁移后 20 分钟内最低观察价格}}{\text{迁移价格}}
\]

规则包括：

- 高风险：`min_price_ratio < 0.3`，或人工审查判为 manipulated；
- 低风险：`min_price_ratio >= 0.7` 且未被判为 manipulated；
- 其他落入中风险；
- 对部分边界样本，作者使用 GMGN 中的完整迁移后价格量轨迹作人工判断。

论文报告的完整迁移样本标签为：

| 标签 | 数量 | 比例 |
| --- | ---: | ---: |
| 高风险 | 34,890 | 84.13% |
| 中风险 | 4,702 | 11.34% |
| 低风险 | 1,878 | 4.53% |

这些标签不是普通账户实际成交盈亏，原因包括：

1. 最低观察价格是路径极端点，不是按给定数量卖出后的可退出净值；
2. 迁移价格不等于普通账户确认信号、计算特征并发送交易后的入场价；
3. 人工 manipulated 标签没有报告盲法、多人一致率或完整标注协议；
4. 实验把中风险与低风险合并为 normal，中风险仍可能经历显著下跌。

因此准确主张是“迁移前特征预测一种事后轨迹风险标签”，不是“预测普通买家真实亏损”。

## 4. 特征与点时可得性

论文第 4–5 页声明 122 个特征严格来自创建到迁移之间，主要包括：

- 时间与 SOL 市场环境；
- 开发者、早期买家和 top-k 持仓集中度；
- 交易数量、用户数、成交量和 wash-trade 痕迹；
- bundle 聚类后的集中度和关联关系；
- 迁移前价格量序列。

没有在 PDF 中发现直接把迁移后价格作为输入特征的证据。但“定义上属于迁移前”不等于“首个 DEX 可交易价格出现前能实时取得”：

- Jito bundle ID 是后来从 Jito Explorer 批量取得；
- funding-address 关系和 CEX 地址排除没有点时版本说明；
- 模型需要等迁移前阶段完成后计算聚类与全部特征；
- 论文没有测量区块确认、抓取、解析、推理和发单延迟。

证据标签应为：

- `F`：论文声明并按定义使用迁移前信息；
- `D`：这些字段能否在实盘决策截止前完整、稳定地取得。

## 5. 样本排除

论文第 7 页在建模前又排除：

- launchpad 销售时间少于 1 分钟的代币；
- 迁移时持有人少于 100 的代币。

排除结果：

| 项目 | 数量或比例 |
| --- | ---: |
| 被排除样本 | 19,835 |
| 占全部迁移样本 | 47.8% |
| 被排除样本中的高风险比例 | 约 95% |
| 最终建模样本 | 21,635 |
| 最终样本高风险 | 16,048，74.18% |
| 最终样本 normal | 5,587，25.82% |

这两个过滤条件在迁移确认时原则上可见，可以成为合法的 eligibility filter；但必须把被排除者作为“规则明确拒绝”的样本完整报告。准确表述是：

> 模型在先剔除近一半明显高风险迁移币后，对剩余迁移币继续排序。

不能表述为模型覆盖全部迁移币。

## 6. 时间切分与分类表现

论文第 8 页报告：

- 按代币创建时间排序；
- 前 70% 训练，后 30% 测试；
- 超参数在训练集内五折交叉验证；
- 表中结果为五次随机运行的平均值。

这是有效的单次未来留出，优于随机切分，但仍有局限：

- 窗口只有三个月，只有一个 70/30 时间边界；
- 五次运行是随机种子重复，不是五个独立时期；
- 训练集五折是否保持时间顺序没有说明；
- 多个模型共享同一测试集后再选择最佳模型；
- 没有第二个最终确认窗口；
- 表格没有完整标准差、置信区间或显著性检验。

Table 8 的主要结果：

| 方法 | AUPRC | macro-F1 |
| --- | ---: | ---: |
| 随机基线 | 0.2589 | 未作为同类模型报告 |
| MLP | 0.5729 | 0.6981 |
| MLP + LSTM | 0.5827 | 论文报告的最高 AUPRC |
| MLP + RF | 未在本审计单列 | 0.7037 |

随机 AUPRC 接近 normal 类比例，说明 AUPRC 很可能把 normal 当 positive；正文又把任务描述为检测 high-risk，类别方向需要通过代码和标签映射确认。

复制必须报告：

- AUPRC 相对类别基率；
- precision、recall、混淆矩阵和校准；
- 随机种子方差及时间切分不确定性；
- 按 developer、资金来源或 bundle entity 分组后的有效样本数；
- 新时间窗口中的真正前向结果。

## 7. Table 10 与交易模拟

### 7.1 排序方向矛盾

第 9 页正文称按 predicted risk score **descending** 排序后取 top-k。前文又定义 high-risk 为 label 1。若按高风险概率降序，理论上应选出最危险的代币；但 Table 10 把 precision 定义为 top-k 中 non-high-risk 的比例，并报告模型把该比例提高到 80%。

可能的解释是代码实际按 normal 概率降序或 risk 概率升序，而正文写反。在检查固定 commit 的代码前，Table 10 的排序实现为 `D`。

### 7.2 论文报告结果

| 方法 | Top-100 normal 比例 | Top-100 平均损失 | Top-200 normal 比例 | Top-200 平均损失 |
| --- | ---: | ---: | ---: | ---: |
| 随机 | 25.4% | 60.71% | 26.5% | 64.84% |
| MLP | 80.0% | 26.64% | 75.5% | 31.47% |

这说明模型在论文口径下显著富集 normal 标签并减少理想化平均损失，具有防御性筛选价值；最佳报告结果仍是负损失，不证明正收益。

### 7.3 不可执行因素

论文模拟不能当作交易回测：

1. 在完整未来测试总体结束后统一排名再取 top-100/top-200，线上无法知道当前代币会不会属于未来总体 top-k；
2. 假设按迁移价格立即买入，没有确认、计算和发单延迟；
3. 在后一小时随机抽取 100 个时间点计算卖出，没有固定实时退出规则；
4. 没有 bid/ask、AMM 冲击、手续费、priority fee、Jito tip、MEV 和失败交易；
5. 没有同时持仓、资金占用和资本循环；
6. 没有 10,000、100,000、500,000 和 1,000,000 元财富层的入场/退出容量；
7. 没有收益分布、极端赢家命中、可退出净值或账户 `P100`。

复制时必须使用训练期冻结的分数阈值或仅依赖当时历史的滚动排名，不能复用完整未来总体 top-k。

## 9. 对候选 5 的影响

论文将“迁移前行为包含可预测风险信号”从纯假说提高为有单次时间留出支持的 `H`。它没有证明：

- 全发行总体的完整分母；
- 普通账户按真实深度可执行的正 Edge；
- 极端赢家的排序增量；
- 可承载财富增长的容量；
- `P100` 高于随机、`B1` 或 1%。

候选 5 因此只升级为：

> 次级窄口径复制线：验证已确认迁移总体中，迁移前风险特征在真实延迟和 AMM 执行后是否仍有增量，再单独检验是否帮助收益右尾。

它不取代候选 4 的首选证伪项目，也不进入实盘队列。

## 10. 外部毕业率主张

“Pump.fun 毕业率从 2025 年 9–10 月约 0.63% 降至 2026 年 5–6 月约 0.198%”不来自本论文，当前没有本地原始计数或一致口径，记为 `D`。

核验前至少需要：

- 每个窗口的发行分母和迁移分子；
- 相同的创建、毕业和目标 DEX 定义；
- 相同 Pump.fun 合约与机制版本；
- failed、重复及替代迁移路径的处理；
- 绝对迁移数/日，而不只是比例。

即使比例下降得到确认，它首先影响机会频率、类别基率、concept drift 和策略半衰期。若总发行量上升，绝对迁移机会未必同步下降；该数字本身不证明 Edge 变好或变差。
