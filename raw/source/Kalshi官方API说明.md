# Kalshi Official API
- Base: https://api.elections.kalshi.com/trade-api/v2 (prod), https://external-api.kalshi.com/trade-api/v2 (new host)
- Docs: https://docs.kalshi.com/api-reference (blocked by policy but SDK shows)
- Endpoints:
  - GET /markets - list markets
  - GET /markets/{ticker} - full detail prices, volume, rules, expiration
  - GET /markets/{ticker}/orderbook - live order book per price level depth
  - GET /markets/trades - executed trades all markets or one ticker
  - GET /historical/trades - historical trades
  - GET /markets/candlesticks - historical OHLC (1min/1h/1day)
  - GET /historical/markets - archived settled markets
- Earliest: varies per market, trade-api v2 since 2021
- Fields: ticker, price in cents 1-99, volume, open_interest, rules, expiration, orderbook levels
- Real L2? Live orderbook yes, historical L2 No - only trades + candles, no historical depth archive. Must poll and store yourself.
- Queue: No
- Rule version: rules field in market detail, no diff history
- Settled: yes via /historical/markets
