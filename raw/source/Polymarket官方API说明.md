# Polymarket Official API
- Gamma API: https://gamma-api.polymarket.com - market metadata, events, tags, search, resolution history
- CLOB API: https://clob.polymarket.com - live orderbook, prices, trades, order management (public endpoint no auth for book)
- Data API: https://data-api.polymarket.com - account and market activity, historical prices
- Docs: https://docs.polymarket.com/ - Overview, Core Concepts, SDKs
- Earliest date: per market creation, no global earliest; historical prices endpoint /prices-history and /batch-prices-history
- Fields: token_id, outcome, price, bestBid/bestAsk (Gamma), book levels (CLOB /book)
- Real L2? Live yes, historical No - only current book. Historical L2 must be synthesized via trade-event + price-history (third-party polymarket-data lib does hybrid reconstruction)
- Queue: No queue position, no historical queue
- Rule version: market rules in Gamma /events, no version diff archive; rule changes observed (Strategy market)
- Settled markets: Gamma includes closed/resolved markets with resolution
