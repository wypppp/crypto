# 结构性 Alpha 与百倍收益综合研究框架 v1.0

> 创建日期：2026-08-13  
> 研究对象：加密资产、预测市场及相关事件型交易  
> 使用者约束：初始验证资金 1 万元；按用户提供的前提，有海外身份和合规交易路径；研究时间充足；具备 CS/LLM 能力；可人工响应约 07:00–22:00；没有依赖共址、专线、私有订单流或区块构建的 HFT/MEV 基础设施  
> 文档定位：整合此前关于 A–E、百倍币、公开中文信息差、危机预警和凸性事件的讨论，形成候选方向、证伪标准与研究优先级。它不是收益承诺、交易信号或实盘仓位方案。  
> 证据纪律：本文对方向的评分是研究前先验，不是已经验证的策略结果；任何具体机会仍须回到当时可得的一手资料、真实报价和本人可执行路径。

## 1. 执行摘要

### 1.1 最终判断

在当前约束下，值得寻找的不是“哪个市场最容易上涨”，而是：

> **哪些市场存在由硬权利、强制行为、绑定规则或公开信息传播摩擦产生，并且普通速度参与者仍可执行的结构性错价？**

综合优先级不是简单的 A、B、C、D、E 单项排名，而是下列**有时间上限的研究顺序**。它不是预期收益率排名，也不是实盘资金配置：

1. **第一优先：`C+B` 交叉机会**  
   通过第 4.2 节六问门槛的强制流制造偏离，硬结算、赎回或转换权提供本人可执行的终值；两条腿缺一不可。
2. **第二优先：D 的窄域公开信息与规则/逻辑子类**  
   尤其检验涉及中国的公开中文原始来源是否产生分钟至小时级的可成交延迟，以及规则语义和跨市场逻辑是否存在可执行的不一致。这是优先验证的假说，不是已知优势。
3. **第三优先：非 MEV 的纯 B 与 `A+B`**  
   数量、时间、场所和执行方式明确的强制处置，或不可撤销并必须在公开市场执行的回购/供应变化。
4. **第四优先：纯 C**  
   最容易建立终值约束，但通常收益、频率和容量有限；更适合验证正期望，不天然适合冲击百倍。
5. **第五优先：绑定 A 与“百倍币候选排序”**  
   可以研究，但前者往往缺少强制收敛，后者极易受幸存者偏差和退出流动性影响。
6. **E 永久保留为基准**  
   BTC/ETH 持有、日线趋势、Carry 和现金不是“次等方向”，而是所有复杂研究必须击败的机会成本。

### 1.2 必须同时接受的两个结论

- **可重复正期望可能存在**：尤其可能出现在复杂、小容量、执行麻烦、规则驱动且机构不愿覆盖的机会中。
- **没有任何方向已被证明能让 1 万元在 0–3 年内可重复地变成 100 万元**：100 倍只能作为账户收益分布的极端右尾，不能作为筛选策略是否合格的第一门槛。

“最容易证明正期望”和“最容易出现单次百倍标的”通常方向相反：

| 目标 | 相对领先的候选 |
| --- | --- |
| 最容易验证终值与净 EV | C、C+B |
| 最可能产生中低频事件 Alpha | B、窄域 D、A+B |
| 单一标的/合约右尾最大 | 小市值 A、D 长尾、危机期权 |
| 最容易稳定扩容 | E、部分头部 D/Carry，但收益率通常更低 |
| 最匹配 CS/LLM 信息工程 | C、B、窄域 D、绑定 A |
| 最适合 1 万元做验证 | D、小容量 C/B、纸面 A；不一定适合司法拍卖/RWA 大额赎回 |

因此，本项目的正确目标是：

> **先证明一个小规模净正期望机制存在，再检验频率、容量和几何增长；百倍只作为模拟输出，不作为研究输入。**

### 1.3 为什么不同大模型会给出相反排名

这些回答通常不是在估计同一个目标函数：

| 分歧来源 | 典型结果 |
| --- | --- |
| 把“最容易证明净正期望”放在首位 | C 或 C+B 排第一 |
| 把“单笔右尾最大”放在首位 | D 长尾或小市值 A 排第一 |
| 把“技能匹配”直接当成 Alpha | 高估 LLM 预测和治理文本扫描 |
| 把 D 当策略、把 A–C 当机制 | 对不在同一层的类别强行排序 |
| 用著名成功案例代替完整候选总体 | 高估百倍币、危机预测和强制流胜率 |
| 忽略资格、容量、真实报价与失败状态 | 把纸面价差误写成可执行套利 |
| 混淆标的、仓位和账户收益倍数 | 把小仓 100 倍误写成账户 100 倍 |

因此，三个模型各自可能抓住了一个真实侧面，但它们给出的星级和“20%–100% 单次收益”“胜率大于 85%”之类数字，在没有完整样本、点时数据和执行成本前都只是叙事性先验。本文吸收其机制假说，不继承其未经验证的收益数字；最终比较单位必须是**具体子类或具体机会**，并统一通过第 7 节的六轴评分和第 10 节的验证协议。

前述回答中以下推断不能直接继承：

| 叙事性跳步 | 缺失的关键证明 |
| --- | --- |
| 钱包转入交易所 = 实际出售 | 最终受益人、内部调拨、真实成交和执行场所 |
| 解锁 + 低成本筹码 = 强制出售 | 法律/资金约束、持有人异质性和实际净流量 |
| 极端资金费率 = 人工可接清算针 | 触发时间、订单优先级、跳空路径和反转终值 |
| 合约有 `redeem()` = 可验证硬底 | 本人权限、资产足额、暂停/升级权、队列和失败回收 |
| fee switch 通过 = 自动回购销毁 | 实际接收人、执行代码、预算、撤销权和净排放 |
| 低价预测合约 + 自信概率 = 10–50 倍机会 | 概率校准、结算尾险、真实 ask 深度和 Kelly 仓位 |
| 1 万元在预测市场没有流动性约束 | 长尾逐档深度、冲击成本、退出和独立机会数量 |
| C 可稳定赚 5%–10%、胜率超过 85%，可加杠杆 | 完整事件总体、失败状态、锁资时间和杠杆清算路径 |

## 2. 统一概念：避免再次把四种“倍数”混在一起

### 2.1 四种收益口径

任何案例和实验必须明确使用哪一种口径：

| 口径 | 定义 | 常见误用 |
| --- | --- | --- |
| 标的收益倍数 | 标的卖出价 / 买入价 | 用事后最低价到最高价，忽略当时容量和退出 |
| 仓位收益倍数 | 某一仓位终值 / 该仓位成本 | 把 5% 仓位的 100 倍写成账户 100 倍 |
| 账户收益倍数 | 账户最终净值 / 初始净值 | 忽略其他仓位、亏损、再平衡和税费 |
| 已实现终值 | 实际成交、提现和结算后的财富 | 用盘中峰值、未实现 P&L 或不可提现余额代替 |

若账户比例 `f` 投入一个最终变为 `M` 倍的标的，其余资金不变，则账户终值为：

\[
W_1=(1-f)+fM
\]

几个关键例子：

| 仓位 | 标的终值 | 账户终值 |
| ---: | ---: | ---: |
| 1% | 100 倍 | 1.99 倍 |
| 5% | 100 倍 | 5.95 倍 |
| 10% | 100 倍 | 10.9 倍 |
| 5% | 20 倍 | 1.95 倍 |

一笔 5% 彩票仓若要单独把账户推到 100 倍，标的需要约 1,981 倍；1% 仓位则需要约 9,901 倍。以后禁止使用“小仓中一张 100 倍票，所以账户可百倍”的说法。

### 2.2 算术正期望不等于可复利

单笔策略的算术期望为：

\[
EV=\sum_i p_i\left(R_i^{gross}-C_i\right)
\]

但长期复利更关心期望对数增长：

\[
g(f)=\sum_i p_i\ln(1+fR_i^{net})
\]

其中 `C_i` 包含状态 `i` 下的手续费、滑点、资金成本以及执行与失败成本；`R_i^{net}=R_i^{gross}-C_i`，`f` 是账户风险比例。若任一可能状态使 `1+fR_i^{net}\le 0`，对应的对数增长为负无穷，意味着该仓位允许账户归零或穿仓。一个策略可以算术期望略正，却因偶发大亏导致 `g(f)<0`。高胜率 C、Carry、卖波动率和接强制卖盘尤其容易出现这种情况。

因此，“正期望”至少分四级：

1. **机制上可能为正**：能说明谁付钱、为什么机会可能存在。
2. **样本算术期望为正**：历史或前向样本扣除成本后盈利。
3. **净期望下置信界为正**：考虑估计误差后仍不能轻易归因于运气。
4. **账户几何增长为正且可扩容**：包含仓位、相关性、尾部损失和容量后仍成立。

只有第四级才有资格讨论长期复投。

本文所称“可重复”，也不是指事后能讲出多个相似故事，而是同一套事前冻结的入选、估值、执行和退出规则，在多个有效独立机会中扣除全部成本后仍成立。若利润主要来自一个极端赢家，只能说明存在右尾，不能说明机制可重复。

### 2.3 凸性、正期望和百倍是三件事

- **凸性**：损失有限、潜在收益很大，是支付结构。
- **正期望**：概率加权收益扣成本后大于零，是定价判断。
- **账户百倍**：整个账户终值达到初始值的 100 倍，是仓位和路径结果。

一张 1 美分、最终可能支付 1 美元的合约具有 100 倍毛支付，但若真实概率不高于成本调整后的 1%，它不是正期望；即使它正期望，若只配置 1%，命中一次也只让账户接近翻倍。

即使主观真实概率为 2%，以 1 美分买入在无费用模型中具有正算术期望，其理论 Kelly 仓位也只有 `(0.02-0.01)/(1-0.01)\approx1.01%`；全仓下注仍有 98% 的概率归零。高赔率与高合理仓位恰恰不是一回事。

### 2.4 百倍的时间约束

1 万元到 100 万元需要 100 倍。若无追加本金：

| 完成时间 | 所需年化复利 |
| ---: | ---: |
| 1 年 | 9,900% |
| 2 年 | 900% |
| 3 年 | 约 364% |
| 5 年 | 约 151% |
| 10 年 | 约 58.5% |

若每次都无亏损、无成本且全额复投：

| 单次净收益 | 达到约 100 倍所需次数 |
| ---: | ---: |
| 3% | 156 次 |
| 5% | 95 次 |
| 10% | 49 次 |
| 20% | 26 次 |
| 50% | 12 次 |
| 100% | 7 次 |

现实中还有亏损、锁资、空仓、机会相关性、容量下降和税费。因此“收益率 × 几次复利”的演示只能作为上限，不是预测。

## 3. 统一分类：A–E 不在同一层

| 类别 | 本质 | 它能提供什么 | 它不能自动提供什么 |
| --- | --- | --- | --- |
| A 绑定规则 / Tokenomics | 改变供应或价值分配规则 | 估值输入、潜在催化剂 | 强制买卖、价格收敛 |
| B 真实强制流 | 价格不敏感主体必须交易 | 可预测订单流和流动性冲击 | 资产终值、必然反转 |
| C 硬结算 / 赎回 / 转换 | 本人可执行的终值权利 | 价格锚和收敛边界 | 履约无风险、无限容量 |
| D 中低频预测市场 | 交易场所与支付载体 | 信息、规则和逻辑错价的变现 | Alpha 本身 |
| E 基准 | 市场暴露或风险溢价 | 机会成本、现金管理、对照收益 | 0–3 年账户百倍 |

D 不是独立收益机制。一个预测市场交易仍须回答它靠什么赚钱：公开信息预测、规则结算、跨市场逻辑约束、强制流，还是做市。A、B 也可以发生在 D 中；只有 complete-set、同一索赔权的固定转换/赎回，或覆盖全部状态后已经锁定支付的结构才同时属于 C。单个二元合约“事件发生则支付 1 美元”只是条件支付，不是交易时已有的硬终值。

## 4. 核心方向评估

### 4.1 C：硬结算、赎回与固定转换

#### 收益机制

市场价格低于本人实际可实现的贴现结算价值。为避免把失败、延期和状态相关成本塞进一个平均数，按完整状态计算：

\[
EV_C=\sum_s p_s\left(\frac{V_s}{(1+r)^{T_s}}-C_s\right)-P_{buy}
\]

其中：

- `s` 覆盖正常履约、延期、暂停、折价回收和完全失败等状态；
- `p_s`：状态概率；
- `V_s`：该状态下结算资产的实际可兑现价值；
- `T_s`：该状态下锁资时间；`r` 是与 `T_s` 使用同一时间单位的机会成本率；
- `C_s`：该状态下的手续费、Gas、滑点、对冲、税务、提现和平台成本；
- `P_buy`：当时真实可成交的购买成本。

#### 真正的硬权利检查表

只有以下问题全部得到明确答案，才能称为 C：

1. 当前买入者本人是否有权调用，而非仅限发行商、授权商户或做市商？
2. 司法辖区、KYC、白名单、最低金额和账户历史是否满足？
3. 比例、结算资产、时间、优先级和截止日是否明确？
4. 资产是否足额、隔离并可独立验证？
5. 是否存在暂停、黑名单、代理升级、多签或治理修改权？
6. 是否有赎回队列、日限额、债务上限或库存上限？
7. 结算资产是否本身波动、脱锚或缺乏流动性？
8. 等待期间是否需要对冲，是否会在终值兑现前被杠杆清算？
9. 若失败，回收是多少、要等多久、由谁承担损失？
10. 机会是否依赖同区块原子交易、MEV 排序或抢兑？

#### 适合研究的子类

- 固定比例、长窗口的代币迁移；
- 明确截止日的 tender / 回购要约；
- 权限开放、储备可验证的赎回；
- 协议关闭后的剩余资产分配；
- 可标准化的小额索赔权或困境资产；
- 复杂但个人可完整执行的跨场所转换。

#### 主要误判

- 合约存在 `redeem()` 不等于本人可调用或资产足额；
- 1:1 转换关系不等于美元硬底，若结算资产也会波动；
- 封装资产和桥接资产的数量对应关系不等于无信用风险；
- 高折价通常意味着资格、偿付、暂停、队列或法律风险，而不是“更好的免费套利”；
- 终值有锚不能保护使用杠杆者免受中途清算。

#### 初始结论

**最适合验证净正期望，通常不适合单独承担百倍目标。**很多此类机会收益有限，并可能呈“小赚多次、偶发大亏”的负偏态；未经失败分布验证，不使用杠杆。

### 4.2 B：真实强制流

#### 收益机制

某主体因法律、合同、保证金、负债、赎回或治理约束，必须在有限时间内交易，且对价格不够敏感。研究优势来自对以下变量的更准确估计：

\[
\text{价格冲击}\approx f\left(\frac{\text{净强制流量}}{\text{当时可执行深度}},\text{时间窗},\text{执行算法},\text{市场预期}\right)
\]

#### 六问门槛

1. 谁必须交易？
2. 哪条法律、合同或资金约束使其不能选择不交易？
3. 数量是多少，是否只是最大可能量？
4. 何时开始、何时完成，能否延期？
5. 通过订单簿、TWAP、OTC、拍卖还是内部撮合？
6. 相对于事前可见深度和自然成交量，规模究竟多大？

答不全时，钱包转移、解锁、债权人收币、极端资金费率都只能作为线索，不能作为交易触发。

#### 适合研究的子类

- 数日到数周执行、公开进度可观察的困境处置；
- 数量、截止日和资格明确的小额公开拍卖；
- 基金赎回、债务偿付或资产转换导致的明确再平衡；
- 固定预算、时间表和公开执行地址的持续回购；
- 卖压完成状态可以观察的事件后反转。

#### 首轮排除的子类

- 数秒或数个区块内完成的链上清算；
- mempool、builder、keeper、预言机更新抢跑；
- 突发新闻后的即时 CEX 清算瀑布；
- 只有大额合格买方才能参与的司法/OTC 交易；
- 把“解锁”“转入交易所”或“获分配”直接等同于公开市场卖出。

#### 两种不同交易

1. **提前交易强制流**：方向空间较大，但容易已被定价、拥挤或执行改道。
2. **确认流量完成后交易反转**：响应要求较低，避免借币和挤仓，但需要独立终值判断。

第二种可能更适合没有 HFT 的个人，但不能假设所有强制卖压结束后都会反弹。

#### 初始结论

**潜在收益高于纯 C，但属于概率型事件研究，不是套利。**“对方必须卖”不等于“会以低于价值的价格卖给我”，更不能推出高胜率、20%–100% 单次收益或应当重仓。

### 4.3 A：绑定规则与 Tokenomics

#### 收益机制

A 改变资产未来的供应、现金流分配或需求，但通常不直接创造价格收敛。研究对象应从泛治理缩窄为 **Binding Mechanism Change**。

#### 可进入候选池的条件

- 治理已经通过，而非论坛讨论或 temperature check；
- 已进入 timelock 或代码已经部署；
- 生效区块、参数、预算和持续时间明确；
- 管理员、紧急委员会和后续治理不能轻易撤销，或撤销概率已计入；
- 经济量能相对于流通市值、自然成交和排放进行计算；
- 价值最终传给代币持有者，而非只进入协议金库；
- 市场价格在当时真实可成交，且事件并未被完全提前定价。

#### 子类判断

| 子类 | 初始判断 |
| --- | --- |
| 外部资产手续费直接分配给持有人 | 较强，但需核索取权和治理可改性 |
| 固定预算公开市场回购 | 升级为 `A+B`，优先级提高 |
| 固定比例赎回/迁移 | 升级为 `A+C` |
| 销毁未流通金库代币 | 通常不产生现实买盘 |
| 本币质押高 APY | 常是持币人之间重新分配稀释 |
| 降低排放 | 只有原接收者确实持续卖出时才减少卖压 |
| 公开已久的固定减半 | 确定性高，但通常更早被定价 |
| 一般治理提案、社区情绪 | 只作线索，不进入交易账本 |

#### 初始结论

**研究流程与 CS/LLM 很匹配，但 A 单独的正期望可信度低于 C/B。**A 最有价值的作用是生成 `A+B` 或 `A+C` 候选，而不是“发现提案就买入”。

---

### 4.4 D：中低频预测市场

#### D 不是一种策略

必须分成四本独立账：

| 子类 | 预测/交易对象 | 初始优先级 |
| --- | --- | --- |
| 信息 Alpha | 现实事件发生概率 | 中高，限窄领域 |
| 规则/结算 Alpha | 平台最终如何裁决 | 中高，容量通常低 |
| 跨市场逻辑/相对价值 | 支付状态之间是否矛盾 | 中高，但执行复杂 |
| 被动做市 | 价差能否覆盖知情流和库存风险 | 低，首轮排除 |

#### 信息 Alpha

预测市场不能只用 `q-a` 表达所有状态，因为取消、退款、部分支付、冻结和延迟可能改变支付与资金占用。以实际 ask `a` 买入时，统一写成：

\[
EV_D=\sum_s p_s\left(\frac{Payoff_s}{(1+r)^{T_s}}-C_s\right)-a
\]

其中 `s` 至少覆盖 YES、NO、取消/退款、部分支付及冻结/延迟；`p_s`、`Payoff_s`、`T_s` 和 `C_s` 均以平台最终支付状态为准。只有在保守概率区间和不利成本情景下，净 EV 下界仍为正，才进入候选。模型与结算不确定性应体现在状态概率和支付情景中，只计一次。若确实是无取消、立即按 0/1 固定支付的简单二元合约，该式才退化为扣除成本后的 `q-a`。

通用新闻和通用 LLM 输出几乎都是市场共有信息。真正可能的优势来自：

- 独特但合法的数据采集；
- 原始公共记录覆盖；
- 小语种/地区信息源；
- 更好的基准率和概率校准；
- 对行政、司法或技术流程的专业理解；
- 市场尚未充分覆盖的窄领域。

#### 规则/结算 Alpha

需要逐字核对：

- 题目版本、截止时间和时区；
- 指定官方来源；
- 阈值、平局、修订、延期和取消；
- 争议、申诉、预言机和平台自由裁量；
- 市场冻结、退款和资金占用。

“现实中发生了”与“平台最终支付 YES”不是同一个随机变量。含“宣布、控制、启动、停火”等解释性词语的市场尤其可能是在出售裁决尾险。

#### 跨市场逻辑与期权比较

同一新闻标题不代表同一支付状态。跨平台只有在事件定义、截止时间、结算源、取消规则和资金可达性完全一致时才接近套利。

普通 vanilla 期权价格也不能直接当作事件概率。它对应连续支付，包含风险中性分布、波动率偏斜、期限和风险溢价。只有严格映射支付状态，例如用窄 call spread 近似数字支付后，才可以研究相对定价；“两个隐含概率相差 2–5 倍”本身不证明正 EV。

#### 容量矛盾

- 头部市场流动性好，但专业资金、机器人和媒体覆盖强，edge 通常小；
- 长尾市场可能错得更多，但真实 ask 深度、退出和独立机会数量有限；
- 1 万元对头部市场可能很小，对长尾某档盘口却仍可能造成明显价格冲击；
- 从 1 万扩容到 50 万时，策略可能被迫进入更有效率的市场。

周转同样是硬约束。若每一元实际部署资金的净算术 edge 为 5%，要获得 99 万元的**期望利润**，累计有效下注额约需 1,980 万元；edge 为 10% 时仍约需 990 万元。复投会改变每期账户规模，但不会消除对大量独立机会、资金周转和可成交容量的需求。这个计算不是收益预测，只用于驳斥“二元合约有高赔率，所以小本金自然容易百倍”的直觉。

#### 初始结论

在海外身份和合规路径成立的前提下，**D 是正式候选，而不是只做纸面观察的方向**。但优先研究窄域公开信息、规则语义和逻辑约束，不做泛政治/战争爆点、直播体育、瞬时套利和手工做市。

### 4.5 E：基准与现金管理

| 基准 | 作用 | 主要风险 |
| --- | --- | --- |
| BTC/ETH buy-and-hold | 长期 Beta/风险溢价零假设 | 高波动、周期回撤、托管 |
| BTC/ETH 日线趋势 | 主动策略基准、减少部分大回撤的候选 | 样本少、震荡磨损、参数过拟合 |
| Carry / 期现 / 资金费率 | 中性收益候选和闲置资金比较 | 基差、负费率、单腿、平台、抵押品 |
| 法币/短债现金 | 保留选择权和危机弹药 | 通胀、汇率、账户限制 |
| 稳定币/RWA | 加密内部资金停泊 | 发行人、银行、赎回、链和平台风险 |

E 的任务不是提供百倍，而是回答：复杂策略扣掉时间、费用、尾部和资金占用后，是否真的优于简单暴露。

每个实验至少比较：收益、最大回撤、波动、Beta、资本占用、尾部损失和研究时间。趋势和 Carry 也不能先验写成正期望，必须在具体市场、样本和成本下检验。

## 5. 四个扩展研究假说

### 5.1 公开中文信息传播 Alpha

#### 必须与内幕消息分开

| 信息类型 | 处理规则 |
| --- | --- |
| 公开中文官方文件、公告、法院和地方数据 | 可研究、可交易，保存原文和首次公开时间 |
| 任何人可合法购买的数据库/公开付费源 | 可研究，记录许可和获取成本 |
| 自行合法开展的调查、访谈、民调 | 可研究，遵守数据、保密和市场规则 |
| 中文社交平台公开传言、截图 | 仅作线索，不作事实触发 |
| 相关员工、官员、军人、候选人等私下提供的未公开事实 | 不交易，隔离并记录来源边界 |
| 付费购买泄密或诱导内部人员提供消息 | 明确排除 |

海外身份和平台准入不会自动使非公开重大信息交易合法。证券、商品、博彩/事件合约、保密义务、国家秘密、平台条款和账户追缴风险彼此独立。

#### 真正可能的优势

“会中文”本身不是壁垒，自动翻译早已普及。可能的优势是：

- 知道应该去哪个原始机构和数据库查；
- 对中国机构、公司、人物、地名做准确实体消歧；
- 区分受理、立案、征求意见、审议、批准、公布和生效；
- 识别正式文件、记者转述、自媒体二次加工和伪造截图；
- 将中文事实精确映射到英文结算条款；
- 在英语信息扩散和市场重定价前仍有可成交窗口。

#### 前向实验

1. 事前固定人工策略的可响应窗口为 `07:00–22:00 Asia/Shanghai`；窗口外事件仍采集数据，但交易账本一律记为 `No trade`。只有已经部署、实测并单独版本化的自动执行系统，才可建立另一套全天策略，不能在回测中预支它。
2. 事前枚举所有涉及中国且规则清晰的市场，禁止只挑后来有行情的事件。
3. 保存规则全文、版本哈希、官方结算源和市场状态。
4. 保存第一条中文原始来源 URL、发布时间、抓取时间和内容哈希。
5. 保存第一条主要英文来源及相同时间字段。
6. 记录中文源出现后 `1/5/10/30/60` 分钟真实 bid/ask、逐档深度和成交。
7. 纳入假消息、无反应、反向结算、无法成交和 No trade。
8. 在可响应窗口内比较立即交易、延迟 10 分钟、延迟 30 分钟和不交易。
9. 输出净 P&L、Brier/log score、最大回撤、容量和信息领先时间分布。

若中文源领先但价格在可操作前已变化，它只有信息价值，没有交易价值。

---

### 5.2 危机预警：寻找“下一个 FTX/UST”

这是可研究的预警问题，不是“看见几个链上异常就做空”的策略。

#### 可观察信号候选

- 储备资产与负债口径差异；
- 赎回速度、排队和折价；
- 抵押品循环、关联方集中和期限错配；
- 跨协议借贷堆叠与清算距离；
- 交易所/发行人地址异常流出；
- 审计、证明储备和法律实体披露质量；
- 借币费、期权偏斜、永续基差与现货脱节。

#### 必须补齐的分母

- 所有触发预警但没有倒闭的主体；
- 从首次信号到事件的真实领先时间；
- 当时是否有可借资产、可成交 put 或可靠交易场所；
- 交易成本、挤仓、跳空和资金费率；
- 危机主体与交易平台是否为同一对手方；
- 平台倒闭后盈利是否能够提现。

正确问题是：

> 一个事前冻结的公开危机评分，能否以可接受的假阳性率，预测未来 30/90/180 日相对于 BTC 或同类资产的大幅下跌，并且当时存在可执行工具？

没有完整假阳性样本前，不得用 UST、FTX 等著名案例宣称系统有效。

---

### 5.3 “下一个百倍币”：从圣杯改成候选排序

#### 为什么不能预测唯一赢家

- 标签极稀疏且市场非平稳；
- 成功项目留下数据，跑路、退市和无流动性项目消失；
- 项目可操纵开发者、用户、TVL 和社交指标；
- 极早价格常没有普通账户可成交容量；
- 代币上涨不等于可以在峰值退出；
- 公开有效模型会因买盘提高入场价而衰减。

#### 可研究的替代问题

> 在当时全部可买、流动性达到门槛的代币中，一个事前冻结的评分模型，能否在预先指定的 `H` 个月期限内提高进入收益分布前 1% 的概率，并在计入信号到入场延迟、归零、退市、排放、滑点、集中度和退出容量后，提高账户级几何增长？

`H` 必须在实验前固定，例如分别评估 12 个月和 36 个月，不能看到结果后改用最有利期限。还须同时冻结信号生成时间、最早入场时间、真实买入价格规则、再平衡频率、退市/迁移处理、退出 VWAP 或订单簿容量规则；否则“未来百倍”标签不可证伪。

#### 候选特征

- 外部资产费用和持有人实际所得；
- 非补贴用户、留存和真实交易需求；
- 稳定币/资本净流入；
- 开发者质量与持续性，而非简单 commit 数；
- 代币索取权和价值捕获链；
- 流通量、FDV、排放、解锁和集中度；
- 竞争格局、分发和网络效应；
- 当前估值相对同类和 BTC 的机会成本；
- 可买容量和分档退出容量。

#### 组合数学约束

- 10 个等权标的中 1 个终值为初始投入的 100 倍、其余归零，账户终值为 10 倍；
- 5 个等权标的中 1 个终值为初始投入的 250 倍、其余归零，账户终值为 50 倍；
- 分散降低单币归零风险，也稀释单一赢家对账户的贡献。

候选排序器可能存在；“可靠找到唯一百倍币”的圣杯没有证据。

### 5.4 凸性事件押注：支付结构，不是 Alpha 来源

粗糙版中“用小仓位买入深度虚值期权或低价事件合约，等待少数 10–100 倍赢家”的直觉，有一部分应当保留：在工具设计正确时，预付权利金可以限制单笔损失，同时保留极端右尾。但这只定义了**如何支付**，没有回答真实概率是否高于价格隐含的门槛。

对任一有限状态事件工具，首先计算：

\[
EV_{convex}=\sum_s p_s\,Payoff_s-Premium-C_{all}
\]

只有保守概率分布下仍为正，凸性才可能成为有用的执行方式。高倍数、有限损失和正期望是三个独立条件。

#### 粗糙版中必须纠正的部分

- “市场上每年都有期权上涨 10–100 倍”只证明事后存在赢家；分母必须包含同一规则买过且归零的全部合约。
- 预测市场价格与普通期权价格不能直接比较成“同一事件概率”。期权是连续支付，受到风险中性分布、波动率偏斜、期限、利率和波动率风险溢价影响。
- 方向判断正确仍可能亏损：事件发生太晚、幅度未过执行价、隐含波动率回落、买卖价差或提前退出都可能吞掉收益。
- 永续合约做空不是损失有限的凸性仓。它有挤仓、资金费率、跳空清算和平台倒闭风险；危机标的与交易场所还可能同时失效。
- 固定写“每次投入 1%–5%”没有统计依据。仓位必须随概率下界、赔率、相关性、模型误差和账户最大可接受损失变化。
- “稳定引擎不亏 + 彩票中一次 = 账户百倍”不符合第 2.1 节的账户数学。小仓位中的 100 倍赢家通常只让账户增加数倍。

#### 适合作为执行层的场景

- 窄域 D 已通过前向校准后，用规则明确的事件合约表达概率优势；
- 危机预警模型已有完整假阳性样本后，在独立、可提现场所买入有足够期限的 put 或 put spread；
- B/A 事件对收益分布产生可量化的离散状态，而期权盘口尚未完全反映；
- 多个工具的支付状态可以严格映射，能够选择在相同最坏损失下期望支付更高的一种。

#### 最小验证

1. 事前冻结事件总体、触发规则、期限和可交易工具，不从事后暴涨合约倒推策略。
2. 保存当时完整期权链或事件盘口，包括可成交 bid/ask、深度、费用和隐含波动率。
3. 在共同状态空间逐项映射支付，而不是直接比较两个页面上的“隐含概率”。
4. 使用真实可成交价格重放，并纳入未成交、提前退出、到期归零和平台/结算失败。
5. 同时比较不交易、现货、有限风险价差结构和对应预测合约。
6. 报告去掉最大赢家后的净 P&L、期望对数增长、资金占用和组合最大损失。

**初始结论：保留为执行覆盖层，不列为独立 Alpha 主线。**只有 D、危机预警、B 或 A 中至少一个上游概率/机制优势得到样本外证据后，才值得研究用凸性工具放大其右尾。

## 6. 交叉机会优于纯类别

| 组合 | 偏离来源 | 收敛/退出来源 | 初始评价 |
| --- | --- | --- | --- |
| **C+B** | 通过第 4.2 节六问、有限期内必须交易的可识别净流量 | 本人可执行的硬终值 | **最高研究优先；两条腿均须成立** |
| **A+B** | 绑定规则生效 | 必须公开执行的回购/卖出 | 高优先 |
| **A+C** | 迁移或规则改变 | 固定比例赎回/转换 | 高优先 |
| **D+C（严格限定）** | complete-set 或同一索赔权组合成本低于确定支付 | 覆盖全部状态后的固定赎回/转换 | 中高；未知事件方向仓不属于此类 |
| **D+中文公开信息** | 待验证的语言、来源、流程认知延迟 | 条件支付与平台裁决 | 中高研究优先、优势未知 |
| **B+基本面终值判断** | 卖压导致偏离 | 非硬但独立估值 | 中等，模型风险较大 |
| 纯 A | 供应/现金流输入变化 | 依赖市场叙事重估 | 中低 |
| 纯长尾 D | 低价高赔率 | 事件命中 | 右尾高、可重复性低 |

最优交集 `C+B` 的核心逻辑是：B 解释“为什么价格会暂时错”，C 解释“为什么以及如何收敛”。B 腿必须完整通过第 4.2 节六问；“有赎回压力”“存在固定截止日”或“价格下跌”本身都不构成 B。未通过时应归为纯 C、A+C 或一般事件交易，不能占用 `C+B` 的最高优先桶。

## 7. 统一评分框架

### 7.1 六轴评分

每个具体候选按 1–5 分评价，禁止只给类别打总星级：

1. **机制确定性**：权利、义务或收益来源是否清楚？
2. **发现优势**：我的数据和研究是否可能优于边际交易者？
3. **执行可行性**：身份、资格、速度、时段、最小金额和工具是否满足？
4. **净 EV 可信度**：扣除成本、失败和模型误差后是否仍可能为正？
5. **机会频率与独立性**：一年有多少有效、非高度相关事件？
6. **容量与扩容**：1 万、10 万、50 万、100 万分别能部署多少？

另列而不混入总分：

- 单笔最大损失；
- 账户尾部损失；
- 资金锁定期；
- 单平台敞口；
- 研究时间；
- 右尾倍数潜力。

### 7.2 研究前先验

以下只用于决定先研究什么：

| 子方向 | 机制 | 发现优势（待证） | 执行 | 净 EV 可证性 | 频率 | 扩容 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| C+B：硬终值下的强制偏离 | 5 | 4 | 3 | 4 | 2 | 2–3 |
| C：本人可执行、非 MEV | 5 | 4 | 3–4 | 4 | 2–3 | 2–3 |
| B：明确数量/时间/场所 | 4 | 4–5 | 3 | 3 | 2–3 | 2–3 |
| D：中文公开信息延迟 | 2–3 | 2–3 | 4 | 2–3 | 2–3 | 2–3 |
| D：规则/逻辑相对价值 | 4 | 4 | 2–3 | 3 | 1–2 | 1–2 |
| A+B：绑定公开市场流 | 4 | 4 | 3 | 3 | 2 | 2–3 |
| A：纯绑定 Tokenomics | 3 | 4 | 3 | 2 | 2 | 2–3 |
| 危机预警 | 2 | 4–5 | 2–3 | 1–2 | 1 | 2–3 |
| 百倍币候选排序 | 1–2 | 4 | 3 | 1–2 | 2 | 1–2 |
| E：趋势/Carry/持有 | 1–3 | 2–3 | 4–5 | 2–3 | 4–5 | 4–5 |

这些分数不是收益预测。中文信息方向的 CS/语言**技能匹配度**可先验评为 5，但实际发现优势仍是 2–3 且待前向数据验证；不能把“我擅长处理”当成“市场尚未定价”。右尾潜力越高，通常越难获得可靠概率、完整分母和稳定容量。

## 8. 研究边界与明确排除项

### 8.1 当前不做

- 毫秒到秒级 HFT、共址和专线套利；
- 依赖 mempool、builder、私有订单流、keeper 抢跑的 MEV；
- 专业做市和无低延迟撤单能力的手工做市；
- 随机 memecoin 打新、sniping 和链上土狗；
- 泛政治/战争突发长尾，尤其是内部人明显占优的市场；
- 直播体育、宏观数据公布瞬间和即时新闻抢跑；
- 高杠杆短线、裸卖期权、可能亏损超过既定风险资本的仓位；
- 因“最终有硬底”而对中途可清算仓位加杠杆；
- 跟单、老师、带单和无法审计的信号；
- 把 BTC/ETH 或稳定币未经说明地称为“现金”。

### 8.2 信息红线

仅使用在交易前已经向不特定公众合法公开、可以保存 URL/原文/发布时间的信息，或已由适格法律意见确认可使用的数据。任何来自工作关系、保密文件、事件相关人私聊或来源不明泄露的信息，不纳入交易决策。

### 8.3 不把风险偏好当作优势

“可以承受全部亏损”只说明风险预算，不会提高任何交易的期望值。杠杆也不会修复不存在的 Alpha，只会增加路径、跳空和清算风险。

本文主动把初始 1 万元定义为既定验证风险资本，并排除可能造成穿仓或损失超过该风险资本的结构。这是一条框架新增的账户边界，不是对个人主观风险承受力的推断。

## 9. LLM/CS 的正确角色

### 9.1 适合自动化

- 多语言原始源抓取和时间戳归档；
- 实体消歧、规则版本 diff 和条款字段提取；
- 治理提案、timelock、合约权限和资产余额监控；
- 法院 docket、拍卖公告、赎回队列和钱包状态整理；
- 点时资产池重建和历史事件库；
- 概率基准、情景模拟、账户级蒙特卡洛；
- 数据对齐、成本计算和异常告警；
- 寻找最强反证和审计回测代码。

### 9.2 不应委托给 LLM

- 最终概率和仓位决定；
- 对权利可执行性的法律判断；
- 合约资产足额与升级风险的最终确认；
- 把论坛、新闻和合约摘要直接变成交易信号；
- 在不知道完整候选总体时生成胜率；
- 用自然语言流畅度替代一手证据。

### 9.3 架构原则

LLM 负责候选发现和非结构化信息抽取；确定性代码负责金额、时间、权限、报价和阈值；人工负责权利确认、反方论证、概率、执行和最终决策。

> 扫描到 `redeem()`、一条钱包转账或一个治理提案，只代表发现线索，不代表发现 Alpha。

## 10. 验证协议

### 10.1 所有方向共用的五道硬门槛

1. **合法且本人可达**：平台合规不等于具体产品、赎回通道或数据使用都可达。
2. **点时数据可审计**：决策当时真实可得，原始数据和版本已存档。
3. **损失结构可接受**：包含跳空、暂停、平台倒闭和失败回收，不只看止损。
4. **响应和执行可实现**：按当前真实时段与速度，而不是预支未来系统能力。
5. **收益机制讲得清**：谁付钱、为何没有被竞争抹平、我凭什么是边际赢家？

### 10.2 共用事件记录

```text
候选 ID / 类别（A/B/C/D/组合）：
首次可知时间 / 信息截止时间：
原始来源 / 内容哈希 / 版本：
当时真实 bid/ask / 逐档深度 / 可成交量：
本人可用平台、资格、最小金额：
经济收益来源 / 风险承担者：
预测对象、方向、期限、概率区间：
全部成本与资金占用：
最强支持证据 / 最强反证：
失败状态、回收价值、平台尾险：
假想仓位及账户级最大损失：
执行/不执行及理由：
结果、归因、相对基准：
```

所有满足事前触发条件的候选都要记录，包括取消、失败、无价格反应、无法成交和 `No trade`。

### 10.3 分方向最小实验

| 方向 | 最小实验 |
| --- | --- |
| C | 建完整权利树和失败状态树；用真实 ask 计算贴现净值与回收敏感性 |
| B | 冻结公告/通过/执行开始/完成四时点；使用事前深度做事件研究 |
| A | 只纳入已通过、timelock/部署、生效参数明确事件；比较净 sink 与排放 |
| D 信息 | 前向记录概率区间、实际 ask、市场基准、结算和 Brier/log score |
| D 规则 | 保存规则版本，逐项模拟争议/取消/延期状态 |
| 中文信息 | 按 `07:00–22:00` 人工窗口测量中文原始源到英文源和可成交盘口变化的延迟；窗口外记 `No trade` |
| 危机预警 | 建包含所有假阳性的主体-日期面板，验证 30/90/180 日相对收益 |
| 百倍币排序 | 预先冻结 12/36 月等期限、入场延迟、再平衡、退市处理和退出容量；使用点时可得且含退市币的资产池评价 top-k 与账户几何收益 |
| 凸性执行 | 冻结完整事件总体和工具集合，在共同状态空间映射支付并重放真实 bid/ask |
| E | BTC/ETH 持有、趋势、Carry 分别按风险匹配口径复现 |

### 10.4 统计纪律

- 历史知名事件只能用于理解机制，不能用于估计胜率；
- 训练、验证、测试按时间切分，测试集一次性使用；
- 登记尝试过的规则、特征、参数和阈值；
- 禁止使用事后最低价、最高价、中间价或无法成交的报价；
- 资产池包含退市、归零和流动性消失标的；
- 事件相关性折算有效样本，不能把同一主题的多个市场当独立样本；
- 同时报算术 EV、期望对数增长、最大回撤和容量；
- 去掉最大 1–3 笔赢家后若策略转负，结论至少降级为“证据不足”；
- 轻微提高费用、滑点或失败概率便转负时，不得扩容。

## 11. 研究资源配置与第一轮工作样本

这里分配的是**研究时间，不是资金仓位**。

### 11.1 第一轮研究配比

| 研究簇 | 时间占比 | 目的 |
| --- | ---: | --- |
| C+B / 纯 C 权利扫描 | 30% | 找最可审计的结构性错价 |
| D：中文公开信息、规则和逻辑 | 30% | 验证最匹配个人禀赋的信息 Alpha |
| B / A+B 事件库 | 20% | 验证强制流是否真能转化为价格优势 |
| 危机预警 / 凸性执行 / 百倍币候选排序 | 10% | 保留高右尾假说，但防止吞噬主线 |
| E 基准与统一账本 | 10% | 建立机会成本和研究基础设施 |

### 11.2 四个等成本工作样本

每个样本投入相同时间和 AI 预算，只回答流程是否可做，不用短期收益排名：

1. **C+B 样本**：找一个同时满足 C 权利树与 B 六问门槛的历史或实时小额事件，完整复原强制流、权利、偏离、容量和执行路径；找不到时如实记录空集，不能用纯 C 替代。
2. **中文 D 样本**：选一组涉及中国的已挂牌市场，在固定人工响应窗口内做规则映射和公开信息延迟测量，窗口外事件记 `No trade`。
3. **B 或 A+B 样本**：从完整候选清单中复原强制性、数量、场所和事件窗口，不只挑成功案例。
4. **百倍币排序样本**：冻结一个历史日期、当时资产池、12/36 月期限、信号后入场延迟、再平衡、退市和退出容量规则，只用当时数据选 top-k，并与等权、BTC 和同赛道龙头比较。

凸性工具不单列第五个工作样本：它只作为上述样本的候选执行方式，并须与现货、不交易和其他有限风险结构作同状态比较。

### 11.3 中途 Go/No-Go

每个方向在工作样本后只能得到以下结论：

- **继续深实验**：数据、执行和机制均能被审计；
- **换子类**：大类有价值，但当前子类依赖速度、资格或数据；
- **证据不足**：流程可做，尚不能证明净优势；
- **淘汰**：机制、执行或完整成本已经使其不可能；
- **转为监控**：机会过于低频，不值得持续主动研究。

“回测盈利”和“发现一个百倍案例”都不能直接进入继续深实验。

## 12. 扩容与账户百倍的正确关系

### 12.1 1 万元的角色

1 万元首先是**验证资金**，不是百万利润的主要分母。它适合：

- 检验真实成交、费用、对账和心理执行；
- 发现纸面模型遗漏的资格、队列和平台问题；
- 验证小容量 D/C/B 机会；
- 为后续 5 万、10 万、50 万扩容建立证据。

它可能不适合：

- RWA 最低赎回额；
- 司法拍卖保证金；
- 大宗 OTC 最小票面；
- 高 Gas 链上的复杂多步操作；
- 需要多平台预置保证金的跨市场相对价值。

### 12.2 扩容依据

扩容只能由新增证据触发：

- 更多前向、有效独立样本；
- 真实成交与模型报价一致；
- 净 EV 下置信界仍为正；
- 最坏状态和账户几何增长可接受；
- 在下一资金档位模拟下仍有容量；
- 平台、稳定币和单事件相关敞口可控。

不能由连胜、短期 P&L、一次大赢家或“策略看起来成熟”触发。

### 12.3 百倍作为输出

只有在获得实际分布后，才用账户级模拟回答：

- 3/5/10 年终值分布；
- 达到 2/5/10/100 倍的概率；
- 中位数、5% 和 95% 分位数；
- 最大回撤与归零概率；
- 不同仓位和相关性假设的敏感性；
- 本金追加与纯投资收益分别贡献多少。

在这些输入不存在前，不给“3 年百倍概率 5%–15%”之类主观数字。

## 13. 当前结论与下一步

### 13.1 当前可下的结论

1. **最值得优先寻找的是 `C+B`，不是泛加密预测，也不是泛 Tokenomics。**
2. **公开中文信息传播 Alpha 是值得正式验证的独立方向。**它不是内幕；优势必须通过信息时间戳和可成交报价证明。
3. **真正非公开内幕信息不纳入路线。**海外身份只解决部分准入，不消除信息来源相关责任。
4. **危机预警可以研究，但必须包含全部假阳性和可执行工具。**“看懂 UST/FTX”不能证明能预测下一次。
5. **百倍币研究应降级为横截面候选排序。**目标是提高 top-k 命中和账户几何收益，不是找到唯一圣杯。
6. **凸性仓可以有限风险地存在，但标的百倍不等于账户百倍。**任何组合方案必须先做账户数学。
7. **C、B、D、A 均尚未证明真实 Alpha。**当前只有研究优先级，没有交易结论。
8. **E 必须永久保留。**若复杂研究不能在相同风险和时间成本下击败简单基准，应停止主动路线。

### 13.2 下一项具体产出

在不修改既有十周路线图的前提下，为以下四项分别建立一页候选卡和数据可得性审计：

1. `C+B` 权利与强制流事件库；
2. 涉及中国的预测市场公开信息延迟库；
3. `A+B` / 纯 B 的绑定执行事件库；
4. 点时可得、含退市币的百倍币候选资产池。

完成四份工作样本后，才决定下一轮 30 小时深实验对象。零策略、只做 E、暂缓或退出主动研究始终是合法结论。
