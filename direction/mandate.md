
# Mandate v0.1

## 0. A-E利润机制

### 一、先分清两种评价

每个方向都要同时放进两个坐标：


| 坐标                 | 回答什么                               | 不能用什么替代     |
| ---------------------- | ---------------------------------------- | -------------------- |
| **个人适配度 \(F\)** | 你能否比别人更快、更准确地研究和迭代？ | 一次偶然盈利       |
| **经济吸引力 \(E\)** | 扣除成本后是否有收益、容量和存续期？   | 你是否喜欢这个方向 |

最终只保留右上角：

* 你适合，但市场没钱：研究爱好；
* 市场有钱，但你没有可建设优势：别人家的机会；
* 两者都高：候选方向。

个人适配度看五件事：

1. 能否获得完整、点时、包含失败样本的数据；
2. 能否在20小时内提出并杀死一个假说；
3. 每做一次实验是否沉淀可复用的数据或工具；
4. 执行系统是否能由普通云服务器和确定性程序完成；
5. 你是否愿意连续半年处理这个方向最枯燥的工作。

经济吸引力另看：

1. 谁在付钱，为什么持续付；
2. 扣成本后的收益上界；
3. 绝对容量；
4. 尾部和路径风险；
5. edge存续期；
6. 是否只是组合组件，还是可能成为主要增长引擎。

### 二、用五份“真实试工”判断适配度

第一轮每类只给4小时，总计20小时。目标不是找盈利回测，而是看你能不能顺利完成该方向最核心的工作。


| 类别             | 4小时试工                                   | 成功表现                                   | 不适合的信号                             |
| ------------------ | --------------------------------------------- | -------------------------------------------- | ------------------------------------------ |
| **A 风险溢价**   | 选一个carry，重建净收益和最坏压力期         | 能说清承担什么风险、尾部一次会吃掉几年收益 | 只看平均资金费，不愿处理崩盘和交易所风险 |
| **B 相对错价**   | 找20次价差异常，按双腿可执行价测收敛        | 能准确处理同步时间、腿风险、成本和未成交   | 总用mid/mark，无法重建真实双腿成交       |
| **C 方向预测**   | 冻结一个事件信号，建立完整事件母体和基准    | 能事前定义信号、窗口、基准和退出           | 不断看结果修改事件定义                   |
| **D 流动性租金** | 采集订单簿和成交，计算1s/5s/30s markout     | 能分解价差、逆向选择、库存和对冲           | 只看spread，不看成交后价格漂移           |
| **E 右尾选择**   | 重建一个完整发行 cohort，包括死亡和下架标的 | 能处理幸存者偏差、实体关系、退出与右尾贡献 | 数据只能覆盖赢家，无法还原当时可买范围   |

### 三、如何从大方向产生子方向

不要从“还有什么币可以交易”开始，而要从**市场摩擦**开始。子方向通常产生于以下七类裂缝：

1. **参与者分割**：KYC、地区、抵押物、账户权限不同；
2. **时间分割**：闭市、周末、结算、到期、上线前后；
3. **强制交易**：清算、解锁、指数调仓、资金费结算；
4. **生命周期切换**：发行、毕业、上币、迁移、下架；
5. **信息理解困难**：治理提案、参数修改、实体控制关系；
6. **流动性不均衡**：新市场、长尾市场、特殊时段；
7. **规则不连续**：费率、保证金、oracle、价格限制突然改变。

然后把每个摩擦放进五个利润机制：

* 它是否产生风险补偿？→ A
* 是否产生可收敛价差？→ B
* 是否预测未来方向？→ C
* 是否提高流动性服务报酬？→ D
* 是否帮助选出少数右尾赢家？→ E

例如“代币毕业”不是子方向，只是一个事件。它至少可以衍生出：

* 毕业前后价差是否异常收敛？→ B
* 哪些特征预测毕业后2小时收益？→ C
* 毕业初期宽价差做市是否覆盖markout？→ D
* 哪些实体与持仓结构预测极端右尾？→ E

四者必须作为四张不同候选卡。

### 四、子方向的标准句式

每个子方向必须能写成一句话：

> 在【点时定义的市场母体】中，当【可观测事件/状态】出现时，因为【某类参与者被迫、受限或反应较慢】，产生【A–E中的一种利润机制】；使用【明确入场、仓位、退出】交易，edge预计持续【时间】，最便宜的证伪方法是【测试】。

写不完整，说明它还只是主题，不是候选。

例如：

> 在全部当时可交易的毕业代币中，当实体集中度低且毕业后净买入持续时，因为机械卖压较弱，可能产生2小时方向延续；按毕业后第10分钟可执行ask进入、第120分钟bid退出，先用完整cohort检验扣成本收益是否为正。

## 1. 最终经济目标

* 初始可用资本：1万元。
* 当账户权益首次达到5万元时，外部注入10万元。
* 自起始日起满3年，目标终值为111万元。
* 模拟对象必须称为：

$$
\text{策略}+\text{仓位政策}+\text{注资政策}

$$

不得把结果只归因于策略。

必须同时报告三条路径：

1. 1万元、无注资；
2. 1万元、达到5万元后注资10万元；
3. 期初直接投入11万元。

由于注资时间不确定，暂不使用单一“目标年化收益率”代替账户路径。

## 2. 本轮任务

本轮不是直接选仓位，而是：

> 在A–E五类利润机制中，找出至少一个经济量级仍可能参与三年目标、且“你＋AI＋可建设自动化”能够持续研究和执行的方向。

适配度只能在经济可行的候选之间比较。

## 3. 候选的三种角色

每张候选卡必须先选一种角色：


| 角色                  | 准入要求                                                 |
| ----------------------- | ---------------------------------------------------------- |
| `PRIMARY-ENGINE`      | 单独或作为主要部分，乐观但自洽的账户路径有可能达到目标   |
| `PORTFOLIO-COMPONENT` | 单独不能达标，但可能降低回撤、利用闲置资本或改善组合路径 |
| `BENCHMARK`           | 不准备投入研究资金，仅用于比较                           |

不能因为普通Carry只有约10%收益就说它“无价值”；但也不能把它伪装成主要增长引擎。

## 4. 结构性禁区

直接淘汰利润依赖以下资源的候选：

* 毫秒级或更快的排他竞争；
* 不可获得的排序权、私有订单流或额度；
* 无法合法、稳定取得的账户或交易权限；
* 无法重建的交易生命周期；
* 可能造成未受限负权益且没有明确隔离装置。

自动撤单、仓位熔断、断线保护、跨场所对冲和24小时运维属于可建设工程，不因当前尚未完成就直接淘汰；但必须单独验证，不能假定其已经可用。

## 5. 证据纪律

* 官方规格和实际行为分开记录；
* 所有成本按使用日重验；
* 没有进出场时间戳，不得估计真实账户收益；
* 没有完整账户时间线，不得逐事件顺序复利；
* 未成交、跳过、资本阻塞和零事件期必须进入母体；
* 历史数据不足不自动STOP，但必须标记`UNIDENTIFIED`；
* Bootstrap不能替代未见尾部和制度失效压力情景；
* 模型共识不构成证据。

## 6. 资金边界

研究、Shadow和历史模拟不产生资金权限。

未来即使通过前向阶段，也只能依次获得：

$$
\text{RESEARCH-ONLY}
\rightarrow\text{LIVE-KILL权限}
\rightarrow\text{PILOT权限}
\rightarrow\text{SCALE权限}

$$

每次升级均需单独规则和你的明确授权。零仓位始终合法。

## 7. 多模型停止规则

总体框架至此冻结，不再进行第四轮抽象评审。

后续三模型只审具体候选。框架仅在以下情况修改：

1. 可复核的公式、代码、数据、规格或账户记账错误；
2. 不修改会改变候选的STOP/继续、资金权限或风险上限；
3. 不修改会造成超过预设工时阈值的无效研究。

其他改进进入Parking Lot。

# 阶段0：候选原子与经济上界门

这里解决另一个模型指出的“几分钟能杀死的候选不能研究几个月”。

## 0A：等额生成，但不等额研究

A–E每类先生成两个一句话候选：

* 一个是该类最常见、最容易取得数据的版本；
* 一个是该类在你的约束下最强的合理版本。

总计10个候选原子。此时只允许写：

> 市场 × 触发条件 × 入场 × 退出 × 付钱方 × 主要失效方式。

这一步等额，是为了防止给喜欢的类别挑强候选、给不喜欢的类别挑稻草人。它应当很便宜，不读取数月数据、不写完整卡。

## 0B：乐观经济上界

每个候选在进入4小时案头卡前，必须填写：

```text
候选：
角色：PRIMARY-ENGINE / PORTFOLIO-COMPONENT / BENCHMARK

乐观但自洽的假设：
1. 单位资本净收益上界：
2. 可执行机会率上界：
3. 实际资本利用率上界：
4. 单笔与并发容量上界：
5. 策略可能存续期：
6. 最大可用杠杆及其尾部约束：
7. 达到该上界依赖的前提：

即使采用上述假设：
- 1万元无注资路径的三年终值上界：
- 阈值注资路径的三年终值上界：
- 期初11万元路径的三年终值上界：
```

这里不用Bootstrap，不报精确达标概率，也不用\(\mu/\sigma\)或Kelly。它只做“不可能性筛选”。

## 0C：四种出口


| 出口                 | 含义                             | 后续                |
| ---------------------- | ---------------------------------- | --------------------- |
| `STOP-SCALE`         | 乐观上界仍不足，不能承担申报角色 | 淘汰或降级为组件    |
| `STOP-STRUCTURAL`    | 生命周期、权限或执行结构不成立   | 淘汰                |
| `BOUND-UNIDENTIFIED` | 上界所需关键量未知               | 最多给一个限时Probe |
| `DESK-ELIGIBLE`      | 经济上界可能通过且结构自洽       | 才进入4小时案头卡   |

关键纪律是：

> “可能达到上界”不代表策略有效；但“上界都不够”足以停止。

## 防止伪造乐观上界

每个乐观假设必须标记来源：

* `RULE-BOUND`：由官方规则直接限定；
* `OBSERVED-BOUND`：由完整点时数据支持；
* `STRESS-ASSUMPTION`：人为设置的乐观压力值；
* `UNKNOWN`：目前不可识别。

如果主要结论依赖多个`UNKNOWN`，不能写“可能达标”，只能进入一次限时Probe。Probe的任务只是识别数量级，不是证明盈利。
